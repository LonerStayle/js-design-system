## 1. 클라이언트와 세계관

### 되감기홈쇼핑 (워드마크 `REWIND 99`, 장식 전각 표기 `ＲＥＷＩＮＤ ９９`, 가타카나 `リワインド`, 한글 표기 "되감기홈쇼핑")
- **무엇**: 매일 밤 **00:00–03:00** 생방송하는 **레트로 가전·문화 리퍼브 전문 라이브커머스 채널**(채널 번호 **CH.99**). 80–90년대 휴대용 카세트 플레이어, 14인치 브라운관 TV, 휴대용 CD 플레이어, 무선호출기 모양 알림기, 시티팝 LP 재발매반, 공테이프 같은 물건을 자체 검수실에서 고쳐 판다. 시청자는 웹·앱의 **"되감기 OS 99"** — 90년대 PC 데스크톱을 흉내 낸 쇼핑 셸 — 에서 방송 창을 띄워 놓고, 옆 창으로 채팅하고, 주문 창으로 산다.
- **스튜디오**: 용산 전자상가 건물 지하. 낮에는 검수실(수리 벤치 6석), 밤에는 B스튜디오에서 생방송.
- **왜 이 클라이언트인가**: 베이퍼웨이브(2010–2012, Macintosh Plus 『Floral Shoppe』, Chuck Person 『Eccojams』, 이후 몰소프트 mallsoft)는 **90년대 소비자 자본주의 — 쇼핑몰·홈쇼핑·기업 광고·윈도우 95·일본 시티팝 — 의 잔해를 느리게 되감아 붙인 장르**다. 한국에서 그 잔해가 가장 진하게 남은 장면은 1995년 개국한 케이블 홈쇼핑의 심야 방송과 용산 전자상가다. "옛날 가전을 심야 홈쇼핑으로 다시 판다"는 서비스는 스타일의 원래 맥락(소비 문화의 향수 + 반복 + 약간의 허무한 유머)과 정확히 겹친다. 장식으로서가 아니라 **판매 도구로서** 베이퍼웨이브가 성립한다.
- **고유 데이터 어휘**: 방송 회차 `EP.1287`, 상품코드 `RW-CS-0091`, 주문번호 `RW-261010-0417`, 회원번호 `M-0420917`, 채널 `CH.99`, 타임코드 `01:12:07`, 방송 큐 `Q-05`, 테이프 규격 `C-60`, 가격 `₩59,900`, 할부 `3개월 무이자`.

### 감정 톤 (한 문장)
**새벽 1시, 거실 불을 끄고 켜 둔 브라운관 속 쇼호스트가 "지금 이 가격, 다시는 없습니다"를 외치는 — 몽롱하고 키치한데 이상하게 다정한 노스탤지어.**
첫 화면 1초 안에: 파스텔(라이트) 또는 한밤 보라(다크) 데스크톱 위에 **회색 베벨 창들이 겹쳐 있고**, 가운데 창 안 브라운관에서 노을이 지고, 노란 OSD 가격이 `₩89,000 → ₩59,900`으로 깎이고, 오른쪽 채팅 창에서 "37대 남았대요"가 올라온다. 사양서가 아니라 **지금 켜져 있는 방송**의 온도.

## 5. 레이아웃 문법 — "데스크톱 좌표계"

이 테마의 화면은 **문서의 흐름이 아니라 바탕화면 위의 창 배치**다.

1. **바탕 = 32px 격자.** 모든 창의 좌상단은 32px 격자점에 스냅. 바탕에는 `--desk-grid` 1px 격자선이 실제로 보인다(시그니처의 일부). 바탕 하단 30%(데스크톱 ≥1024px)에는 `--desk-floor` 원근 그리드 바닥.
2. **창 = 콘텐츠 단위.** 섹션·카드·패널은 모두 "창"이다. 둥근 카드 금지. 창 구조 고정: 타이틀 바(28px, 모바일 36px) → [선택] 메뉴 막대(28px: 파일 편집 보기 도움말) → [선택] 도구 막대 → 내용(패딩 12px / 16px) → [선택] 상태 표시줄(24px, 칸 나눔 inset 베벨).
3. **겹침(캐스케이드)이 기본 구도.** 관련된 창은 **x +32px, y +32px**씩 계단처럼 겹친다(Windows '계단식 배열'). 활성 창이 맨 위(z-index 높음, 타이틀 바 컬러), 나머지는 비활성(타이틀 바 `--title-off`). 한 장면에 겹침 최소 1회.
4. **세 가지 배열을 섹션마다 바꾼다**: ① 계단식(겹침 — 첫 화면, 오버레이 시연), ② 바둑판식(2×2 / 3열 타일, 간격 8px, 겹침 없음 — 데이터), ③ 최대화(창 하나가 바탕 여백 24px만 남기고 화면을 채움 — 단일 작업 페이지). 같은 배열이 연속 두 섹션에 오지 않는다.
5. **바탕 아이콘 열**: 데스크톱 왼쪽 24px에서 시작하는 세로 열, 아이콘 32px + 라벨 2줄, 피치 88px, 열 폭 80px. 선택 시 라벨에 `--select` 바탕. 아이콘 = 페이지 바로가기(실제 링크).
6. **작업 표시줄**: 화면 하단 고정 44px(모바일 52px). 좌 `시작` 버튼(되감기 로고) → 열린 창 버튼들 → 우 트레이(LIVE 점 + 시청자 수 VT323, 검색 ⌘K, 테마 토글, 시계 `01:12`). 본문 하단에 작업 표시줄 높이만큼 `padding-bottom`.
7. **여백 리듬**: 창 사이 8px(타일) 또는 -32px(겹침), 섹션(=바탕화면 장면) 사이 96px(데스크톱)/48px(모바일). 창 내부 수직 간격 8 / 12 / 16 / 24 네 단계만.
8. **폭**: 바탕 전체는 풀블리드. 창 폭은 내용이 정한다 — 대화상자 360/480/640px, 앱 창 760/960px, 최대화 = 100% − 48px. **고정 max-width 컨테이너를 모든 섹션에 씌우지 않는다.**
9. **모바일(≤768px)**: 모든 앱 창은 최대화(좌우 여백 0, 바탕 8px만 보임), 계단식 겹침은 y +16px 계단 + x 0으로 축소(타이틀 바가 책갈피처럼 쌓여 보임), 아이콘 열 → 가로 4열 그리드, 메뉴 막대 → 가로 스크롤 + 오른쪽 페이드. 타이틀 바 버튼(최소화·최대화·닫기)은 시각 20px이지만 히트 영역 44px.

## 6. 시그니처 (두 개만, 끝까지)

### 시그니처 A — 베벨 크롬 (Win95 3D 테두리, 0px 모서리)
모든 표면이 **빛이 왼쪽 위에서 오는 2단 베벨**로 정의된다. 그림자·반경·유리 대신 명암 4색으로 깊이를 만든다.
- `--bevel-out` (튀어나옴): `box-shadow: inset 1px 1px 0 var(--bevel-hi), inset -1px -1px 0 var(--bevel-edge), inset 2px 2px 0 var(--face-hi2), inset -2px -2px 0 var(--bevel-lo)` (`--face-hi2` = 라이트 #EEEAF6 / 다크 #3A2E5C)
- `--bevel-in` (파임): 위 값을 반전(입력 필드·리스트 상자·상태 표시줄 칸·눌린 버튼·진행 막대 홈).
- `--bevel-well` (얕게 파임 1px): 탭 패널, 표 머리.
- 적용: 버튼(out → 누르면 in + 글자 1px 아래·오른쪽 이동), 입력·셀렉트·텍스트영역(in), 체크박스·라디오(in, 체크 표시는 픽셀 SVG), 창·대화상자·메뉴·팝오버(out), 탭(활성 탭이 패널과 이어지는 out), 슬라이더 손잡이(out), 진행 막대(in 홈 + 블록 단위 채움), 스크롤바(webkit 커스텀 out 손잡이), 표 머리(out 버튼처럼 클릭해서 정렬), 툴팁만 예외(1px #1B1230 실선 + 노란 바탕).
- **반경 0px 전면**. 예외는 `.crt` 화면(18px)과 LIVE 점·아바타(원) 둘뿐.
- 활성 타이틀 바: `linear-gradient(90deg, var(--title-a), var(--title-b))` — Win98 그라디언트 타이틀을 마젠타→청록 노을색으로. 여기가 노을색이 OS에 스며드는 유일한 통로.
- 포커스: Win95 점선 포커스 사각형(`outline: 1px dotted var(--ink)`, offset -4px)을 내부에 + 외부 `box-shadow: 0 0 0 2px var(--focus)` — 형태가 사각이라 v1의 '알약 버튼에 둥근 링' 불일치가 원천 소멸.

### 시그니처 B — 방송 OSD 레이어 (브라운관 + 자막 + 가격 깎기)
OS 창 안에 들어가는 **"화면" 표면**(`.crt`)은 방송 문법을 따른다: 노을·스캔라인·18px 곡면 모서리·노란 VT323 OSD.
- 좌상단 OSD `CH.99 ▶ LIVE`(VT323 #FFE45C, 그림자 `2px 2px 0 #000` — 흐림 없음), 우상단 타임코드 `SP 01:12:07`, 하단 자막 바(#120A24, 왼쪽 8px 마젠타 #FF71CE 탭) 위 Black Han Sans 상품명, 그 아래 **가격 깎기**: 정가 `₩89,000`에 빨간 대각선 취소선(2px #FF3B5C, -12°) → 노란 띠 위 `₩59,900`.
- 적용 컴포넌트: carousel(채널 넘기기), progress(남은 수량 `37/120` 블록 게이지), skeleton("신호 없음" 노이즈 + 컬러바), spinner(돌아가는 카세트 릴), marquee(자막 띠 뉴스 티커), badge 중 상태 배지(OSD 태그: 노랑/검정, `LIVE`·`품절임박`·`방송중`), empty(신호 없음 화면), dashboard 차트 패널(화면 안 오실로스코프), 404(컬러바 방송 사고), toast 중 `주문 폭주` 알림의 아이콘.
- **노을·글로우·스캔라인은 오직 .crt 안에서만**. OS 크롬에는 절대 넣지 않는다 — 두 세계(회색 OS / 네온 방송)의 대비가 이 테마의 긴장이다.

## 7. 모션 문법 — "OS는 끊기고, 방송은 흐른다"

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--dur-snap` | `0ms` | 버튼 눌림·체크·탭 전환 — OS 크롬은 **즉시**(design-system "instant transitions" 채택) |
| `--dur-open` | `160ms`, `steps(4, end)` | 창·대화상자·메뉴 열기: 와이어프레임 사각형이 4프레임으로 커지는 Win95 '줌' — scale(.6)→1, 외곽선만 먼저 |
| `--dur-close` | `120ms`, `steps(3, end)` | 닫기(역재생) |
| `--dur-channel` | `220ms` | 채널 전환 노이즈(캐러셀 슬라이드 전환, 페이지 첫 로드 1회): 화면에 노이즈 + 가로 슬라이스 2개 ±6px 어긋남 → 복귀 |
| `--dur-count` | `900ms`, `cubic-bezier(.2,.8,.2,1)` | 가격 깎기(₩89,000 → ₩59,900 숫자 롤링), 주문 수 증가 |
| `--marquee` | `40s linear infinite` | 자막 띠(일시정지 버튼 필수) |
| `--reel` | `1.6s linear infinite` | 스피너 카세트 릴 회전 |
| `--blink` | `1s steps(2) infinite` | LIVE 점, 텍스트 커서 (1Hz, 3Hz 미만) |
| `--split` | 호버 시 `text-shadow: -1px 0 #FF71CE, 1px 0 #01CDFE` 즉시 | 방송 관련 링크·CRT 썸네일 호버 = "신호 간섭". OS 버튼에는 쓰지 않음 |

- 한 화면 동시 상시 모션은 **방송 화면 1 + 자막 띠 1**까지(ux 데이터 Excessive Motion 채택).
- 실시간 수치(시청자, 남은 수량)는 4초마다 1틱 변화, 탭이 숨겨지면(`visibilitychange`) 정지.
- `prefers-reduced-motion: reduce`: 창 열기 즉시, 채널 노이즈 없음, 자막 띠는 줄바꿈된 정적 목록, 카운터는 최종값, 릴·LIVE 점 정지(LIVE 점은 채운 원으로 고정), 원근 그리드 스크롤 없음.

- 페이지 배경 전체를 노을 그라디언트로 칠하기 + 지평선 radial 글로우 + 섹션에 걸려 잘린 태양 — 노을은 .crt 안에만.
- 유리(glass) 카드, 8–12px 둥근 모서리, 모든 카드의 핑크 글로우 그림자, 알약 버튼.
- eyebrow → `NEW RETRO` 2줄 그라디언트 → 자간 벌린 반복 → 세리프 이탤릭 부제 → CTA 2개 → 기능 칩 4개 첫 화면.
- `기반 요소 / 디자인 토큰`, `구성 요소 / 컴포넌트 갤러리` 라벨-제목-부제 섹션 헤더.
- 디자인 시스템 자기 홍보 카피("토큰 한 줄로…", "데모 화면에서 쓰는 코드와 동일").
- 라이드셰어 SaaS "NEONRIDE"(MRR·활성 라이더·가입 전환률) 세계 전체.
- Orbitron·Audiowide·Cormorant Garamond·Outfit·IBM Plex Mono·Do Hyeon·나눔명조 조합, 한글에 걸린 넓은 자간.
- `.text-chrome` shimmer·`.text-neon` 글로우를 제목·숫자에 거는 것(흐림), 텍스트 그라디언트 한 단어 강조.
- 4% 불투명도 세로 가타카나 같은 읽히지 않는 장식 — 가타카나는 워드마크·시작 메뉴 배너처럼 **읽히는 크기**로만.
- 포인터 패럴랙스, 상시 스크롤되는 원근 그리드, 상시 크롬 shimmer — 상시 모션은 방송 화면 1 + 자막 띠 1뿐.
- 빈 스와치 카드·보이지 않는 그림자 견본·`000만` 축 라벨 같은 렌더 실패를 '분위기'로 덮는 것 — 모든 견본은 실제 값이 보여야 한다.
