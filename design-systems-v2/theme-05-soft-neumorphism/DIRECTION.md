## 1. 클라이언트 · 세계관

### 몽돌 오디오 (워드마크 `mongdol`, 한글 표기 "몽돌")
서울 성수동의 작은 오디오 하드웨어 스튜디오. 대표 제품은 손바닥 두 개 크기의 **데스크톱 스트리밍 앰프 「몽돌 M1」** — 화강암 회색 알루미늄 한 덩어리를 깎아 만든 면판에 큰 볼륨 노브 하나, 입력 선택 키 5개, 주황 전원 키 하나, 앰버 LCD 창 하나. 이름은 바닷물에 수천 년 굴러 둥글어진 거제·여수 바닷가의 **몽돌** — 모서리 없이 둥글고, 표면과 같은 재질로 솟고 꺼지는 뉴모피즘 실루엣 그 자체다.

- **스타일의 원래 맥락**: 뉴모피즘은 2019년 Dribbble(알렉산더 플류토 "Skeuomorph Mobile Banking")에서 이름이 붙었지만, 그 계보는 **산업 디자인의 면판**이다 — 디터 람스의 브라운 SK4·T3(1950–60s, 한 재질에 새긴 조작부), 바이 앤 올룹슨 Beosound, 그리고 요즘의 데스크톱 신시사이저·스마트 스피커. 공통점: 배경과 버튼이 **같은 재질**이고, 조작부는 색이 아니라 **솟음과 파임**으로 구분되며, 색은 오직 **표시등(LED)과 하나의 주황 키**에만 있다.
- **그래서 이 클라이언트**: 뉴모피즘의 약점(저대비, 경계 모호)은 "실제 기기 면판"이라는 맥락 안에서만 정당해진다. 면판에는 각인 라벨, 표시등, LCD 판독창이라는 **명확한 정보 장치**가 있기 때문이다. 이 세 장치가 v2의 접근성 보강책이자 시그니처다.
- **사용자 장면**: 망원동 작업실에서 일하는 일러스트레이터가 책상 위 M1의 노브를 돌려 저녁 음악을 듣는다. 앱(몽돌 컨트롤)은 그 면판을 화면으로 옮긴 것이다. 몽돌 팀(성수 청음실·고객지원·AS센터)은 같은 면판 문법의 내부 도구를 쓴다.
- **감정 톤 (한 문장)**: *손끝에 서늘하게 닿는 매끈한 돌 — 노브를 한 칸 돌릴 때 "딸깍" 하고 걸리는, 조용하고 정확한 손맛.*
  — 첫 화면 1초 안에: 화면을 가득 채운 회색 돌 면판, 그 위에 크게 솟은 볼륨 노브와 따뜻하게 빛나는 앰버 LCD "VOL 36". 다크에선 불 꺼진 방에서 LCD와 주황 LED만 빛난다.

## 5. 레이아웃 문법 — "면판 그리드 (Faceplate Grid)"

이 테마만의 규칙. 페이지는 **기기 면판 여러 장을 책상 위에 배치한 것**처럼 짠다.

1. **조작부 클러스터 + 그루브.** 화면은 기능별 "클러스터"로 나뉘고, 클러스터 사이는 선(border)이 아니라 **파인 홈(groove)** 2px로 가른다: `box-shadow: inset 1px 1px 1px var(--stone-lo), inset -1px -1px 0 var(--stone-hi)`. 카드를 늘어놓지 않는다 — **한 장의 큰 면판 안을 홈으로 구획**하는 것이 기본.
2. **레전드 위 · 조작 가운데 · 판독값 아래.** 모든 조작 요소는 세로 3층 정렬: 위에 각인 레전드(11–12px) → 조작체(키·노브·페이더) → 아래 판독값(Share Tech Mono). 레전드 베이스라인은 클러스터 내에서 한 줄로 맞춘다.
3. **판독창 좌측 · 조작부 우측 (4:8).** 정보 화면은 12단 그리드에서 왼쪽 4단 = LCD/판독 영역(어둡고 파인 창), 오른쪽 8단 = 조작 영역. 모바일에선 판독창이 위로 올라가 상단 고정(sticky) "계기 띠"가 된다.
4. **깊이 3단 = 정보 위계.** `−` 파인 우물(입력·판독·트랙, 값이 들어가는 곳) / `0` 면(텍스트, 정적 정보) / `+` 솟은 캡(누를 수 있는 것). **누를 수 없는 것은 절대 솟지 않는다** — v1처럼 정적 카드를 띄우지 않는다. 솟음은 곧 "만질 수 있음".
5. **간격 8px 기준, 디텐트 리듬.** 간격 토큰 4/8/12/16/24/32/48/72/120. 조작체 사이 최소 8px(터치), 클러스터 내부 패딩 24px(모바일 16px), 면판 바깥 여백 48px(모바일 16px 측면 거터).
6. **반경은 물체 종류에 묶인다.** 기기 면판 28px · 모듈 20px · 키 14px · 우물/입력 12px · LED·노브·페이더 손잡이 50% · 칩 999px. "모든 것 같은 radius" 금지.
7. **섹션 리듬은 매번 다른 기기 배치.** index는 ① 풀블리드 거대 면판 1장 → ② 단면도(가로로 긴 띠) → ③ 마감 견본 3개 비대칭 → ④ 랙처럼 쌓인 1U/2U/3U 모듈 → ⑤ 오버레이 창 → ⑥ 바닥 명판. 같은 max-width·같은 그리드가 두 번 연속되지 않는다. 기본 컨테이너 1200px, 거대 면판은 1320px, 단면도 띠는 풀블리드.
8. **나사 금지.** 모서리 나사·리벳 같은 장식은 쓰지 않는다(몽돌 면판은 일체형 가공). 장식은 오직 깊이.

## 6. 시그니처 (2개, 끝까지)

### 시그니처 A — "한 덩어리 돌 면판 + 깊이 3단"
모든 요소가 `--stone` 한 재질에서 깎여 나온다. 그림자 토큰(광원 좌상단 135° 고정):
```
--sh-raised-sm : -3px -3px 6px  hi, 3px 3px 6px  lo
--sh-raised    : -6px -6px 14px hi, 6px 6px 14px lo
--sh-raised-lg : -14px -14px 32px hi, 18px 18px 40px lo   (기기 면판·모달)
--sh-pressed   : inset 4px 4px 8px lo, inset -4px -4px 8px hi
--sh-pressed-sm: inset 2px 2px 4px lo, inset -2px -2px 4px hi
--sh-well-deep : inset 6px 6px 14px lo, inset -5px -5px 12px hi  (LCD 베젤·레벨 트랙)
--sh-groove    : inset 1px 1px 1px lo, inset -1px -1px 0 hi       (구획 홈 2px)
--knob-cap     : conic-gradient(from 210deg, hi 0 8%, stone 22%, lo 48%, stone 70%, hi 100%) 위에 raised-lg — 금속 원뿔 반사(그라디언트 허용은 여기 하나)
```
적용: 버튼=raised→pressed, 입력=pressed, 트랙=well-deep, 구획=groove, 오버레이=raised-lg. **보더 0.**

### 시그니처 B — "표시등 문법: LED 점 + 앰버 LCD 창"
상태는 색 면 채우기가 아니라 **작은 LED 점(8px 원 + glow)과 LCD 판독창**으로만 알린다.
- LED: 8px 원, 꺼짐 = `--stone` pressed-sm 구멍 / 켜짐 = 해당 LED 색 + glow. 활성 탭·선택 입력·스위치 ON·알림 상태·칸반 우선순위·리스트 상태 모두 LED.
- LCD 창: `--lcd-bg` 우물 안 Share Tech Mono 앰버 글자. 꺼진 세그먼트 잔상은 **숫자만 이어진 값**(`2:37`, `4.6`, `890,000`)에만 `--lcd-ghost`로 아주 낮게 깔린다 — 글자(`VOL`, `NET`)·기호(`₩`, `-`, `/`)가 섞인 값에는 깔지 않는다(세그먼트 폰트가 아니라 글자 틈으로 8이 비쳐 깨진 글자처럼 읽혔다). 면판 메인 판독값(index `VOL 36`)만 **CSS 7-세그먼트**(`.seg7`, 막대 7개)로 그려 꺼진 막대가 진짜 잔상이 된다. 404 `NO SIGNAL`은 잔상 없음. 쓰임: 면판 판독값, 토스트, 툴팁, 코드 블록, 마키, KPI 메인 숫자, 페이지 상단 상태 띠.
- 한글은 LCD 안에서도 Noto Sans KR로 분리(앰버 색만 공유).

## 9. index.html 구성안 — 「몽돌 M1 사용설명서」(제품 사용설명 화면)

매체: **조작 가능한 제품 사용설명서**. 랜딩 아님. 첫 화면은 기기 그 자체.

1. **상단 면판 띠 (navbar)** — 왼쪽 `mongdol` 각인 워드마크 + "M1 사용설명서 · 제2판 2026.10" / 가운데 입력 선택 키형 내비(각 부 · 재질 · 표시등 · 글자 · 조작부 · 문제 해결) / 오른쪽 주간·야간 물리 스위치, 화면 목록 메뉴 키.
2. **① 첫 화면 — "각 부의 이름" (풀블리드 거대 면판, 1320px)**
   - 화면 중앙~좌측에 M1 정면 면판(CSS로 그린 28px 반경 raised-lg 정사각, 데스크톱 560px, 390에서 폭 100%−32px): 거대 볼륨 노브(지름 260px, 조작 가능: 드래그·휠·←→·−/+ 키), 노브 왼쪽 위 앰버 LCD 창 `VOL 36` / `NET · 96kHz`, 아래 입력 선택 키 5개(NET 점등), 오른쪽 아래 주황 전원 키, LED 열, 헤드폰 단자 파인 원.
   - 면판 둘레에 **번호 콜아웃 ①–⑧**(지시선 1px `--ink-2` + 원 번호)과 우측 세로 "각 부 명칭" 목록. 목록 항목을 호버/포커스하면 해당 부위 LED가 켜진다.
   - 장 표시: 거대 음각 **"M1"**(모델명, Barlow SC 음각 — 장 번호가 아니다) + 제목 "각 부의 이름" (64px). 형용사 슬로건·CTA 쌍 없음. 한 줄 안내: "노브를 돌려 보세요. 한 칸에 1단계, 80칸에서 최대입니다."
   - **쪽 번호(folio)**: 모든 장 우상단 같은 자리에 작은 각인 `p. 02` `p. 04` … `p. 14`. 장마다 "번호 + 제목"을 반복하지 않는다(01·30 문법 회피). 화면 창 장의 LCD "07" 같은 단독 번호도 쓰지 않는다.
   - LCD 메인 판독값은 7-세그먼트 두 자리 + 작은 `VOL`/`MUTE` 태그.
   - 390: 면판이 화면 폭을 채우고, **콜아웃 ①–⑧은 숨긴다** — 아래 '각 부 명칭' 번호 목록이 그 역할을 하고, 목록 항목을 누르면/포커스하면 해당 부위 LED가 켜진다.
   - **면판 정본**: 이 첫 화면 배치가 M1의 얼굴이다. product 캐러셀·index 도면·profile 보유 기기·pricing 구성 썸네일은 모두 공용 축소판 `.m1mini`(같은 배치·비율 672:698·반경 4.2cqw, 콜아웃 없음)로 그린다. 윗면(220×68)·후면(220×220)도 같은 폭·같은 반경.
3. **② 재질 — 단면도 (풀블리드 가로 띠)**
   - M1 면판을 옆에서 자른 단면 SVG/CSS: 파인 우물(−4) · 면(0) · 키(+6) · 노브(+12)의 높이 차를 치수선으로 표기하고, 각 높이 아래에 실제 컴포넌트 조각(입력 우물, 텍스트, 키, 노브)을 놓는다. 하단에 그림자 토큰 값 표(가공 사양표 형식, 행 7개). 단면 띠만 좌우 거터 없이 꽉 찬다.
4. **③ 표시등 읽는 법 + 마감 (비대칭 7:5)**
   - 왼쪽 7: "표시등 읽는 법" 표 — LED 색 4종(주황·그린·앰버·빨강) × 점등/깜빡임 의미 8행(예: "빨강 깜빡임 — 클리핑, 볼륨을 3칸 낮추세요"). 각 행에 실제 LED.
   - 오른쪽 5: 마감 견본 3개를 **솟은 몽돌 조약돌**(비정형 둥근 실루엣, border-radius 46% 54% 52% 48%)로 — 화강 그레이 / 현무 차콜 / 주황 노브 에디션, hex와 대비값.
5. **④ 글자 — 각인과 LCD (좌측 거대 견본, 우측 규칙)**
   - Orbit "몽돌" 120px 음각 견본, LCD `VOL 36` 72px, Barlow SC 레전드 줄 `VOLUME · INPUT · POWER`, 본문 단락(사용설명서 실제 문장). 우측 좁은 열에 스케일 표.
6. **⑤ 조작부 — 확장 컨트롤 데크 (랙 스택: 1U/2U/3U 모듈이 위아래로 쌓임)**
   - 32개 컴포넌트를 "기기 확장 모듈"로: 1U(높이 96px) = 키 열·배지·브레드크럼·페이지네이션·탭 / 2U = 폼(입력 우물·스위치·체크 키·라디오·페이더 EQ 5밴드), 레벨 미터, 스피너·스켈레톤 / 3U = 테이블(입력 단자 사양 8행), 캘린더(청음실 10월 예약), 캐러셀(면판 정면·윗면·후면), 칸반 미니(펌웨어 2.5.0 작업 3열), 타임라인(펌웨어 변경 기록), 리스트. 각 모듈 왼쪽 끝에 세로 각인 레전드(`BTN` `FORM` `METER`…)와 한글 이름.
   - 같은 카드 갤러리 금지 — 모듈은 폭이 1/1, 2/3+1/3, 1/2+1/2로 번갈아 바뀐다.
7. **⑥ 화면 창 — 오버레이 열린 상태 견본**
   - 모달("공장 초기화할까요?"), 서랍(EQ 프리셋 편집), 메뉴(입력 이름 바꾸기), 팝오버(디텐트 설명), 툴팁, 커맨드 팔레트(⌘K "펌웨어", "야간 모드"…), 토스트(LCD 띠 "프리셋 '저녁 작업' 저장됨")를 **정적으로 열린 채** 한 판 위에 배치 + 각각 실제로 여는 트리거 키.
8. **⑦ 문제 해결 (아코디언 + 경고)** — "노브를 돌릴 때 지직거려요" "블루투스가 자꾸 끊겨요(2.5.0에서 수정, 10/20 배포)" "LCD가 꺼져 있어요" 등 6항목, 고객센터 1588-0416.
9. **⑧ 바닥 명판 (footer)** — 기기 바닥 라벨 한 장: 파인 우물 판 위 가운데 정렬 각인 줄 — 큰 `MD-M1` · `AC 100–240V 50/60Hz 18W` · CSS 바코드 + 일련번호 **형식 표기** `M1-GR-YYMM-#####`(제조 라벨 견본 — 명판은 스토어·고객지원·AS 화면에도 붙으므로 특정 고객 기기 번호를 찍지 않는다. 윤하람 번호는 그녀의 장면에서만, 수정 1) · 인증 각인(원 KC · 사각 CE · 분리배출) · `MADE BY MONGDOL AUDIO · SEOUL` · 회사/주소/설계/고객센터 한 줄. **칸 테두리·라벨/값 정의 목록 없음**(01·30 판권 블록 문법 회피). 아래 10개 화면 링크 키 열.
10. **판독창 좌측 열은 따라온다** — 문제 해결의 CARE 창, pricing 합계 영수증, product 도면 캐러셀처럼 4:8의 왼쪽 판독 열은 `position: sticky; top: 96px`. 판독 열이 짧아 생기는 벽보형 빈 칸(브리프 7.8)은 sticky + 내용 보강(AS 보내는 법 3단계, 마감별 정면 3대, 이번 주 출고 2건)으로 메운다.
