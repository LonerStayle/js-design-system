## 1. 클라이언트 · 세계관

### 스타일의 원래 맥락
Organic/Earth 스타일의 뿌리는 1970년대 홀어스 카탈로그·생협 소식지와 2010년대 파머스마켓 브랜딩(크라프트지, 고무도장, 손글씨 칠판)이다. 한국에서 이 정서의 진짜 현장은 **오일장과 생협 꾸러미**다: 누런 갱지 전단, 골판지 조각에 매직으로 쓴 "햇고구마 3kg 19,000", 빨간 인주로 찍은 "산지직송" 도장, 마을 회관 벽의 24절기 달력. v2는 여기서 출발한다.

### 클라이언트 (한국) — 볕바른장
- **정체:** 충남 홍성군 홍동면 소농 23가구가 모인 제철 농산물 꾸러미 협동조합. "볕바른"은 '햇볕이 잘 드는'이라는 순우리말.
- **두 가지 일:** ① 주간 제철 꾸러미 정기배송(목 수확 → 금 발송 → 토 도착), ② 서울 망원동 **장날**(매달 둘째·넷째 토요일 오프라인 장터).
- **화면이 하는 일:** 구독자에게는 이번 주 꾸러미와 생산자 이야기를, 조합 사무국에게는 수확·포장·발송 작업판을 보여준다.
- **워드마크:** 한글 "볕바른장"(East Sea Dokdo) + 원형 인주 도장 "볕". 라틴 워드마크 없음.

### 감정 톤 (한 문장)
**"한낮 장터 좌판 앞에서 햇볕에 데워진 흙 묻은 고구마를 손에 쥐는 기분 — 투박하고, 넉넉하고, 사람 냄새가 난다."**

## 5. 레이아웃 문법 — "펼친 3단 전단 위에 좌판을 차린다"

1. **3단 접지 그리드.** 기본 12단(최대 1320px, 거터 24px, 모바일 4단·거터 16px·좌우 16px). 전단 지면 섹션은 **4/4/4 또는 5/7, 3/5/4**로 나누고 단 사이에 **접지선**(2px dashed `--line`, dash 8/6)을 세로로 긋는다. 모바일에서 접지선은 가로로 눕는다. 카드 그리드 `repeat(n,1fr)` 균등 분할은 표·달력 외에 쓰지 않는다.
2. **풀블리드 색 띠와 전단 지면을 번갈아.** 인접한 두 섹션이 같은 바탕·같은 폭·같은 패딩이면 안 된다. 순서 예: 볕 띠(풀블리드, 상하 112px) → 크라프트 지면(1320px, 상하 88px) → 흙 지층 띠(풀블리드, 상하 0 — 띠 자체가 내용) → 갱지 지면(1120px, 상하 72px) → 배추 띠 …
3. **가위로 오린 가장자리.** 풀블리드 띠의 위·아래 경계는 직선이 아니라 **지그재그(핑킹가위) 10px 톱니** — `mask: conic-gradient` 반복 또는 `clip-path`. 블롭·물결 곡선 금지.
4. **좌판 선(床線).** 상품·가격표·컴포넌트 견본은 6px 두께 `--ink` 가로선(좌판 널빤지) 위에 **바닥 정렬**(`align-items:end`)로 놓인다. 물건 높이가 달라도 바닥이 맞으니 빈 칸이 생기지 않는다(브리프 7-8).
5. **기울기 규칙.** 쪽지·가격표·도장만 기울인다: 회전 값은 {−2°, −1.2°, 0.8°, 1.5°} 중 하나를 `:nth-child`로 돌려 쓴다. 본문 블록·표·입력칸은 0°. hover/focus 시 0°로 바로 선다.
6. **왼쪽 무게, 오른쪽 메모.** 제목·본문은 좌측 정렬. 가운데 정렬 섹션 헤더 금지. 손글씨 메모는 본문 단 밖 여백(오른쪽 2단)에 걸치고 짧은 손그림 화살표(`currentColor` SVG)로 가리킨다.
7. **반경.** 종이 면 `2px`, 입력칸 `3px`, 도장·아바타 `50%`, 그 외 둥근 모서리 없음. 같은 radius·같은 그림자를 모든 것에 바르지 않는다: 그림자는 "위에 얹힌 종이"(쪽지·가격표·모달)에만.
8. **여백 리듬.** 섹션 간 간격은 88/112/72/0 중 인접 섹션과 다르게. 쪽지 내부 패딩 20/24px, 표 셀 12/16px.

## 6. 시그니처 (2개, 끝까지)

### 시그니처 ① 인주 손도장 `.dojang`
- **모양:** 원형(지름 56/88/140px) 또는 사각(낙관) 도장. 테두리 3px `--stamp` 이중 원(바깥 3px + 안쪽 1px, 간격 4px), 안에 Nanum Gothic 800 또는 East Sea Dokdo 글자 1~4자.
- **잉크 번짐:** 페이지마다 숨긴 인라인 SVG에 필터 `#ink-rough` 1개(`feTurbulence baseFrequency=.8 numOctaves=2` + `feDisplacementMap scale=2.5`)를 두고 `filter:url(#ink-rough)`. 인주가 덜 묻은 얼룩은 `mask-image`에 노이즈 SVG data-URI(투명도 0.75~1). 라이트에서 `mix-blend-mode:multiply`, 다크는 normal + 2px `--stamp-ink` 테두리.
- **기울기:** 기본 −8° (도장은 언제나 삐뚤게 찍힌다).
- **쓰이는 곳(컴포넌트 전반):** 브랜드 마크 "볕", 상태 배지(`수확 완료`·`발송`·`품절`·`예약`), 활성 내비 항목 옆 작은 도장, 체크박스 체크 = 빨간 원 도장, 단계(steps) 완료 표시, 가격표 "제일 많이 받음" 도장, 토스트 아이콘 자리, 404의 "장 파함" 큰 도장, 빈 상태, 테이블 행 선택 표시.
- **동작:** "찍기" — `scale(1.4) rotate(-18deg) opacity 0` → `scale(.94)` → `scale(1) rotate(-8deg) opacity .95`, 260ms, `cubic-bezier(.2,1.5,.4,1)`. 주 버튼 클릭·체크·단계 완료·토스트 등장 때 같은 동작.

### 시그니처 ② 골판지 가격표 `.tag`
- **모양:** `--cardboard` 면 + 골판지 결 `repeating-linear-gradient(90deg, rgba(0,0,0,.05) 0 2px, transparent 2px 6px)`, 가장자리는 손으로 뜯은 다각형 `clip-path`(꼭짓점 10~12개, 2~5px 들쭉날쭉) 3종(`.tag--a/b/c`), 왼쪽 위 펀치 구멍(지름 10px, 바탕색 원) + 끈(1.5px `--ink-2` 곡선 SVG, 선택).
- **글씨:** 품목명 East Sea Dokdo `--t-hand-m`, 가격 East Sea Dokdo `--t-hand-l` 또는 인쇄 가격 Zilla Slab `--t-price-l`, 단위는 Nanum Gothic 700.
- **쓰이는 곳:** 가격(pricing 3장·product·index), KPI 숫자(dashboard "412상자"), 툴팁 말풍선 대신 작은 가격표, 칸반 카드 오른쪽 위 수량 꼬리표, 캐러셀 슬라이드 라벨, 마퀴의 품목 띠, 페이지네이션 현재 페이지.
- **동작:** "툭 놓기" — `translateY(-14px) rotate(+4deg) opacity 0` → 제자리 회전값, 320ms, `cubic-bezier(.3,1.35,.5,1)`; stagger 40ms.

### 바탕 재료 (시그니처 아님, 전 화면 공통)
크라프트 섬유: body에 SVG `feTurbulence`(baseFrequency .9, 2옥타브) 노이즈 data-URI를 `opacity .16 / multiply`로 1겹. radial 얼룩·블롭 없음. 다크는 `opacity .10 / screen`.

### 일러스트 (원형이 요구하는 주인공)
농산물·사람은 인라인 SVG로 직접 그린다 — 고구마(`--goguma-fill` 몸 + `--ochre` 흙 얼룩), 배추(`--leaf-fill` + `--cabbage-fill` 잎맥), 무(`--gangji` + 연두 잎), 대봉감(`--persimmon` — 세로가 긴 도토리·하트꼴, 높이:너비 ≈ 1.2:1, 아래가 뾰족, 세로 하이라이트 한 줄, 납작한 4엽 올리브 꽃받침 + 짧은 갈색 꼭지대. 둥근 몸 + 초록 별 꼭지는 토마토로 읽히니 금지), 표고(`--shiitake-fill` 갓 + `--ill-white` 갈라진 무늬), 쪽파. 선은 2px `currentColor`, 면은 `style="fill:var(--x)"`(presentation attribute에 var() 금지). 단순한 판화 같은 2색 면 — 사실적 그라데이션 금지. **밤:** 면은 `*-fill`로 깊은 흙빛을 지키고 외곽선만 밝은 `--ink`(1.5px)로 바뀐다 — 알전구 아래 판화. 흰 면(무·달걀·쌀자루)은 `--ill-white`. product의 큰 고구마는 다리·더듬이처럼 읽히는 짧은 뿌리 선 없이, 아래 20–25%가 황토밭에 묻힌 채 양 끝에 가는 직선 꼬리뿌리 하나씩(갈고리·부리처럼 휘지 않는다) + 앞 고구마 왼쪽 끝(머리)에서 나와 위로 휘는 순 한 줄기(잎 넷)가 히어로 왼쪽 위 빈 크라프트를 채운다. 그림은 1.25배, 산지직송 도장은 흙과 고구마 경계에 −8°. 모바일은 고구마와 밭흙을 220px로 잘라 주문 쪽지 위로 올린다.

**본문 속 숫자:** Zilla Slab 700은 가격·단독 수치에만. 문단 안 숫자(`1,980㎡`, `600평`, `10월 22일`)는 `.num-in` — 본문 글꼴(Nanum Gothic) 그대로 + `tabular-nums`, 본문색.

## 7. 모션 문법 — "툭 찍고, 툭 놓고, 천천히 해가 든다"

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--dur-quick` | 120ms | hover 색·0° 바로 서기 |
| `--dur-stamp` | 260ms | 도장 찍기 |
| `--dur-drop` | 320ms | 가격표·쪽지 놓기, 드로어·모달 |
| `--dur-sun` | 900ms | 첫 화면 볕 띠 진입(위에서 아래로 빛이 차오름 — `clip-path inset` 0→100%) 1회 |
| `--ease-stamp` | `cubic-bezier(.2,1.5,.4,1)` | 오버슈트 (back.out 1.4 근거) |
| `--ease-drop` | `cubic-bezier(.3,1.35,.5,1)` | |
| `--ease-out` | `cubic-bezier(.2,.7,.2,1)` | 일반 |
| stagger | 40ms (10개 초과 시 20ms) | 좌판 물건·리스트 |

- 버튼 press: `translateY(2px)` + 그림자 제거(종이를 바닥에 누름), 120ms.
- 모달 = 위에서 쪽지가 떨어져 −1.2°로 놓임. 드로어 = 오른쪽에서 장바구니 쪽지가 밀려 들어옴(회전 없음). 토스트 = 아래에서 도장과 함께.
- 마퀴(장날 안내 띠) 40s 선형 루프, hover 시 정지.
- `prefers-reduced-motion: reduce` → 모든 진입·회전 애니메이션 제거, 최종 상태 즉시, 마퀴 정지(정적 줄), 도장은 찍힌 상태로.
