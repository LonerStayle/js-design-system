## 1. 클라이언트 · 세계관

### 소다넷 (워드마크 `sodanet`, 한글 표기 "소다넷", 플레이어 이름 "소다플레이어")

- **무엇**: 2003년에 문을 연 개인 홈피 포털. 미니홈(개인 홈피) + BGM + 쪽지 + 스킨샵 + 물친구(서로 맺는 친구 관계). 2011년 서비스 종료, **2026년 3월 3일(화) "소다넷 2026"으로 재개장**해 그때 홈피 데이터를 그대로 되살렸다. 20~30대가 옛 홈피를 다시 꾸미고, Z세대가 Y2K 스킨을 사서 꾸민다.
- **왜 이 스타일인가**: 프루티거 에어로(2004~2013, 윈도우 비스타·XP 바탕화면, 맥 OS X 아쿠아, WMP 11, 2000년대 휴대폰·MP3 UI)는 "기술은 맑고 낙관적이며 자연과 함께한다"는 시대 정서다. 한국에서 그 정서를 가장 많이 입은 것이 **포털 스킨·미니홈피 스킨·미디어 플레이어 스킨**이었다. 소다넷은 그 스킨 문화를 파는 회사이므로, 광택·물방울·하늘·초원이 장식이 아니라 **상품 그 자체**다.
- **원래 맥락에서 가져오는 것**: ① 고정폭 스킨 프레임 + 3단 포털 그리드(로그인 박스 · 본문 · 플레이어/랭킹) ② 상단에 매달린 아쿠아 탭 ③ 젤리 광택 알약 버튼과 구슬(orb) 아이콘 ④ 하늘→초원 언덕 바탕화면 ⑤ 미디어 플레이어의 LCD 창·이퀄라이저 ⑥ TODAY/TOTAL 방문자 카운터 ⑦ 실시간 검색어 티커 ⑧ 2000년대 포털 푸터(회사소개 | 이용약관 | 개인정보처리방침).
- **이 테마가 아닌 것**: 반투명 서리 유리 판(theme-04 윤슬홈의 문법), 보라·핑크 네온 Y2K(ui-ux-pro-max 기본값), 회색 기술 문서.

### 감정 톤 (한 문장)
**"토요일 오후, 막 새로 바른 홈피 스킨에서 BGM이 흘러나오고 쪽지 알림이 '띠링' 하고 뜨는 — 맑고 들뜨고 약간 촌스러운 반가움."**

1초 안에 느껴야 할 것: 화면 위쪽 절반을 채우는 맑은 하늘과 초원 언덕, 그 위에 떠 있는 사탕처럼 반짝이는 젤리 버튼, 오른쪽에서 돌아가는 플레이어. 정보보다 **반가움과 들뜸**이 먼저다(브리프 7-2).

## 5. 레이아웃 문법 — "고정폭 스킨 + 포털 3단 + 매달린 탭"

1. **스킨 프레임**: 화면 전체 = 하늘·언덕 바탕화면(`position: fixed` 배경 레이어). 그 위에 **최대 1200px 고정폭 스킨**이 가운데 놓인다(2000년대 980px 스킨을 현대 해상도로 확대). 스킨 바깥 여백은 바탕화면이 보이는 "책상"이다. 스킨 좌우 패딩 24px(1440), 16px(390).
2. **포털 3단**(≥1100px): `232px | 1fr | 300px`, 간격 16px. 왼쪽 = 로그인/내 정보 박스 + 바로가기, 가운데 = 본 장면, 오른쪽 = 소다플레이어 + 순위. **좌측은 목차가 아니다**(theme-30 문법 금지) — 사람·재화·쪽지가 있는 "내 박스"다.
   - 760~1099px: `1fr | 300px` 2단, 로그인 박스는 상단 가로 띠로 접힘.
   - <760px: 1단. 소다플레이어는 **화면 하단 고정 미니 플레이어 바(높이 64px + safe-area)**로 도킹, 본문 하단 패딩 88px.
3. **매달린 아쿠아 탭**: 로고 바(높이 72) 바로 아래, 탭들이 바에서 **아래로 매달려** 스킨 상단 가장자리를 덮는다(탭 높이 40, 위 모서리 반경 14 / 아래 0, 활성 탭만 본문 면과 이어짐). 모든 페이지 공통.
4. **포털 박스**: 모든 정보 덩어리는 "박스" — 머리 띠 36px(아쿠아 탭 라벨 + 오른쪽 "더보기 ›") + 몸 패딩 14/16px. 박스끼리 간격 16. 박스 반경 **12px**(작다 — 패널은 단단한 스킨 부품, 둥근 것은 버튼·구슬의 몫).
5. **반경 위계(같은 radius 금지)**: 스킨 프레임 20 · 박스 12 · 입력 10 · 탭 14/0 · 버튼 999(알약) · 아이콘·아바타·마커 50%(구슬). 이 다섯 개 이외의 값은 쓰지 않는다.
6. **밀도 리듬을 바꾼다**: 포털 구간은 촘촘(행 높이 40~44, 박스 간격 16) ↔ 장면 구간은 넓게(위아래 96px, 하늘이 보이는 빈 공간). index·pages 모두 촘촘 → 넓음 → 촘촘 교차.
7. **바탕화면 구간(full-bleed)**: 스킨을 잠시 벗어나 바탕화면 위에 바로 놓이는 구간을 페이지당 최대 1곳 허용 — 창(window) 몇 개가 언덕 위에 겹쳐 떠 있는 데스크톱 장면. 창은 위 모서리 10, 타이틀바 32px(광택) + 오른쪽 구슬 버튼 3개(최소화 앰버/최대화 라임/닫기 빨강, 각 지름 16, 터치 영역 44).
8. 360/390: 가로 스크롤 0. 탭 줄은 가로 스크롤 + 오른쪽 32px 하늘색 페이드 힌트.

## 6. 시그니처 (2개, 끝까지)

### 시그니처 A — 젤리 광택 캡 (Aqua gel)
모든 **누를 수 있는 것과 진행을 보여주는 것**은 젤리다:
- 몸통 세로 그라디언트(밝은 위 → 진한 아래) + **상단 42%에 흰 광택 캡**(위 .85 → 아래 .15 → 가장자리 투명 페이드, 좌우 6% 안쪽 들여, 위 모서리는 몸통 반경 -2) + 하단 반사광(`--gloss-floor`) + 1px 진한 림(몸통 바닥색 -12% 명도) + 바닥 그림자 `0 3px 6px rgba(10,60,110,.28)`.
- **가독성 규칙 (수정 1, 2026-10-11)**: 1차 결과에서 48%·.92 캡이 흰 글자 라벨('내 정보', '바로가기', '소다플레이어', '내 미니홈 가기', 가격 알약 등)의 윗부분을 녹였다. 시그니처가 가독성을 깎으면 안 되므로, 흰 글자 젤리(sky·red·창 바·박스 탭)는 라이트에서 캡 불투명도를 .5 / .4로 낮추고 글자 그림자를 `0 -1px 0 rgba(0,40,90,.55), 0 1px 2px rgba(0,40,90,.45)` 두 겹으로 받친다. 어두운 글자 젤리(라임·앰버·아쿠아·흰 젤리)는 원래 세기(.92) 그대로라 광택감은 유지된다. 호버는 캡을 1로 올리지 않고 15%만 증폭한다.
- 적용: 버튼(주요/보조/라임/앰버/위험), 아쿠아 탭(활성), 배지·상태 알약, 진행바 채움(+ 움직이는 사선 줄무늬), 스위치 레일과 썸, 슬라이더 썸, 페이지네이션 현재 쪽, 스텝 노드, 캘린더 오늘, 스크롤바 썸, 플레이어 버튼, 창 타이틀바, 툴팁 꼬리 없는 알약.
- 쓰지 않는 곳: 본문 박스 면, 표 셀, 입력칸 안쪽(입력은 오목하게 — 안쪽 그림자 `inset 0 2px 3px rgba(10,46,77,.18)`).
- 구현: `.gel` 유틸 + `--gel-top/--gel-bottom/--gel-ink` 세 변수만 바꿔 색 변주. `::before` = 캡, `::after` = 반사광.

### 시그니처 B — 구슬 (Orb) 마커 체계
모든 아이콘·아바타·순번·데이터 점은 **유리 구슬** 안에 산다:
- 구슬 = 원형 + 대각 radial 하이라이트(좌상단 30%/25% 지점 흰 타원) + 하단 색 짙어짐 + 림.
- 적용: 탭 아이콘, 로그인 박스 아바타(이니셜 구슬), 순위 번호(1~3위 앰버·하늘·라임 구슬, 4위 이하 작은 회청 구슬), 쪽지 읽음 표시, 차트 데이터 점, 타임라인 노드, 빈 상태 일러스트의 큰 물방울, 창 컨트롤 버튼, 로고 `sodanet`의 o.
- 배경 물방울(떠오르는 버블)도 같은 구슬 문법의 투명 버전 — 시그니처와 배경이 같은 언어.

> 이 두 개 외의 장식(별 반짝이, 렌즈 플레어, 크롬 금속 텍스트, 무지개 그라디언트)은 쓰지 않는다. 렌즈 플레어는 index 배너 1곳 예외.

## 7. 모션 문법 — "누르면 젤리, 놓으면 통통, 물방울은 위로"

| 이름 | 값 | 쓰임 |
|---|---|---|
| `--ease-spring` | `cubic-bezier(.34, 1.56, .64, 1)` | 놓을 때 복원, 토스트 등장, 박스 팝 |
| `--ease-out` | `cubic-bezier(.22, 1, .36, 1)` | 탭 이동, 드로어 |
| `--dur-press` | 90ms | 누름 |
| `--dur-release` | 420ms | 복원 |
| `--dur-ui` | 220ms | 호버·탭 |
| `--dur-pop` | 380ms | 등장(back.out 성격) |

- **누름(squash)**: `:active` → `transform: scale(1.04, .92)` 90ms, 캡 높이 42% → 40%. 놓으면 `--ease-spring` 420ms로 복원(살짝 튕김).
- **호버**: 2px 떠오름 + 캡 불투명도 .92 → 1 + 바닥 그림자 확장. 호버만으로 정보 노출 금지(ux 근거).
- **등장**: 포털 박스는 load 시 scale .92 → 1, y 16 → 0, 60ms 스태거(최대 8개), `back.out` 성격의 `--ease-spring`. 스크롤 리빌은 **쓰지 않는다**(v1처럼 블러로 멈춘 채 남는 사고 방지) — load 1회만.
- **물방울**: 배경 버블 12개(390은 6개)가 14~22s 동안 아래에서 위로 떠오르며 ±12px 흔들림, 위에서 사라질 때 opacity 0. 클릭 시 터지는 연출은 index 배너에서만.
- **진행바 줄무늬**: 사선 줄무늬 배경이 1.2s linear 무한 이동(Aqua 진행바).
- **실시간 검색어 티커**: 3s마다 한 줄씩 위로 넘김(세로 롤링), 호버·포커스 시 정지.
- **플레이어**: 재생 중 이퀄라이저 막대 7개가 서로 다른 주기(0.6~1.1s)로 오르내림. LCD 곡명은 왼쪽 정렬 정적 텍스트가 기본이고, 칸보다 길 때만 `0 → -(넘친 폭)`으로 천천히 왕복(약 28px/s). 오른쪽 밖에서 흘러 들어오는 마키는 빈 LCD에 글자 조각만 남기므로 쓰지 않는다. 자동 재생 페이지도 첫 사용자 입력 전까지 시계는 01:27에 멈춘다.
- **토스트**: "띠링" — 하단에서 수면 위로 떠오르듯 y 24 → 0 + scale .96 → 1, `--ease-spring`. 4.5s 뒤 가라앉음.
- **테마 전환**: 하늘 그라디언트가 600ms 동안 낮 → 밤으로 크로스페이드(배경 레이어 두 장 opacity 교차).
- `prefers-reduced-motion: reduce` → 버블·티커·마키·이퀄라이저·줄무늬 정지(정적 최종 상태 렌더), 스쿼시는 색 변화만, 등장 애니메이션 없음.

## 8. 32개 컴포넌트 처리 원칙

공통: 컴포넌트 CSS는 semantic 토큰만. 젤리 = `.gel`, 구슬 = `.orb`, 박스 = `.box`(머리 띠 + 몸). 터치 타깃 44px 이상. 아이콘은 인라인 SVG `currentColor`(stroke 1.8, 24 그리드, 둥근 끝 `stroke-linecap: round`) — 이모지 금지. SVG 속성에 `var()` 금지(`style=""` 또는 CSS 클래스).

- 랜딩 공식 첫 화면 전체: eyebrow 알약, "맑고 투명한 / 인터페이스의 표준" 2줄 헤드라인, CTA 3개, 기능 칩 3개, 날씨 위젯 카드.

- 회색 구슬 + 청록 안개 다크 모드. 다크는 별 뜬 밤 물가로 새로 설계.

- 폰트: Mulish · Hind · Do Hyeon · Noto Serif KR(미사용 import) · 시스템 고딕 폴백.
