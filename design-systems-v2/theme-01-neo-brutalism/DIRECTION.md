### 스타일의 원래 맥락 → 왜 이 클라이언트인가
네오 브루탈리즘(2020년 전후 Gumroad·Figma 계열 웹에서 대중화)은 2014년 brutalistwebsites.com의 "꾸미지 않은 웹"에서 왔고, 그 시각 재료(두꺼운 검정 선, 플랫 원색, 비뚤게 붙은 스티커, 블러 없는 그림자)는 더 거슬러 **펑크 진(zine)·복사기 공연 전단·가격표 라벨건**에서 왔다. 레코드샵은 이 재료가 장식이 아니라 **실물**인 곳이다: 판 위에 비뚤게 찍힌 가격 스티커, A–Z 칸막이가 꽂힌 크레이트, 벽에 겹겹이 붙은 공연 전단. v2는 이 실물을 UI로 옮긴다. "브루탈한 스타일의 SaaS"가 아니라 "레코드샵 벽과 계산대가 화면이 된 것".

### 시맨틱 — dark (`[data-theme="dark"]`) "공연 끝난 지하 1층" — 단순 반전 아님
v1처럼 흰 보더+흰 그림자로 뒤집지 않는다. 다크에서는 **그림자 색이 옐로(#FFD400)** 로 바뀐다(조명 꺼진 무대 위 형광 테이프). 규칙선은 `#F2F2F2`.

## 5. 레이아웃 문법 — "규칙선 벽보 그리드"

v1: 가운데 `.container`(같은 max-width) + 같은 섹션 패딩 + 간격 있는 카드 그리드의 수직 스택.
v2: **간격 0, 칸과 칸 사이가 3px 잉크 선인 풀블리드 그리드.** 매장 벽에 전단을 빈틈없이 붙인 것처럼 칸이 서로 선을 공유한다(카드 사이 여백이 없다).

1. **룰 그리드(`.wall`)**: 12단, `gap: 3px`, 컨테이너 배경 `var(--rule)`, 각 칸 배경 `var(--surface)` → 갭이 곧 규칙선. 외곽은 상하 3px 선만, 좌우는 화면 끝까지(풀블리드). 칸 내부 패딩 24px(데스크톱) / 16px(≤768).
2. **비대칭 스팬만**: 한 행의 분할은 7/5, 8/4, 9/3, 3/9, 5/7, 4/8 중에서. 4/4/4·3/3/3/3 균등 분할은 데이터 표와 캘린더 외 금지. 행 높이도 서로 다르게.
3. **세 가지 섹션 리듬을 번갈아** (같은 리듬 두 번 연속 금지):
   - (A) **벽보** — 룰 그리드 칸 구성.
   - (B) **슬랩** — 한 색(레드/옐로/잉크) 면이 화면 폭 전체를 채우는 띠. 위아래 3px 선, 세로 패딩 72px(데스크톱)/48px(모바일). 내용은 왼쪽 정렬, 오른쪽 3단은 비워 둔다.
   - (C) **크레이트 인덱스** — 왼쪽 3단 고정(sticky top 72px) 인덱스 열 + 오른쪽 9단 본문. 인덱스 열은 칸막이 탭(시그니처 2).
4. **섹션 머리 = 카탈로그 행**: 높이 최소 72px의 한 줄 행. `[2단: 모노 번호 PP-03] [7단: Gasoek 제목 --fs-d2] [3단: 모노 메타 "부품 32 · 10.08 수정"]`. 전부 왼쪽 정렬. **가운데 정렬 섹션 헤더·부제 금지.** 섹션 소개 문단은 붙이지 않는다(필요하면 7단 칸 안 1문장).
5. **크롭**: mega 타이포는 칸 밖으로 넘쳐 오른쪽에서 잘린다(`overflow: clip`은 섹션 단위로 — 페이지 가로 스크롤 0).
6. **여백 스케일(4px 기반)**: `4 8 12 16 24 32 48 72 120`. 섹션마다 다른 값을 쓴다: 벽보 0(칸 패딩만), 슬랩 72, 인덱스 48.
7. **본문 폭**: 읽는 글은 `max-width: 62ch`. 칸이 넓어도 글은 왼쪽에 붙는다.
8. **반응형**: ≤1024 8단(스팬 비율 유지: 7/5→5/3), ≤768 4단, ≤480 1단(숫자 칸만 2단). 규칙선은 모든 폭에서 유지. 360/390에서 스티커 회전각은 절반, 오프셋 겹침은 4px 이하로.
9. 헤더(`navbar`)도 룰 그리드: 워드마크 칸 | 메뉴 칸들 | 검색(⌘K) 칸 | 테마 토글 칸 — 각 칸이 세로선으로 나뉜 한 줄. 메뉴는 모든 화면이 같은 8칸(01 운영 … 08 설정, index '장면 9' 번호와 같음), 남는 폭은 메뉴 칸이 나눠 가져 빈 칸이 없다.
10. **벽보 칸 높이를 맞춘다(수정 1)**: 한 행의 두 칸 높이 차가 크면 짧은 쪽 아래가 비어 미완성으로 읽힌다. ① 짧은 부품 둘을 세로로 쌓아(`row-2`) 긴 칸 옆에 붙이거나 ② 남는 칸을 옐로·잉크 **전단**(계산대 옆 매입 벽보, 판판 라이브 #118 포스터 등 세계 안의 인쇄물)으로 채워 빈 면이 의도된 면이 되게 한다.
11. **바닥글**: pages는 같은 `.site-foot` 하나 — [7 잉크 칸: PANPAN · 주소 · 요일별 영업시간 · 매입][5 장면 지도 10칸, 현재 화면 옐로]. 마지막 섹션 3px 선에 여백 없이 붙는다.

## 6. 시그니처

### 시그니처 1 — 가격 스티커 (라벨건 스티커)
중고 판에 비뚤게 찍힌 가격표. **"붙어 있는 정보"는 전부 이 형태.**
- 형태: 직사각형, radius 0, 보더 2px `--rule`, 배경 `--highlight`(기본) / `--accent`(매진·위험) / `--surface`(중립), 글자 Plex Mono 600 12–14px, 패딩 4px 8px.
- 회전: `--tilt` 값 집합 `-4deg, -2deg, 3deg` 중 요소별 고정(nth-child 순환). 랜덤 금지.
- 그림자: `3px 3px 0 var(--shadow-ink)` (스티커만 3px).
- 위치: 부모 모서리에 걸쳐 겹친다 — `position:absolute; top:-12px; right:-8px` (모바일 -8/-4).
- 적용: 상품 카드 가격(`₩38,000`)·등급(`NM`), 상태 배지(표 안에서는 회전 0·그림자 0, 붙는 위치에서만 회전), 툴팁(화살표 없는 스티커), 토스트(우상단에 찍힘), 캘린더 매진일(`매진` 레드 스티커), 칸반 카드 라벨, pricing 가격, 404 코드, index 표지의 판수 스티커.

### 시그니처 2 — 크레이트 칸막이 탭
레코드 상자 안 A–Z 칸막이가 위로 튀어나온 모양. **"고르는 내비게이션"은 전부 이 형태.**
- 형태: 탭 손잡이가 패널 위 모서리에서 12px 튀어나온 사다리꼴 없이 직사각형, 손잡이 폭은 내용에 맞추되 위치는 엇갈림(첫 탭 left 0, 이후 탭은 앞 탭 끝 +3px). 비활성 탭 높이 44px(터치 타깃 하한, 수정 2에서 40→44) / 배경 `--surface-2`, **활성 탭 높이 56px(12px 더 솟음) / 배경 `--highlight` / 아래 보더 없음 → 패널과 이어짐.**
- 손잡이 글자: 모노 인덱스(`A`, `07`) + Plex 700 이름.
- 적용: tabs(가로), sidebar(세로 — 탭이 오른쪽으로 12px 튀어나옴), accordion(각 항목 머리가 칸막이, 펼친 항목만 솟음), pagination(번호가 칸막이 손잡이), index 부품 인덱스 열, settings 섹션 내비, inbox 폴더.

### 공통 재료 (시그니처 아님 — 위계 규칙)
- 하드 섀도 `6px 6px 0 var(--shadow-ink)`는 **누를 수 있거나 떠 있는 것에만**: 버튼, 링크 카드(포스터), 모달·드로어·팝오버·메뉴·커맨드·토스트. **정적 컨테이너(패널·표·폼 그룹)는 보더만, 그림자 없음.** (v1의 "모든 박스에 같은 그림자" 폐기)
- 보더: 기본 3px, 칸 내부 하위 구분 2px, 표 행 구분 2px. 1px 금지.
- radius 0. 예외는 원형 물체뿐: 레코드 스피너, 라디오.
- 배경 텍스처(점·격자·노이즈·radial) 금지. 색 면 아니면 흰 종이.
- **사이드 스트라이프 금지(수정 1)**: 카드·인용·변경 필드 왼쪽의 색 띠/inset 막대는 AI 대시보드 버릇이다. '오늘 처리'는 레드 `오늘` 스티커, '변경'은 라벨 옆 옐로 `변경` 스티커, 인용은 Gasoek 큰 따옴표로.

## 7. 모션 문법 — "찍고, 누르고, 돈다"

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--t-press` | `90ms` | 버튼·링크 카드 눌림 |
| `--t-snap` | `140ms` | 탭 솟음, 아코디언, 드로어 이동 |
| `--t-stamp` | `220ms` | 스티커·토스트·모달 등장 |
| `--ease-snap` | `cubic-bezier(.2, 0, 0, 1)` | 이동 |
| `--ease-stamp` | `cubic-bezier(.3, 1.5, .5, 1)` | 스탬프(살짝 튕김) |
| `--spin-33` | `1.8s linear infinite` | 레코드 스피너 (33⅓rpm) |

1. **프레스**: hover `translate(-2px,-2px)` + 그림자 8px / active `translate(6px,6px)` + 그림자 0 (그림자 속으로 박힘). 
2. **스탬프**: 등장 = `scale(1.3) rotate(calc(var(--tilt) + 8deg))` → 최종 `scale(1) rotate(var(--tilt))`, `--t-stamp --ease-stamp`. **opacity 페이드 없음**(0→1 즉시). 토스트·모달·스티커·성공 체크.
3. **칸막이 솟음**: 탭 활성화 시 높이 44→56px `--t-snap`.
4. **드로어/모달 배경**: `rgba(17,17,17,.72)` 단색, 즉시 표시(페이드·blur 없음).
5. **마퀴는 1곳만**: 사이트 최상단 "오늘 입고 / 이번 주 공연" 띠. 48s linear, hover·focus-within 일시정지.
6. 금지: 스크롤 리빌, 페이드-업 스태거, 패럴랙스, 바운스 반복.
7. **prefers-reduced-motion**: 스탬프·솟음·드로어 이동은 최종 상태로 즉시, 프레스는 그림자 변화만(이동 없음), 마퀴는 정지된 한 줄, 스피너는 회전 대신 라벨 "불러오는 중"과 3단계 점 깜빡임 없이 정적.
