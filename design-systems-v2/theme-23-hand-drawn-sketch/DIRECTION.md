## 1. 클라이언트와 세계관

**클라이언트: 끄적** — 한국 스타트업 기획자·디자이너가 쓰는 손그림 와이어프레임 및 화이트보드 협업 툴 (운영사 끄적랩 주식회사).
화면 위에 포스트잇을 붙이고, 마커로 와이어를 그리고, 결정 사항에 빨간 동그라미를 치는 일을 온라인에서 하는 서비스다.

- **스타일의 원래 맥락**: 회의실 화이트보드 위의 기획 세션, 냅킨 스케치, 그리고 2008년 Balsamiq Mockups 이후 굳어진 "로파이 와이어프레임" 관습이다. 일부러 덜 다듬은 선은 "아직 결정 전이니 마음껏 고쳐도 된다"는 신호다. 장식 취향으로 고른 스타일이 아니다. 이 툴이 하는 일 자체가 손그림이어서 세계관과 매체가 같다.
- **데모 속 고객사**: 끄적을 쓰는 팀으로 **모락**(동네 반찬가게 픽업 주문 앱)의 프로덕트팀을 둔다. 모든 페이지는 모락 팀이 10월 스프린트 24에서 실제로 끄적을 쓰는 장면이다.
- **감정 톤 (한 문장)**: 회의가 막 끝난 화이트보드 앞, 마커 뚜껑이 아직 열려 있고 빨간 동그라미 친 결정 사항이 남아 있는, 들뜨고 손이 바쁜 몰입감.
- 첫 화면 1초 안에 드러나야 하는 것은 기술 문서의 정갈함이 아니다. 사람이 방금 쓴 손글씨, 기울어진 포스트잇, 화살표의 속도감이다.

## 4. 팔레트

### 원칙
- **실제 보드마커 4색 + 포스트잇 4색 + 형광펜 1색.** v1의 펜 6색 + 형광펜 3색은 버린다.
- 마커 색은 역할이 고정이다: **검정 = 글·선**, **파랑 = 실행(primary)**, **빨강 = 주석·지적·위험**, **초록 = 확정·완료**. 빨강을 버튼 장식에 쓰지 않는다.
- 포스트잇은 종이라서 다크에서도 뒤집지 않는다. 밤 조명 아래 살짝 어두워질 뿐 위의 글씨는 계속 검정 잉크다.

## 6. 레이아웃 문법 — "점 격자 위의 클러스터"

이 테마만의 규칙. 01(포스터 블록), 02(스위스 그리드), 30(좌측 목차 문서)과 겹치지 않게 한다.

1. **보드 = 풀블리드 면, 단위는 24px 점 격자.** 페이지 배경 전체가 `--board` + 24px 간격의 1.2px 점이다(`radial-gradient` 1.2px 원, 번진 얼룩이 아닌 기능적 격자). 모든 요소의 x·y·크기는 24의 배수에 맞춘다. 데스크톱 1440은 60칸이다.
2. **중앙 max-width 컬럼을 쓰지 않는다.** 콘텐츠는 왼쪽 48px(모바일 16px)에서 시작해 오른쪽으로 자유롭게 배치한다. 섹션마다 점유 폭이 다르다(예: 보드① 60칸 전폭, 보드② 왼쪽 34칸 + 오른쪽 여백에 주석, 보드③ 와이어 3대가 18·18·18칸).
3. **클러스터 + 화살표.** 관련 요소는 클러스터(포스트잇 무리, 와이어 프레임 묶음)로 모으고 클러스터 사이는 SVG 화살표로 잇는다. 클러스터 안은 촘촘하게(8–12px, 포스트잇끼리 최대 12px 겹침 허용), 클러스터 사이는 넓게(데스크톱 최소 96px, 모바일 48px). 빈 공간이 "생각할 자리"로 읽혀야 한다.
4. **회전 위계.** 와이어 프레임·표·폼(정보 영역)은 0deg로 똑바로 둔다. 포스트잇은 `--tilt` 순환(−2.5, 1.5, −1, 2, −0.5deg), 주석·테이프는 −4~3deg. 텍스트 입력이 있는 요소는 회전하지 않는다.
5. **제목은 항상 왼쪽 위에서 쓴다.** 가운데정렬 섹션 헤더는 금지한다. 제목은 마커 글씨 + 손으로 그은 밑줄(SVG path)이고, 제목 옆에 날짜나 담당자를 메모 글씨로 단다("10/14 서윤").
6. **섹션 구분 = 보드 장 넘김.** 섹션 사이에 3px 마커 가로선을 손떨림 path로 긋고, 그 왼쪽 끝에 테이프로 붙인 보드 이름표("보드 2 · 글씨")를 둔다. "§ 번호"와 가운데 라벨은 쓰지 않는다.
7. **모바일(≤ 640px)**: 점 격자는 유지하고 클러스터를 세로로 쌓는다. 회전은 ±1deg로 줄이고 가로 화살표는 아래 방향 화살표로 바꾼다. 겹침은 텍스트를 가리면 해제한다. 좌우 16px 거터, 가로 스크롤 0.
8. **앱 페이지(pages/*)의 셸**: 끄적 앱 화면이다. 상단 툴바 navbar(56px) + 데스크톱 왼쪽 보드 목록 sidebar(264px, 접힘 72px) + 본문 캔버스. 본문 안에서는 같은 클러스터 문법을 쓴다. 셸 마크업은 COMPONENTS.md에 복사용 스니펫으로 고정한다(2단계).

## 7. 시그니처

### 시그니처 A — 두 번 그은 윤곽선 (Double Stroke)
펜으로 박스를 그리면 한 번에 닫히지 않고 선이 두 겹으로 살짝 어긋난다. 이를 모든 윤곽에 쓴다.
- 구현: 요소 `border: 2px solid var(--ink)` + `border-radius: var(--r-wobble-a)`. `::before`는 `inset: -3px 1px -1px -2px`, `border: 1.5px solid var(--ink)`, `border-radius: var(--r-wobble-b)`, `opacity: .45`, `transform: rotate(.4deg)`, `pointer-events:none`.
- radius 토큰 3종 (이웃 요소에 순환):
  - `--r-wobble-a: 14px 22px 16px 24px / 22px 14px 24px 16px`
  - `--r-wobble-b: 22px 12px 26px 14px / 14px 24px 12px 22px`
  - `--r-wobble-c: 10px 18px 12px 20px / 18px 10px 20px 12px`
  - `--r-blob: 58% 42% 55% 45% / 46% 56% 44% 54%` (아바타·원형 버튼·동그라미)
- 적용: 버튼, 입력창, 와이어 프레임(카드), 모달, 드로어 가장자리, 표 바깥선, 탭 활성 탭, 캘린더 오늘 칸, 커맨드 팔레트.
- 미적용: 포스트잇(종이라서 윤곽선 없음), 텍스트 링크, 리스트 행 사이(1px 점선).

### 시그니처 B — 빨간 마커 주석 (Circle & Arrow Memo)
기획자가 결정 사항에 동그라미를 치고 화살표로 메모를 다는 행동이 **이 디자인 시스템의 상태 표현 언어**다.
- 부품: `memo-circle`(불규칙 타원 SVG path, 3px, `--marker-red`, 시작과 끝이 겹치게 열린 고리), `memo-arrow`(곡선 화살표 3종 path), `memo-note`(Nanum Pen Script 26px, `--marker-red`, −3deg).
- 어디에 쓰나:
  - **focus-visible**: 포커스 링을 3px 빨간 손그림 고리(outline이 아니라 `::after` 불규칙 radius 링, offset 4px)로 그린다. 키보드 사용자가 "지금 여기"를 동그라미로 본다.
  - **선택·현재**: 활성 탭, 현재 페이지(페이지네이션·브레드크럼·사이드바)에 동그라미를 친다.
  - **에러**: 입력창에 빨간 동그라미 + 화살표 + 메모("이메일 형식이 아니에요").
  - **새 항목·중요**: 배지 "NEW" 대신 동그라미 친 "새로"와 손글씨.
  - **차트 이상치**: 10월 8일 급증점 동그라미 + "디자인 리뷰날!".
- 남발 금지: 한 화면(뷰포트)에 동그라미 주석은 정적인 것 최대 3개. focus와 에러는 예외.
- SVG 색은 `currentColor` 또는 `style="stroke:var(--marker-red)"`만 쓴다(presentation attribute에 var() 금지).

### 재료 (시그니처를 받치는 물성)
- **포스트잇**: 콘텐츠를 나르는 기본 카드. 윤곽선 없이 면만 있고, 아래쪽 모서리 그림자 `0 10px 12px -10px rgba(31,35,40,.35)`로 살짝 들뜬다. 76×76 단위(24 격자에서 3칸 + 여유)의 배수 크기. 위쪽 18px은 접착 띠라 색이 4% 진하다.
- **마스킹 테이프**: 프레임이나 스크린샷 견본을 보드에 붙이는 용도로만 쓴다. 64×22px, `--tape`, −4~5deg, 양 끝은 지그재그 `clip-path`.
- **점 격자**와 **마커 트레이**(index 첫 화면 하단에 CSS로 그린 마커 4자루) 외의 장식은 없다. 커피 얼룩, 별, 낙서 버스트, 터뷸런스 필터는 쓰지 않는다.

## 8. 모션 문법 — "지금 손으로 그리는 중"

| 오버레이 | 모달·드로어·커맨드 팔레트 | 모달: 종이를 보드에 대듯 `scale(.97) rotate(-.6deg) → 1 0deg` 220ms. 드로어: 오른쪽에서 밀려 들어옴 260ms `cubic-bezier(.2,.8,.2,1)`. 백드롭은 블러 없이 `--board` 72% | |

- 금지: 페이드-업 일괄 리빌, 패럴랙스, 블러, 스프링 바운스 남용(포스트잇 붙이기 외).
- `prefers-reduced-motion: reduce`이면 모든 애니메이션 duration 0. 선은 다 그려진 상태, 형광펜은 칠해진 상태, 포스트잇은 제자리에 둔다.

1. **첫 화면 — 보드 전체 (뷰포트 1장, 전폭)**
