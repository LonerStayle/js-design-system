## 1. 클라이언트 · 세계관

### 윤슬홈 (워드마크 `yunseul home`, 한글 표기 "윤슬홈")
신축 아파트에 기본 설치되는 **스마트홈 허브 + 앱**. 조명·공조·도어락·가전·에너지를 거실 벽 패널과 휴대폰에서 한 판의 위젯 보드로 다룬다. "윤슬"은 햇빛·달빛이 물결에 부서져 반짝이는 빛 — 강변 단지의 통창, 그 앞에 떠 있는 유리 패널이라는 이 테마의 이미지와 그대로 겹친다.

- **스타일의 원래 맥락**: 유리 UI의 계보는 Windows Vista Aero(2007) → iOS 7 제어 센터의 반투명 블러(2013) → macOS Big Sur 위젯·제어 센터(2020) → visionOS 공간 유리(2023)다. 공통점은 **유리 뒤에 "진짜 배경"(배경화면, 사진, 현실 공간)이 있고**, 패널은 그 위에 깊이 순서대로 떠 있다는 것. 장식용 보라 얼룩이 아니다.
- **그래서 이 클라이언트**: 스마트홈 벽 패널은 유리 UI가 실제로 쓰이는 몇 안 되는 국내 제품 맥락이다. 유리 뒤의 배경 = **거실 통창 밖 강변 풍경**(CSS/SVG로 그림). 라이트는 노을 17:42, 다크는 같은 창의 밤 22:40.
- **감정 톤 (한 문장)**: *해 질 녘 거실 통창 앞에서 손끝으로 빛을 만지는, 차갑지 않은 첨단의 고요함.*
  — 첫 화면 1초 안에: 따뜻한 노을빛이 젖빛 유리를 통과해 번지고, 거대한 얇은 시계 숫자와 불 켜진 조명 타일이 보인다.

## 5. 레이아웃 문법 — "셀 보드 + 3단 깊이"

1. **셀 그리드(스프링보드)**: 모든 위젯은 정사각 셀 단위로만 크기를 갖는다.
   - 데스크톱 ≥1200: 12열, 셀 84px, 간격 16px → 보드 폭 1,184px
   - 태블릿 768–1199: 8열, 셀 76px, 간격 14px
   - 모바일 <768: 4열, 셀 = `(100vw − 32px − 36px) / 4` (390 → 80.5px, 360 → 73px), 간격 12px
   - 위젯 크기: **S 1×1**(원형 토글) · **M 2×1**(알약) · **L 2×2** · **W 4×2** · **T 1×2**(세로 슬라이더) · **XL 4×4** · 리스트 패널 6×N(데스크톱만, 모바일은 4×N)
   - `grid-auto-flow: dense`로 빈 칸 0. 칸 높이는 셀 배수라 벽보형 공백이 원천적으로 안 생김.
2. **3단 깊이(Z층)**: z0 장면(`position: fixed`, 전체 뷰포트) → z1 보드 바탕 유리 → z2 위젯·패널 → z3 오버레이. 그림자 크기·블러가 층을 말한다 — 같은 층은 같은 값, 다른 층은 반드시 다른 값.
3. **동심 반경 규칙**: 안쪽 반경 = 바깥 반경 − 패딩. 시트 40px(패딩 16) → 위젯 24px(패딩 12) → 안쪽 컨트롤 12px → 칩 8px. S 타일은 원, M은 알약. "모든 것에 같은 radius" 금지의 구조적 해법.
4. **가운데 정렬 컨테이너 금지**: 섹션마다 보드의 위치가 바뀐다 — 오른쪽 정렬(히어로) · 왼쪽 가장자리 넘침(재료) · 전체 폭(규격) · 겹침 2판(컨트롤) · 후퇴 판(오버레이) · 좌우 분할(알림). 바깥 여백 데스크톱 56px / 태블릿 32px / 모바일 16px.
5. **겹침**: 각 섹션에서 최소 1개 패널은 다른 패널 모서리를 `translate(−24px, 32px)`만큼 덮는다(z2가 z1 위). 모바일은 겹침을 −12px로 줄이고 가로 넘침 0 유지.
6. **크롬은 OS처럼**: 위쪽 = **상태 바**(navbar), 아래쪽 = **독**(전 페이지 공통 이동). 섹션 헤더는 OS 그룹 라벨(13px 600, 보드 안 좌상단)로만 — 가운데 정렬 "라벨→제목→부제" 금지.

## 6. 시그니처 (2개, 끝까지)

### 시그니처 A — 빛 림 + 스윕 (광원 좌상단 150°)
- 모든 유리 면 공통 믹스인 `.glass`: `background: var(--sheen-top), var(--glass-N)`(윗변 12px `rgba(255,255,255,.55)→0` 반사, 다크 .08) + `backdrop-filter: blur(Npx) saturate(170%)`(z1 180%) + `::before`로 **1.5px 그라디언트 테두리**(`--rim`, 광원 쪽 0% 정지점 알파 1, `mask: … content-box exclude …`) + `box-shadow: inset 0 1px 0 rgba(255,255,255,.6)`(다크 .18) 윗변 반사 + 바깥 1px 빛 테 `0 0 0 1px rgba(255,255,255,.35)`(다크 .06).
- 층 그림자는 확실히 벌린다: z1 `0 8px 16px` · z2 `0 24px 48px` · z3 `0 48px 80px`(음수 퍼짐으로 판 밖으로 번지지 않게). 같은 층 같은 값.
- 텍스트 없는 z1(보드 바탕·도해 판)은 `.glass--bare` `.40`(다크 .38) — 뒤 장면이 더 비쳐 z2 위젯(.72)과 두 층으로 갈린다. 홈 보드(dashboard)는 위젯 격자 뒤에 이 바탕판을 깐다. 텍스트가 있는 z1은 `.48` 유지(대비 기준).
- 광원은 장면 속 해(라이트, 좌측 낮게) / 도시 불빛(다크, 아래) 위치와 일치 — 림이 가장 밝은 모서리는 라이트 좌상단, 다크는 좌상단 약하게 + 아래 모서리 앰버.
- **스윕**: hover/focus-visible 시 `::after`에 `linear-gradient(105deg, transparent 38%, rgba(255,255,255,.38) 50%, transparent 62%)`가 `translateX(−120% → 120%)` 900ms 한 번 지나감. 버튼·타일·카드·탭·독 아이콘 전부 동일. 감속 모션 → 스윕 없음, 림 밝기만 +10%.
- 적용: 버튼, 위젯, 입력, 탭 선택 알약, 모달, 드로어, 토스트, 독, 상태 바, 칸반 카드, 표 패널 — 유리인 모든 것.

### 시그니처 B — 깊이 후퇴 (Recede)
- z3 오버레이(모달·드로어·커맨드·시트·메뉴 시트)가 열리면 `.app[data-receded]`: 뒤 보드 `transform: scale(.955) translateY(8px)` + `filter: blur(3px) brightness(.9) saturate(.85)`, 장면은 `brightness(.82) blur(8px)` — `.app` 의 filter 가 안쪽 유리의 backdrop root 가 되어 장면을 못 흐리므로, 장면 쪽을 함께 흐려 뒤 판들이 계속 서리 유리로 읽히게 한다. 오버레이는 `scale(1.04) → 1`, `opacity 0 → 1`.
- 곡선 `cubic-bezier(.32,.72,0,1)`(시트 곡선) 420ms. 닫힘 300ms.
- index에서는 **후퇴한 보드 위에 열린 모달**을 정적으로 렌더한 견본 + 실제 트리거를 둔다.
- 켜진 상태 규칙(보조): 활성 타일은 유리에서 **불투명 판(`--tile-on`)으로 바뀌며 빛난다**(라이트: 흰 판 + 앰버 글리프, 다크: 밝은 판 + 앰버 글로우). "켜짐 = 유리가 불투명해진다"는 OS 제어 센터 문법.

## 7. 모션 문법 — "떠오르고, 물러나고, 빛이 지나간다"

| 이름 | 값 | 쓰임 |
|---|---|---|
| `--ease-sheet` | `cubic-bezier(.32,.72,0,1)` | 시트·모달·드로어·후퇴 |
| `--ease-pop` | `cubic-bezier(.34,1.56,.64,1)` | 위젯 등장, 토스트 배너 낙하 |
| `--ease-out` | `cubic-bezier(.22,1,.36,1)` | 일반 상태 변화 |
| `--dur-press` | 110ms | 누름 `scale(.96)` |
| `--dur-quick` | 180ms | hover, 토글 노브 |
| `--dur-sheet` | 420ms | 오버레이 등장·후퇴 |
| `--dur-sweep` | 900ms | 빛 스윕 |

- 등장: 위젯 `opacity 0, scale(.92), translateY(16px)` → 1, 60ms 간격(`--i` 변수), `.js-ready`일 때만 숨김.
- 토글: 노브 180ms, 켜짐 시 타일 면이 유리→불투명으로 180ms 크로스페이드 + 글로우.
- 세로 슬라이더(조명 밝기): 채움 높이 실시간, 손 뗄 때 `--ease-pop`으로 2px 튕김.
- 토스트 = OS 알림 배너: 상단에서 `translateY(−120%) → 0` `--ease-pop`, 쌓이면 뒤 배너 `scale(.95)` 깊이 스택.
- 장면: 포인터 패럴랙스 배경만 ±12px, 시계는 분마다 갱신(숫자 교체 fade 200ms).
- `prefers-reduced-motion: reduce`: 등장·스윕·패럴랙스·튕김 제거, 후퇴는 transform 없이 밝기만, 모든 전환 ≤120ms opacity.

## 9. index.html 구성안 — "윤슬홈 벽 패널, 주원네 집 17:42" (OS 컨트롤 센터 / 위젯 보드)

전체가 **하나의 창 앞 공간**이다. z0 장면은 고정, 스크롤하면 보드들이 장면 위로 지나간다. 섹션 이동은 제목이 아니라 **보드의 위치·크기·깊이**가 바뀌는 것으로 느끼게 한다.

1. **잠금 해제 직후 제어 센터 (100svh)** — 장면 전면(노을 하늘·해·강·스카이라인). 왼쪽 하단 1/3: 거대 시계 `17:42`(라이트) / `22:40`(다크) + "10월 10일 토요일" + "맑음 17° · 일몰 18:03". 오른쪽: 4×6 셀 **제어 센터 보드** — 연결 2×2(허브 온라인·외출 모드·방해금지·카메라 S 타일 4개), 거실 메인등 T 세로 슬라이더(70%), 무드등 T(40%, 앰버 글로우), 온도 L "23.5°" 게이지, 장면 M×3(귀가 활성·영화·취침), 거실 스피커 W, 도어락 M "잠김". 보드 위로 알림 배너 하나가 모서리를 덮으며 떠 있다("16:20 택배가 무인택배함 B-12에 도착했어요"). eyebrow·헤드라인·CTA 없음. 390: 시계 위, 보드 4열 아래.
2. **유리의 재료** — 왼쪽 가장자리를 넘쳐 나가는 **분해된 유리 3장 + 맨 아래 z0 장면판**(해·스카이라인·무드등·굵은 시각 — 위 판이 덮은 만큼 흐려진다). 각 층 콜아웃 오른쪽에 같은 대상을 그 층의 실제 blur·불투명도로 본 원형 렌즈(z0 또렷 → z3 거의 흰 판). '빛과 움직임' 림 견본은 장면 크롭 위 z2 유리판(광원 쪽 1.5px 림, 105° 스윕 중간 프레임 정지 렌더), 이징 칩은 곡선 글리프 + 같은 시간 간격 잔상 점 5개. 390에서는 층/빛/하늘/대비 4장을 가로 스냅 선반으로 접고 대비 표는 기본 접힘.(z1/z2/z3를 `rotateX(56deg) rotateZ(-36deg)` 등각으로 띄워 쌓음), 각 판 옆 콜아웃: blur 16/24/40, 불투명도 .48/.72/.84, 림, 그림자. 오른쪽: **하루의 하늘 띠** — 06:00→22:40 시간 눈금 가로 띠에 장면 색 토큰을 시간대로 배치, 17:42(라이트)·22:40(다크) 표시 핀. 색 토큰 = 시간의 색. 아래 작은 대비 표(유리 합성면 × 텍스트 4종).
3. **위젯 규격 (스프링보드)** — 전체 폭, 셀 격자를 옅은 점으로 노출. 실제 위젯으로 크기 S/M/L/W/T/XL을 채우며, 각 위젯이 타입 스케일 한 단계를 보여준다(XL에 `--t-readout-xl` "23.5°", W에 에너지 "₩28,940", L에 캘린더 등). 한 L 위젯에 **동심 반경 규칙** 도해(40→24→12→8 중첩 사각과 수치).
4. **컨트롤 시트** — 겹친 두 판: 뒤 z1 "거실" 기기 판(타일 토글·세로 슬라이더·스테퍼·스위치), 앞 z2 시트가 그 모서리를 덮으며 "방문 차량 등록" 폼(정상/포커스/오류/비활성 + 세그먼트 + 체크·라디오) 과 버튼 4종(귀가 장면 실행 / 기기 상세 / 전원 끄기 / 다시 연결). 탭(방 필터)·브레드크럼·배지가 시트 상단에. 두 판의 높이 차는 **계단**으로 흡수한다: 데스크톱에서 뒤 판은 64px 아래에서 시작하고 앞 시트가 위에서 그 오른쪽 모서리를 덮는다. 보드가 6열로 펼쳐지는 ≥1380에서는 뒤 판에 세로 슬라이더 T 2개(메인등 70%·무드등 40%) + 거실 공기 W(습도 46%·CO₂ 640ppm·초미세먼지 9)를 더해 시트와 바닥을 맞춘다(왼쪽 아래 빈 하늘 금지).
5. **오버레이 층** — '물러남' 견본도 추상 도형이 아니라 실제 위젯(조명 T 2 · 귀가 M · 온도 S · 도어락 S)을 축소 렌더한 미니 보드 + 토글. 0.955로 **후퇴한 미니 보드 위에 열린 모달** "현관 문을 열까요?" 정적 견본(시그니처 B). 그 오른쪽에 열린 드로어(무드등 L2 상세), 열린 커맨드 팔레트("세탁" 검색, 결과 3 + 빈 결과 견본), 컨텍스트 메뉴, 팝오버(색온도), 툴팁이 공간 콜라주로 겹쳐 있다. 각 견본 옆 "열어 보기" 실제 트리거.
6. **알림 센터 · 집 기록** — 좌우 분할 7:5. 왼쪽: 기기 표(12행, 정렬·상태 알약·페이지 점) 넓은 유리. 오른쪽: 알림 배너 스택(토스트 3 + alert 2) 과 오늘 타임라인, 진행률(펌웨어 62%·필터 8% 링), 스피너·스켈레톤(카메라 로딩), 빈 상태(서재). 상단 마키 공지 띠. 장면 미리보기 캐러셀과 자동화 코드 블록, 미니 칸반이 아래 줄. 미니 칸반은 kanban.html 과 같은 **4열(할 일 4 / 진행 중 3 / 확인 필요 2 / 완료 1)**, 높이가 맞도록 할 일 열만 위 3장 + '1건 더' 링크. 두 열 높이가 어긋나 큰 빈 하늘이 생기지 않게 판을 옮겨 맞춘다(욕실 배터리 띠 경고는 왼쪽 방 아코디언 위).
7. **독 (전 페이지 공통)** — 화면 하단 고정 유리 독: 런치패드(index) + 앱 8개(404 제외 — 오류 화면은 1급 앱이 아니다. index 앱 서랍과 설정 위험 영역 링크로만)를 원형 사각 아이콘(56px, 모바일 44px 가로 스크롤 + 페이드)으로. 아이콘마다 hover/focus 툴팁 라벨. 마지막 섹션 끝에는 독 대신 "앱 서랍" — 9개 장면 아이콘을 크게(각 아이콘 안에 그 페이지 미니 장면 CSS 그림) 펼친 런치패드형. 푸터는 한 줄: "윤슬홈 허브 H2 · 펌웨어 4.2.1 · 윤슬힐 104동 1802호".
