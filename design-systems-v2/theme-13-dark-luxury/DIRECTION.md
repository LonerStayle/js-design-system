## 1. 클라이언트 · 세계관

### 스타일의 원래 맥락
- 다크 럭셔리의 원형은 **하이주얼리·고급 시계 메종의 캠페인 룩북과 매장 진열**이다. 검은 벨벳 트레이, 조도를 낮춘 살롱, 스포트라이트 한 줄기, 보석이 빛을 받아 튀기는 반짝임(글린트). 인쇄 룩북은 한 펼침면에 오브젝트 하나, 귀퉁이에 작품번호·소재·캐럿만 적힌 캡션, 그리고 마지막 몇 장에 전 작품 목록과 가격표 삽지가 들어간다.
- 시계 쪽 문법: 다이얼의 인덱스 눈금, 초침의 스윕, 무브먼트(칼리버) 번호, 한정 시리얼 `No. 5/7`.
- 핵심 어휘: **어둠(여백) · 빛 하나 · 백금 헤어라인 · 아주 작은 캡션 · 느린 시간.**

### 클라이언트 (한국, 가상) — 윤슬 YUNSEUL · 하이주얼리 & 워치 메종
**윤슬**은 1987년 세공 장인 윤해담이 종로 귀금속 골목 작업대 하나로 시작해, 지금은 **청담 메종(판매·살롱)과 성수 아틀리에(제작)**를 둔 한국 하이주얼리·시계 메종이다. 이름은 "햇빛·달빛에 반짝이는 잔물결"이라는 순우리말에서 왔다. 2026년 가을, 물을 주제로 한 하이주얼리 컬렉션 **「물비늘」**(유니크 피스 12점)과 시계 컬렉션 **「자정 子正」**(레퍼런스 3종)을 공개한다.
디자인 시스템은 **고객용 컬렉션 사이트(룩북·작품 상세·예약·소장가 계정)**와 **메종 내부 도구(클라이언트 어드바이저의 살롱 장부·서신함·아틀리에 공정 보드)**가 함께 쓴다.

어울리는 이유: 하이주얼리는 어두운 곳에서 빛 하나로 판다. 다크 모드가 "취향"이 아니라 **업무 조건**(프라이빗 살롱의 낮은 조도, 밤 프리뷰)이다. 이름 "윤슬" 자체가 이 테마의 시그니처(어둠 위 빛의 반짝임)를 설명한다.

### 감정 톤 (한 문장)
**불을 낮춘 살롱, 조명 하나가 백금 링 위에서 잔물결처럼 반짝이는 순간 — 아무도 소리 내지 않고, 시간은 초침처럼 천천히 흐른다.**

## 3. 팔레트

원칙: **UI는 무채색 + 백금 + 따뜻한 빛 한 점.** 보석의 색(사파이어 블루, 아쿠아마린, 진주 광택)은 **그려진 오브젝트 안에서만** 존재하고 버튼·배지·링크에는 절대 쓰지 않는다. 금(gold) 계열 hex는 UI 어디에도 없다(warning 상태색 제외).

## 5. 레이아웃 문법 — "플레이트와 캡션"

1. **플레이트(plate)가 단위다.** 한 섹션 = 한 장의 룩북 펼침면. 데스크톱 `min-height: 100svh`(index), 페이지에서는 `min-height: 72svh` 장면 블록. 모바일 `min-height: 88svh`(index만). 판 사이 간격 0 — 판의 경계는 배경 톤(`--bg` ↔ `--bg-void`)과 1px `--line`로만.
2. **24단 미세 그리드, 오브젝트는 황금 분할점에.** 데스크톱 24단, 거터 16px, 판 안쪽 여백(inset) 48px(1440) / 32px(768) / 20px(390). 주인공 오브젝트의 중심은 가로 61.8% 또는 38.2% 지점, 세로 46%. **가운데 정렬 금지**(쉼표 플레이트의 한 줄만 예외 아님 — 그것도 왼쪽 38.2%에서 시작).
3. **글자는 모서리에 산다.** 플레이트의 텍스트는 네 모서리 중 하나(주로 좌하단 타이틀 + 우하단 캡션, 또는 좌상단 플레이트 번호)에 inset 거리로 고정. 판 중앙부는 오브젝트와 어둠의 몫. 텍스트 블록이 판 면적의 15%를 넘지 않는다.
4. **캡션 문법 고정**: `No. 04` (Jost 라틴) — `달그림자` (Noto Serif KR 300) / `플래티넘 · 남양 백진주 13.2mm · 다이아몬드 1.92ct` (Noto Sans KR 13px muted) / `YS-HJ26-04` (mono 12px subtle). 네 줄 이하, 좌정렬, 행간 1.6.
5. **판의 종류 4가지를 교차**한다 — 같은 종류가 연속 두 번 오지 않는다.
   - **A 단독판**: 오브젝트 하나 + 모서리 캡션. 여백 70% 이상.
   - **B 이면판(diptych)**: 14/24단 큰 장면 + 6/24단 확대 디테일(위쪽 정렬 어긋나게 96px 내림), 사이 4단 비움.
   - **C 쉼표판**: 오브젝트 없음. 문장 한 줄과 시간 표기만.
   - **D 밀착 인화판(contact sheet)**: 작은 칸을 촘촘히 — 룩북 끝의 전 작품 목록. 유일하게 밀도가 높은 판.
6. **내부 도구 페이지**(dashboard·inbox·kanban·settings)도 같은 문법: 상단 `72svh` 이하 "장면 헤더"(오브젝트 하나 + 모서리 텍스트) 뒤에 실무 영역. 실무 영역은 12단, 거터 24px, 표·리스트는 헤어라인 행(박스 카드 금지).
7. 모바일(<720px): 오브젝트가 위, 캡션이 아래로 내려오되 좌정렬·inset 20px 유지. 이면판은 큰 장면 위에 디테일이 오른쪽 아래 모서리로 겹쳐(−32px) 놓인다. 가로 스크롤 0.

## 6. 시그니처

### 시그니처 ① 윤슬 라인 (Glint Hairline)
1px 헤어라인인데 **한 점에서만 빛난다** — 잔물결 위 햇빛 한 점.
- 구현: `height: 1px; background: linear-gradient(90deg, transparent 0, var(--line) 18%, var(--platinum) 46%, var(--glint) 50%, var(--platinum) 54%, var(--line) 82%, transparent 100%); background-size: 220% 100%; background-position: var(--glint-x, 50%) 0;`
- 정지 상태: 빛점이 고정 위치(구분선 50%, 활성 탭은 탭 중앙).
- 움직임: hover/active/진입 시 `--glint-x`가 100% → 0%로 1200ms `--ease-silk` 한 번 스윕. 표지에서만 9000ms 주기로 반복. reduced-motion: 정지(50%).
- 적용처: 섹션 구분선, **활성 탭 밑줄**, navbar 현재 페이지 밑줄, 입력 focus 밑줄, 진행 바의 머리(채워진 끝에 빛점), 토스트 상단 테두리, 타임라인 현재 지점, 모달 상단 1px, 표 선택 행 좌측(세로 버전 `180deg`), 캐러셀 현재 인디케이터, 스켈레톤 시머(빛점이 지나가는 형태), 포커스 링 하단 보강.

### 시그니처 ② 스포트라이트 플레이트 (Spotlit Object)
**CSS/SVG로 직접 그린 보석·시계**가 조명 하나를 받는다. 조명은 오브젝트가 있을 때만 존재한다(분위기용 radial 얼룩 금지).
- 조명: `radial-gradient(ellipse 34% 42% at var(--spot-x, 61.8%) var(--spot-y, 46%), var(--spot-core) 0%, color-mix(in srgb, var(--spot-core) 40%, var(--bg)) 46%, var(--bg) 78%)` — 경계가 분명한 타원(무대 조명), 흐릿한 구름 아님.
- 접지 그림자: 오브젝트 아래 `ellipse` 가로 60%·높이 6%, `--bg-void` 70% → 투명.
- 오브젝트 라이브러리(SVG `<symbol>`, 선 굵기 1–1.5px `currentColor` + style로 채움, presentation attribute var() 금지):
  - `ring` 첫 물결 — 플래티넘 밴드 타원 + 쿠션컷 패싯(사파이어 스톤 `#0F2350 → #2B4C8C → #6C8FD0`, 오브젝트 전용 색), 프롱 4개
  - `drop` 달그림자 — 진주(radial 3스톱 `#F4F1EA → #CFCBC2 → #8E8A82`) + 다이아 캡
  - `necklace` 물비늘 — 비늘 모양 반원 18개 체인
  - `dial` 자정 — 38mm 다이얼: 60분 눈금, 12개 인덱스 바, 문페이즈 창, 시·분·초침
  - `setting` 빈 프롱 세팅(404 · empty 전용)
- 오브젝트 위 글린트: 패싯 한 곳에 4px `--glint` 점 + 12px 가로 광선(윤슬 라인 축소판). 반짝임은 2개 이하.
- 적용처: index 플레이트, 작품 상세 메인, 대시보드 장면 헤더(다이얼), 빈 상태·404, 온보딩 각 단계 배경, 프로필 소장품 썸네일, 칸반 카드 썸네일(축소 — 조명 없이 실루엣만).

부속 규칙: **radius 0**(예외: 아바타·다이얼·진주 원, 토글 스위치 트랙 999px). **그림자 없음**(다크) — 고도는 면 톤(`bg → surface → raised`)과 헤어라인. 라이트 모드 오버레이만 `0 24px 48px -24px rgba(17,18,20,.28)`.

## 7. 모션 문법 — "초침처럼 느리게, 빛은 한 번만 지나간다"

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--ease-silk` | `cubic-bezier(0.22, 1, 0.36, 1)` | 모든 입장 |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | 퇴장 |
| `--dur-micro` | 240ms | hover 색·불투명도 |
| `--dur-panel` | 480ms | 드로어·모달 입장 (퇴장 240ms) |
| `--dur-reveal` | 900ms | 플레이트 진입 페이드 (opacity 0→1, translateY 12px→0) |
| `--dur-glint` | 1200ms | 윤슬 스윕 1회 |
| `--dur-tide` | 9000ms | 표지 글린트 반복 주기 |
| `--dur-second` | 60s linear | 다이얼 초침 한 바퀴 (표지·대시보드·스피너) |

- 순서: 플레이트 진입 시 ① 조명이 0→1(600ms) ② 오브젝트 페이드(900ms, 120ms 지연) ③ 캡션(900ms, 240ms 지연). 뷰당 움직이는 요소 최대 2개.
- 스피너 = 초침 스윕(2.4s 한 바퀴, `linear`) — 회전하는 호(arc) 금지.
- 마키 = 작품명이 **28px/s**로 아주 느리게 흐르는 띠(hover 시 정지).
- 버튼 hover: 배경 변화 없이 하단 윤슬 라인 스윕(ghost/secondary), primary는 펄 → 글린트 색 240ms.
- 금지: bounce, scale 팝, 300ms 미만 입장, 스크롤 재킹, 패럴랙스.
- `prefers-reduced-motion: reduce` → 모든 진입 즉시 최종 상태, 글린트 정지(50%), 초침 정지(19:40:00 표기 위치), 캐러셀 자동 재생 끔.
