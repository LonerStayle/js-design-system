## 1. 클라이언트와 세계관

### 여명일보 黎明日報 · THE YEOMYEONG DAILY (한국, 가상)
- **무엇**: 대전·세종·충남을 다루는 **지역 조간 일간지**. 1953년 9월 15일(화) 창간, 월~토 발행(일요일 휴간). 본지 A섹션 28면 + 생활 섹션 「여명 라이프」 B섹션 8면 = 하루 36면.
- **이 시스템을 쓰는 곳 두 군데**:
  1. **「여명 디지털 지면」** — 독자용 웹. 오늘 지면을 종이 그대로 읽고, 구독을 신청·관리하고, 「그날의 1면」 복각본을 산다.
  2. **「여명 조판실」** — 편집국 내부 웹. 기사 송고, 면 배열, 교열, 판 강판(마감), 윤전 전송을 관리한다.
- **이름의 뜻**: 여명(黎明) — 동트기 직전. 조간신문은 밤새 만들어져 해 뜨기 전에 문 앞에 놓인다. 회사 표어「해보다 먼저 문 앞에」(제호 옆 세로쓰기).

### 스타일의 원래 맥락 → 왜 이 클라이언트인가
뉴스프린트(신문 용지) 미학은 19세기 말~20세기 활판·윤전 인쇄 일간지에서 왔다. 값싼 회황색 갱지, 먹 한 가지, 사진은 망점(하프톤)으로 분해해 찍고, 장식 대신 **괘선**으로 기사를 나누고, 기사의 중요도를 **단(段) 수와 제목 크기**로 매긴다. 한국 일간지는 여기에 고유 관습을 더했다: 1988년 이전의 세로쓰기 유산(제호 옆 세로 표어), 국한문 병기 제호, 꺾쇠 말머리([단독]·[속보]·[사설]), ◆·▶·※ 조판 기호, 판(版) 번호(초판 40판 → 최종 50판), 그리고 1면 하단의 **5단 광고**.
그래서 이 테마의 크림 갱지·명조 본문·세리프 숫자는 서재 장식이 아니라 **매체의 실물**이다(브리프 3절 예외 조건 충족). 세계가 진짜 신문사이므로 대시보드는 마감 상황판, 칸반은 면 배열 보드, 프라이싱은 구독료, 404는 정정보도가 된다 — 모든 화면에 "왜 신문 모양인가"의 답이 있다.

### 감정 톤 (한 문장)
**새벽 4시 막 윤전기에서 나온 조간을 펼칠 때의 긴장감 — 잉크 냄새가 아직 남은 빽빽한 지면, 그 안에서 가장 큰 제목 하나가 오늘의 무게를 말한다.**
첫 화면 1초 안에 느껴야 할 것: 거대한 제호, 신문 전체 폭을 가로지르는 톱 제목, 망점 사진, 그리고 빽빽한 회색 본문 단. "깔끔한 문서"가 아니라 **꽉 찬 지면**이다.

반전이 아니라 장면이다. 조판실 모니터와 윤전기 블랭킷의 **먹색 판** 위에, 교정지 색 활자와 **주홍 경고등**. 주홍은 다크에서도 주홍(분홍·연어색으로 밀리지 않음). 망점 사진은 **반전하지 않는다** — 네거티브로 뒤집으면 어두운 피사체가 크림색 덩어리가 되어 밤 장면에서 사진이 가장 밝은 면이 된다(2차 수정). 야간판 사진은 명암 매핑을 유지한다: 먹 피사체는 무점(판색), 밝은 곳만 교정지 75%(`#BFB59F`) 점이 촘촘해지며 최대 점 면적 45%. 결과적으로 사진의 평균 밝기는 본문 단과 같거나 낮다. 갱지 바탕이 흰 띠로 남는 영역 없음 — 제호 띠·광고 박스까지 전부 먹 판으로 넘어간다.

## 6. 레이아웃 문법 — "판면(版面)"

1. **판면 폭과 여백**: 지면 최대 폭 1320px, 판면 여백 좌우 32px(≥1024), 24px(≥600), 16px(<600). 페이지 전체 바탕은 갱지 한 장 — 섹션별로 배경 띠를 바꾸지 않는다(접힘선 아래 `--paper-fold` 한 번만 예외).
2. **6단 / 12소단 그리드**: `grid-template-columns: repeat(12, 1fr)`, `column-gap: 24px`. 기사는 항상 **2소단 = 1단** 단위로 폭을 갖는다(1단·2단·3단·4단·6단 기사). 인접 기사 사이에는 단 괘선(1px `--ink` 또는 0.5px `--rule-hair`)을 gap 중앙에 긋는다(`::before` 의사요소, 박스 테두리 금지).
3. **세로 모듈 15단**: 지면 높이를 52px 단위 "세로 단"으로 센다. 광고·박스 높이는 이 배수(하단 5단 광고 = 260px, 3단 박스 = 156px). 기준선 4px.
4. **크기로 말하는 위계**: 한 화면에 같은 크기 기사 두 개를 나란히 두지 않는다. 1면은 톱(8소단) : 세로 기사(2소단) : 단신(2소단), 접힘 아래는 4단 : 사설 1단 : 색인 1단. 같은 폭 카드 그리드 금지.
5. **정렬**: 왼쪽 정렬이 기본. 가운데 정렬은 제호·판권 줄·호외 제목 세 곳뿐. "작은 라벨 → 제목 → 부제" 가운데 정렬 섹션 헤더 금지.
6. **면 머리(running head)**: 각 면(섹션)의 시작은 4px 먹 괘 위에 `A3 · 사회 ─── 2026년 10월 27일 화요일 ─── 여명일보` 한 줄(좌·중·우). 제목 헤더가 아니라 신문의 면 머리다. 이어지는 면마다 아래 그리드 구성이 바뀐다.
7. **점프와 이음**: 단이 끊기면 `→A3면에 계속`, 관련 기사는 `▶관련기사 A4면`. 페이지 간 링크는 이 문법으로 건다.
8. **밀도**: 기사 사이 24px, 기사 안 문단 간격 0(들여쓰기). 섹션 사이 여백은 64px가 최대. 큰 빈 칸 금지 — 단 높이가 남으면 단신·날씨·색인으로 메운다(7-8).
9. **모바일(<600)**: 12소단 → 1단 흐름. 세로 단 괘선은 기사 사이 가로 헤어라인으로 바뀐다. 제호는 가운데 유지, 귀(날씨·가격)는 제호 아래 한 줄로 내려온다. 제목 위계 비율 유지. 단 본문은 `column-count: 1`.
10. **태블릿(600–1023)**: 6소단 그리드(3단), 톱은 6소단 전체 폭.

## 7. 시그니처

### 시그니처 ① 「괘선(罫線) 조판」 — 상자 대신 선
괘선 위계(토큰): `--rule-0` 0.5px `--rule-hair` · `--rule-1` 1px 먹 · `--rule-2` 2px 먹 · `--rule-4` 4px 먹 · **`--rule-double`(쌍괘) = 4px 먹 + 2px 틈 + 1px 먹**.
- radius 전부 0. 원형은 상태 핍(8px)과 망점 아바타 원에만.
- box-shadow 금지. 유일한 예외: 호외 판(모달)·메뉴처럼 지면 위로 "얹힌 종이"에 `6px 6px 0 var(--shadow-hard)` 하드 오프셋(야간판 = 한 단 밝은 종이 겹 슬래브 + 헤어라인).
- 컴포넌트 적용: 카드 = 위 `--rule-4` + 아래 `--rule-0`(옆 선 없음) · 표 = 위아래 쌍괘, 행 사이 `--rule-0`, 세로선 없음 · 탭 = 면 색인(선택 탭 위 4px 먹 괘) · 입력 = 밑줄 2px 먹(포커스 시 주홍) + 서식 라벨 · 사이드바 = 오른쪽 1px 단 괘선 · 내비 = 아래 쌍괘 · 푸터 = 위 쌍괘.

### 시그니처 ② 「망점(網點) 사진」 — 이미지는 전부 하프톤
이미지 파일 금지 조건을 장점으로: 모든 사진·도판·아바타·빈 상태를 CSS 망점으로 그린다.
- 구현: `background-image: radial-gradient(circle, var(--dot) 38%, transparent 40%); background-size: 5px 5px;` + 농도는 `mask-image: linear-gradient(...)` 또는 SVG `<pattern>`(점 크기 변화)로 명암을 낸다. 피사체(버스·사람·가로등)는 SVG 실루엣에 망점 패턴 채움(`fill` 속성 대신 `style="fill:url(#dots)"`, var()는 style로만).
- 사진에는 항상 `figcaption` + 크레디트(「사진=노은별 기자」). 캡션 없는 망점 금지.
- 야간판 명암 매핑: SVG 패턴 점 반지름은 CSS `r: var(--ph-r-10…80)`로 모드별로 바뀐다(주간판 0.9→2.52 / 야간판 1.1→0.3, 어두울수록 성김). 패턴 아래에 `--ph-under`(야간판 = 판색) 칸을 깔아 바탕 점이 비치지 않게 하고, 사진 SVG 안에서는 `--dot` → 판색, `--paper` → `#ht-hi`(최대 45%)로 바꾼다. 섬네일은 `--ph-thumb`.
- 컴포넌트 적용: 아바타 = 망점 원 + 이니셜 · 스켈레톤 = 망점 10% 판(반짝임 대신 점 농도 2단 교대) · 진행 막대 = 망점 채움에서 먹 채움으로 · 차트 막대 = 망점(전주) vs 먹(이번 주) · 빈 상태 = 사진 틀 + 「사진 대기」 · 모달 스크림 = 망점 40% · 기사 카드 hover = 망점 촘촘해짐(5px → 4px).

### 보조 장치 — 한국 조판 기호 (시그니처를 받치는 문법)
- 꺾쇠 말머리 배지: `[단독]` `[속보]` `[사설]` `[현장]` `[알림]` — 둥근 알약 대신 대괄호가 붙은 Gothic A1 800. 주홍은 [단독]·[속보]만.
- 기호: ◆ 단신 구분, ▶ 관련기사·이동, ※ 주석, ■ 소제목, ─ 30 ─ 기사 끝 표시는 쓰지 않는다(서구 관습).
- 판 표기: 1면 오른쪽 위 `50판`, 대시보드 진행 판.
- 제호 옆 세로쓰기 표어 `writing-mode: vertical-rl` 「해보다 먼저 문 앞에」 — index 제호와 404에만.

## 8. 모션 문법 — "윤전(輪轉)"

종이는 흐려지지 않는다. **페이드 금지, 끊어 바꾸기(cut) + 짧은 기계적 이동.**

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--dur-cut` | 0ms | 탭 전환, 아코디언 내용 표시(높이만 120ms) |
| `--dur-press` | 90ms | 버튼 누름 |
| `--dur-fast` | 140ms | 메뉴·팝오버·토스트 진입 |
| `--dur-base` | 200ms | 드로어·호외 판 진입 |
| `--dur-rule` | 480ms | 괘선 긋기(로드 1회) |
| `--ease-press` | `cubic-bezier(.2, 0, 0, 1)` | 전 모션 공통 |
| `--dur-ticker` | 48s linear infinite | 속보 띠 |

- **괘선 긋기**: 페이지 로드 시 제호 아래 쌍괘가 `transform: scaleX(0→1)`, `transform-origin: left`로 한 번 그어진다. 면 머리 4px 괘도 뷰포트 진입 시 1회(IntersectionObserver, opacity 변화 없음).
- **속보 띠**: 주홍 띠 위 텍스트가 오른쪽→왼쪽으로 흐름. hover·focus 시 정지, 정지 버튼 제공.
- **활판 누름**: 버튼 기본 `box-shadow` 없음 → `:active`에서 `translate(1px, 1px)`. 1차 버튼만 hover 시 2px 하드 오프셋이 생겼다가 누르면 0.
- **전보 토스트**: 화면 위에서 띠로 `translateY(-100%→0)` 140ms, 5초 뒤 같은 길로 퇴장. 아이콘 대신 말머리 `[알림]`.
- **호외 판(모달)**: `translateY(-12px)→0` 200ms + 하드 오프셋 그림자 등장. 스크림은 망점, 페이드 없이 즉시.
- **기사 hover**: 제목 밑줄 1px → 2px, 망점 사진 농도 상승. 이동·확대 없음.
- `prefers-reduced-motion: reduce` → 모든 duration 0, 속보 띠 정지(첫 항목 고정 표시), 괘선은 처음부터 그어진 상태.

## 10. index.html 구성안 — 「10월 27일자 1면 교정쇄」

index는 랜딩이 아니라 **여명일보 2026년 10월 27일 화요일자 지면 교정쇄(校正刷)**다. 실제 뉴스가 조판된 1면 위에 편집부가 **주홍 교정 주석**(여백의 작은 쪽지와 지시선)으로 "이 제목은 `.hd-6` 80/1.06 Black Han Sans" 같은 조판 규격을 적어 넣는다. 스펙은 주석, 주인공은 지면. 뒤로 넘기면 A2·A3… 면이 이어지며 면마다 구도가 다르다.

1. **속보 띠 + 면 머리 띠** (공통 셸 navbar): 맨 위 주홍 속보 띠「[속보] 대전역 동광장 임시 정류장 27일 오전 5시 30분부터 운영 ◆ …」, 그 아래 색인 줄 `A1 1면 │ [조판실] 상황판 · 면 배열 · 제보·송고함 · 기자 페이지 │ [독자서비스] 구독 안내 · 그날의 1면 ……… 내 구독`(면 번호는 A1만), ⌘K 기사 검색, 「주간판/야간판」 토글.
2. **1면 제호부 (첫 화면 상단 1/3)**: 왼쪽 귀 = 날씨(대전 4℃/17℃, 해 뜸 06:54), 가운데 = **「여명일보」 Hahmlet 900 132px** + 黎明日報 + 세로쓰기 표어「해보다 먼저 문 앞에」, 오른쪽 귀 = `50판 · 36면 · 1부 1,000원`. 아래 쌍괘가 그어지고 판권 줄「제22,184호 · 1953년 9월 15일 창간 · 2026년 10월 27일 화요일 · 대전 · 조간」.
