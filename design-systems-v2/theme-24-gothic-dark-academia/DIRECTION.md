## 1. 클라이언트 · 세계관

### 스타일의 원래 맥락
- **고딕 리바이벌(19세기~1930년대)**: 옥스퍼드·케임브리지 칼리지, 미국 예일·프린스턴의 석조 도서관. 뾰족 아치(첨두아치) 창, 사엽(四葉) 장식 트레이서리, 참나무 서가, 녹색 갓 독서등(뱅커스 램프, 1909~).
- **다크 아카데미아(문학·온라인 미학)**: 도나 타트 『비밀의 계절(The Secret History)』(1992)에서 출발해 2010년대 텀블러, 2020년 팬데믹기에 미학으로 굳었다. 고전어, 밤샘 필사, 지적 집착, 약간의 위험과 비밀, 가을. 색은 갈색·검정·버건디가 아니라 **밤의 서고 그 자체**다.
- **필사본 전통**: 중세 수도원 필사본은 검은 철잉크(오배자 잉크)로 쓰고, 장 머리·두문자·문단 기호(¶)·각주 표시는 **주사(朱砂)·연단(鉛丹) 붉은색**으로 덧썼다(rubrication, 주서). 여백에는 방주(欄外註)를 달았다. 동아시아 고서도 붉은 권점(圈點)·주서로 같은 일을 했다.
- **도서관 카드 목록(1890s~1990s)**: 7.5 × 12.5 cm 카드에 타자기로 친 청구기호·서명·저자, 아래 가운데 막대 구멍, 왼쪽의 붉은 세로 괘선. 책 뒤표지 안쪽의 **대출카드 주머니**와 **반납일 날짜도장**(보라·청 잉크, 비뚤게 찍힘).
- 그래서 v2의 매체는 **"자정의 대열람실 책상 위에 펼친 필사본과, 그 옆에 당겨 놓은 카드 서랍"**이다. 필사본(장 표제·주서·각주)이 이야기를 하고, 카드(타자 글씨·청구기호·날짜도장)가 데이터를 맡는다.

### 클라이언트 (한국) — 석루서고 石樓書庫 · BIBLIOTHECA SEOKRU
**석루서고** — 서울 중구 정동길의 1931년 고딕 리바이벌 석조 건물 **석루관(石樓館)**에 있는 사설 회원제 **야간 고서 도서관**. 성공회 선교회가 신학교 도서관으로 지은 2층 석조 건물(첨탑 하나, 첨두아치 창 14개)을 2019년 서지학자·고서 수집가 **한도경**이 매입·복원해 2021년 3월 개관했다. 조선 후기 필사본·목판본과 선교사들이 남긴 18~19세기 서양 고서, 그리고 고딕 소설 초판본을 함께 소장한다. **밤에만 열람실을 연다** — 오후 6시에 등을 켜고 새벽 2시에 끈다.

디자인 시스템은 **회원용 웹(열람 신청·회원·상점·필사회) + 서고 업무 도구(야간 사서 일지·서신함·수선 공방 작업대)**가 함께 쓴다.

어울리는 이유: 장 표제·주서·각주·장서 카드·청구기호·대출카드·날짜도장은 장식이 아니라 **도서관의 실제 업무 양식**이다. 카드가 곧 레코드, 날짜도장이 곧 상태 배지, 각주가 곧 도움말, 열람석 배치도가 곧 대시보드다.

### 감정 톤 (한 문장)
**자정이 가까운 석조 열람실, 녹색 램프 하나 아래에서 백 년 넘은 책장을 넘기며 숨을 죽이는 — 경건하고 은밀하며, 조금은 위험할 만큼 깊이 빠져드는 밤의 지적 열기.**

1초 안에 보여야 할 것: **검은 잉크와 주서 붉은색의 대비**, 거대한 장 번호, 필사본 판면(넓은 여백 + 방주), 그리고 한 장의 장서 카드와 비뚤게 찍힌 보라색 날짜도장. 다크에서는 **첨두아치 창 너머의 밤과 램프 불빛의 원뿔**.

## 5. 레이아웃 문법 — "중세 판면 비례 + 바깥 여백의 방주 단"

1. **판면 단위 u = 24px. 여백 비율 안:위:바깥:아래 = 2 : 3 : 4 : 6** (중세 필사본 판면 규범, 반 더 그라프 캐논의 근사). 데스크톱 index 한 장(leaf): 안쪽 48 · 위 72 · 바깥 96 · 아래 144px. 아래 여백이 가장 넓다 — 모든 장(章)은 **위가 좁고 아래가 깊은 무게중심**으로 끝난다.
2. **2단 비대칭: 본문 단 + 방주 단.** `grid-template-columns: [inner] 48px [text] minmax(0, 680px) [gap] 56px [gloss] 280px [outer] minmax(96px, 1fr)` (1440 기준 본문 680 · 방주 280). 방주 단에 각주·토큰 값·사서 연필 메모·작은 도판이 들어간다. **홀수 장(recto)은 방주가 오른쪽, 짝수 장(verso)은 왼쪽** — 장마다 좌우가 뒤집혀 펼침면 리듬이 생긴다.
3. **도판(figure)은 단을 넘는다.** 컴포넌트 시연 도판은 `text`+`gap`+`gloss` 세 칸(1016px)을 쓰거나, 본문 단 안에 들어가거나, 화면 전체(ink-block)를 쓴다 — 같은 장 안에서 두 가지 이상 섞는다. 도판 아래 캡션 "도판 4-2 · 열람 신청서 (열린 상태)" + 방주 각주.
4. **각주 장치(apparatus).** 장 끝마다 본문 단 폭의 1/3 길이 1px `--ink` 괘선 → 각주 13px. 모바일에서 방주 단은 해당 문단 바로 뒤 **들여쓴 방주 블록**(왼쪽 2px `--rubric` 괘선, 패딩 0 0 0 16px)으로 접힌다.
5. **카드 서랍은 판면을 깨는 유일한 구역.** 필사본 판면을 벗어나 화면 전폭의 참나무 서랍(`--wood`)이 들어오고, 그 안에서 카드가 **7.5 : 12.5 = 3 : 5 비율**로 선다. 서랍 안 카드는 위 36px(색인 탭 줄)만 보이게 겹쳐 서 있고, 선택한 카드만 위로 당겨져 전체가 보인다(시그니처 1).
6. **장부(ledger)는 괘선으로 칸을 만든다.** 표·목록·달력은 카드 그림자 대신 **이중 괘선 머리**(위 3px double `--ink`, 아래 1px `--rule`)와 1px 행 괘선. 둥근 카드 컨테이너에 담지 않는다.
7. **세로 리듬 = 32px 괘선.** 본문 line-height 32px에 맞춰 모든 수직 간격은 8의 배수, 장 사이는 144px(아래 여백 6u), 장 안 블록 사이 48 또는 72px. 섹션마다 같은 패딩을 반복하지 않는다: 표제지(전체 화면) → 차례(좁은 단 중앙) → 1장(잉크 블록 전폭) → 2장(방주 왼쪽) → 서랍(전폭 나무) → 4·5장(펼침면 2쪽) → 6장(전폭 장부) → 열람 기록부(주머니 9개) → 간기(한 줄).
8. **모서리**: 기본 0. 카드 용지 2px(실제 카드 모서리). 원은 아바타 인장·카드 구멍·라디오에만. **그림자**: 평면 없음. 카드 들림만 `0 1px 0 var(--hairline), 0 10px 24px rgba(20,14,8,.18)`(다크 `rgba(0,0,0,.55)`).
9. **모바일 390**: 좌우 거터 16px · 본문 단 100% · 방주 → 인라인 방주 · 장 번호 168px를 장 표제 왼쪽에 걸지 않고 **위에 단독**으로 · 펼침면 2쪽 → 1쪽씩 세로 · 카드 서랍 → 세로 겹침 스택(탭 줄 44px 터치 타깃) · 표 → 장서 카드 행.

## 6. 시그니처

### 시그니처 1 — 장서 카드와 날짜도장 (데이터의 그릇)
**장서 카드**: `--leaf` 용지, 비율 5:3(가로형), 모서리 2px, 1px `--hairline` 외곽, **왼쪽 28px 지점 1px `--rubric` 세로 괘선**(카드 목록 용지의 붉은 여백선), 위 40px 지점 1px `--lapis` 30 % 가로 괘선, **아래 가운데 지름 10px 막대 구멍**(`--page` 색 원, 안쪽 1px 그림자). 왼쪽 위 청구기호(Special Elite 13px), 본문은 Nanum Gothic Coding 타자 글씨.
**날짜도장**: Special Elite 15px 숫자, `--stamp` 보라 잉크, 2px 테두리 + 1px 안쪽 테두리(이중 괘), 패딩 4px 8px, `rotate(-3deg)`(요소마다 −4°~+2° 사이 고정값), 불투명도 .9, 가장자리를 SVG 노이즈 마스크로 살짝 거칠게(선택). 상태 배지가 도장이 된다: `열람 가능`(녹청)·`대출 중`(보라)·`귀중본`(주서)·`수선 중`(석웅황).

적용: card(장서 카드 그대로) · list(서랍 속 겹친 카드 행) · table 행 hover(카드 한 장이 1px 들림) · modal(큰 카드 = 열람 신청서) · popover/tooltip(작은 쪽지 카드) · toast(반납 쪽지 + 도장 찍힘) · badge(날짜도장) · calendar(열람한 날에 도장) · timeline(연대 = 도장) · empty(청구기호 없는 빈 카드) · skeleton(타자 글씨 자리 줄) · pagination(카드 서랍 색인 탭) · kanban 카드(수선 의뢰 카드 + 꼬리표).

### 시그니처 2 — 주서(朱書)와 각주 (서사의 문법)
흑 한 색으로 쓰고, **구조를 표시하는 것만 붉게**: 장 번호(Grenze Gotisch 360px), 장 첫 글자 두문자(Noto Serif KR 900, 3줄 드롭), 문단 기호 ¶, 각주 번호 ¹²³, 현재 위치. 설명은 본문에 쓰지 않고 **각주로 내린다** — 토큰 값·대비·접근성 메모·폼 도움말이 모두 각주다.

적용: tabs(활성 탭 = 앞에 주서 ¶ + 아래 2px 주서 괘) · navbar(러닝헤드에 현재 장 번호 주서) · sidebar(현재 항목 왼쪽 주서 ¶) · breadcrumb(러닝헤드 형식 `석루서고 · 귀중본실 · 『프랑켄슈타인』`, 구분자 주서 `·`) · form(라벨 뒤 각주 번호 → 필드 아래 각주 도움말, 오류 = 주서 글자 + ✕ 표 + 문장) · accordion(열람 규칙 "제1조 ¶") · steps(주서 로마숫자 Ⅰ Ⅱ Ⅲ Ⅳ — 장식 위치이므로 허용, 옆에 한글 단계명 필수) · alert(위험 = 주서 왼쪽 4px 괘) · focus(2px 주서 링 + 2px 오프셋) · 링크(밑줄 1px `--rubric`, hover 시 2px로 두꺼워짐).

**금지**: 데이터 컨트롤·수치 라벨의 로마숫자(감사 메모 D — "VII Days" 류). 로마숫자는 장 번호·steps 장식·표제지 연도에만.

## 7. 모션 문법

원칙: **사람이 종이를 다루는 속도**. 튕김(spring) 없음, 촛불 깜박임 없음. 이징 `--ease-ink: cubic-bezier(.22,.61,.36,1)`, 도장만 `--ease-stamp: cubic-bezier(.3,1.35,.5,1)`.

| 동작 | 값 |
|---|---|
| 호버 (링크·버튼) | 120ms · 색·밑줄 두께만 · 버튼 y −1px |
| 카드 당기기 (서랍·목록·표 행) | hover/focus: translateY(−10px) 240ms · 선택: 위로 −56% 당겨져 전체 노출 320ms · 다른 카드 0.6 불투명 |
| 날짜도장 찍기 (toast·승인·저장) | 160ms: scale 1.25→1, rotate −8°→−3°, opacity 0→.9 · 직후 카드 2px 눌림 80ms |
| 장 표제 등장 | 뷰포트 진입 시 1회: opacity 0→1 + y 8px→0, 420ms. 장 번호는 120ms 늦게 |
| 모달·드로어 | 카드가 아래에서 올라옴 280ms (y 24px→0) · 배경 `rgba(11,9,7,.62)` 200ms · 닫힘 180ms |
| 테마 전환 | **램프 켜기/끄기**: 표제지 램프 빛 원뿔 opacity 0↔.14 360ms, 화면 전체 색 전환 240ms. 토스트 "밤 열람실로 옮겼습니다 · 램프를 켰습니다" / "낮 열람실로 옮겼습니다" |
| 스피너 | 녹색 갓 램프 아이콘의 빛 원뿔이 1.6s 주기로 .35↔.9 (회전 없음) · 대안: 사엽 장식 4점이 차례로 채워짐 |
| 마퀴 | 오늘 밤 반납·신착 날짜도장 띠, 40px/s, hover·focus 시 정지, 정지 버튼 |
| `prefers-reduced-motion` | 모든 transform 제거, 즉시 최종 상태. 도장은 정적 표시, 마퀴는 정적 목록 |

- 워드마크 `Folio·24`, 히어로 "Dark Academia" 블랙레터 헤드라인, "촛불 아래 장정한 인터페이스 폴리오" 카피, `장서각`·`Scriptorium`·`필사실 장부`·`묵향당 필방`·`문정원` 등 세계관 이름 전부
- eyebrow → 헤드라인 → 문단 → CTA 2개("서재로 들어가기 / 폴리오 넘겨보기") 첫 화면
- 흐릿한 radial 금색/버건디 얼룩 배경, 반투명 유령 글자 "XXIV" 워터마크, 한 글자씩 세로로 쌓은 장식 레일
- **금색이 모든 것**(괘선·라벨·카드 테두리·차트·아이콘) — v2에서 금은 장식 전용
- 모든 패널의 같은 골드 1px 테두리 + 같은 안쪽 그림자 + 4px 모서리 카드 그리드
- 컬러 램프 50~900 막대 진열, 타이포·여백·모서리·그림자 4카드 갤러리
- 촛불 깜박임(`candle-flicker`) 모션, 커서 따라오는 광원 아이디어(감사 메모 ⑤-①) — 얼룩 배경의 변형이라 기각
- 데이터 컨트롤·수치 라벨의 로마숫자, 연도를 빨간 알약 배지로 쓰는 표
- 대시보드의 KPI 카드 4장 + 스파크라인 + 범용 라인/막대 차트 조합, 오프팔레트 차트 색(분홍·하늘)
- EB Garamond / Cinzel / UnifrakturCook / Song Myung 조합(Song Myung은 theme-17이 사용)
- 모노 폰트 스택의 Noto Sans KR 폴백(모노는 라틴·숫자만, 한글 타자는 Nanum Gothic Coding)
- `?theme=` 쿼리를 무시하는 테마 결정 로직 — v2는 쿼리 → localStorage → 시스템 순
