## 1. 클라이언트 · 세계관

### 스타일의 원래 맥락
- **카와이(かわいい)** 의 시각 원천은 1970년대 일본 여학생들의 **둥근 손글씨(丸文字)** 와 그것을 상품화한 **팬시 문구**(1974 산리오 동전지갑, 1980년대 스티커·편지지 세트), 1990년대 **스티커 사진(프리쿠라)·시ール帳(스티커 수집첩)** 이다. 크기는 작고, 모서리는 둥글고, 색은 우유를 탄 파스텔이며, 물건마다 얼굴이 있다.
- 한국에서는 2000년대 팬시 문구점(편지지·스티커 코너)을 거쳐 2020년대 **다꾸(다이어리 꾸미기)** 문화로 되살아났다 — 스티커 시트, 마스킹테이프, 떡메모지를 사서 위클리 칸에 붙이고 사진을 찍어 올리는 놀이. 즉 이 스타일의 진짜 매체는 웹페이지가 아니라 **스티커를 붙인 다이어리 한 장**이다.
- 그래서 v2의 매체는 **"한 권의 다꾸 견본첩"** 이다. 모눈 속지 위에 스티커·테이프·메모지가 붙어 있고, 넘기면 다음 장이 나온다.

### 클라이언트 (한국) — 폭닥문방구 POKDAK
**폭닥문방구**(폭닥폭닥 = 포근하게 감싸는 소리) — 다꾸용 스티커·마스킹테이프·떡메모지를 직접 만드는 문구 브랜드 + 입점 작가 편집숍. 2021년 일러스트레이터 한보미가 시작. 서울 성수동 오프라인 매장 **"폭닥 다꾸 테이블"** 에서 산 물건을 바로 붙여 볼 수 있는 꾸미기 좌석을 운영하고, 매달 스티커를 봉투에 담아 보내는 구독 **"폭닥 우편함"** 이 주력. 마스코트는 구름처럼 뭉실한 아기 양 **폭닥이**.
디자인 시스템은 **고객용 쇼핑·구독 사이트 + 운영팀/입점 작가용 관리 도구**가 함께 쓴다.

어울리는 이유: 스티커 다이컷 외곽선, 마스킹테이프, 메모지, 모눈 속지가 장식이 아니라 **이 회사가 실제로 파는 물건** 이다. 컴포넌트가 곧 상품 견본이 된다.

### 감정 톤 (한 문장)
**방과 후 책상 위, 새 스티커 시트를 막 뜯어 위클리 한 칸에 붙이는 순간의 두근거림 — 반듯하지 않아도 귀여우면 정답.**

- 다크의 장면 장치: 페이지 오른쪽 위에서 내려오는 **스탠드 불빛 원뿔**(conic 한 장, 약 60° 폭, 알파 .16→.08, radial 얼룩 금지). 배경 아래 한 겹 + 펼친 종이 위에 screen 합성 한 겹으로 종이에도 불빛이 내려앉고, 아래로 갈수록 마스크로 사라진다(딱 끊긴 네모 금지). **야광 별 스티커 7개**(SVG, 고정 좌표)는 펼침면 바깥 양옆 여백에 붙여 첫 화면에서 보이게 한다 — 폰에서는 작은 별 4개만 가장자리에. 테이프는 알파 94%(원색 유지 — "밤에도 파스텔").
- 대비 검산 결과는 위 괄호 수치(WCAG 상대휘도 직접 계산). 전 조합 본문 4.5:1 이상, 큰 글자·UI 3:1 이상.

## 5. 레이아웃 문법 — "모눈 속지 위에 붙인다"

1. **모눈 20px 그리드.** `body` 배경 = 20px 모눈(가는 선) + 100px 굵은 선, CSS `linear-gradient` 4장. 모든 간격·크기는 20의 배수(8·12px는 컴포넌트 내부에만). 요소의 **왼쪽 위 모서리는 모눈 교점에 스냅**.
2. **펼침면(spread).** 데스크톱(≥1080px) index는 **좌우 두 쪽 펼침면**: 최대 폭 1320px, 가운데 제본선 40px(링 구멍 9개 또는 스프링 SVG), 양쪽 쪽 각 640px. 한 펼침면 = 한 장(章). 섹션 사이에는 펼침면을 "넘기는" 단차(다음 장이 20px 오른쪽으로 밀려 겹침)를 둔다. 태블릿(720–1079px)은 한 쪽짜리 페이지 + 제본선 왼쪽, 모바일은 테두리 없는 한 장.
3. **붙임 규칙 — 비대칭 · 기울기.** 스티커·메모지는 −4°~+4° 안에서 기울인다(같은 각 연속 금지: −2, +3, −1, +4 … 순환). 표·폼·본문 텍스트는 **절대 기울이지 않는다**(읽기 영역은 0°). 한 펼침면에 쪽 경계를 넘는 큰 스티커 1개(제본선 침범)만 허용.
4. **종이는 각지고, 스티커는 둥글다.** 메모지·속지·표 = radius 2–4px(+한쪽 모서리 접힘 가능). 스티커·버튼·배지·칩 = 다이컷 곡선(radius 18–28px 또는 비대칭 `24px 18px 26px 16px`). 같은 radius를 모든 것에 쓰지 않는다.
5. **테이프로 고정.** 카드형 면(메모지·사진·폴라로이드)은 마스킹테이프 1~2조각으로 붙어 있다(위 가운데 1개 또는 대각 두 모서리). 테이프 없는 카드형 면 금지 = 둥근 카드 갤러리 방지.
6. **여백 리듬.** 펼침면 안쪽 여백 60px(모바일 20px), 펼침면 사이 120px. 한 장 안에서 요소 간격은 20/40/80 세 단계만. 섹션마다 밀도를 바꾼다: 표지(듬성) → 스티커 시트(빽빽) → 메모 콜라주(중간) → 트래커(빽빽) → 폴라로이드(듬성).
7. **모바일(360–480px)**: 펼침면 → 한 쪽 세로 흐름, 기울기 절반(±2°), 제본선 대신 페이지 상단 스프링 SVG. 페이지 오른쪽 가장자리에 **인덱스 탭**(색 탭 44×56px)이 섹션 전환 역할. 가로 넘침 0(스티커가 가장자리를 넘는 연출은 `overflow-x: clip`된 래퍼 안에서만).

### 앱 셸(pages)
- **관리 도구 페이지**(dashboard·inbox·kanban·profile): 상단 = **다이어리 표지 띠**(높이 72px, cherry 면 + 고무줄 밴드 세로선 + 워드마크 스티커) / 왼쪽 = **인덱스 탭 레일**(폭 88px, 각 메뉴가 색 탭 스티커로 페이지 가장자리에서 튀어나옴, 현재 탭은 20px 더 길게). 사이드바는 목차형 텍스트 리스트가 아니라 **탭 스티커 기둥**. 390px에서는 레일이 하단 탭바(인덱스 탭 5개, 각 64×56px)로.
- **고객 페이지**(product·pricing·onboarding·settings·404): 상단 = 가게 간판 띠(폭닥문방구 워드마크 + 검색 + 장바구니 봉투 아이콘), 레일 없음. 간판 띠 메뉴 = 스티커 · 폭닥 우편함 · 취향 고르기 · 내 다이어리(직원용 "작가 노트"는 고객 메뉴에 두지 않는다). 390px 이하에서 간판 띠는 sticky를 풀고 흐름 속에 둔다(고정 크롬 최소화).
- **예외 — settings**: 고객(이수아 U-58214) 화면이므로 관리 레일·하단 탭바를 쓰지 않는다. 왼쪽 레일 자리는 **고객 전용 인덱스 탭**(속지 · 밤다꾸 · 우편함 · 알림 · 멈추기)이 쪽 가장자리에서 튀어나온 모양으로 대신한다.
- 푸터는 공통 1종: 마스킹테이프 한 줄 위 "폭닥문방구 · 서울 성동구 연무장7길 14, 2층 · 02-468-1120 · 화–일 12:00–20:00 (월 휴무)" + 폭닥이 작은 스티커.

## 6. 시그니처 (2개, 끝까지)

### 시그니처 A — 다이컷 스티커
- 모양: 색 면 + **3px 흰 다이컷 외곽선**(`--die-cut`) + 바닥 그림자 `0 2px 0 rgba(58,35,64,.10), 0 8px 14px -6px rgba(58,35,64,.28)`.
- 키스컷 시트: 여러 스티커가 하나의 **스티커 시트**(옅은 wash 면, radius 12px, 시트 가장자리 점선 칼선 `2px dashed` ink-faint 25%) 위에 놓인 구성.
- 호버 = **모서리 떼기**: 오른쪽 아래 모서리가 접혀 올라감(`::after` 삼각 그라디언트 16px, 180ms) + 스티커 전체 −3px 들림. 눌림 = 납작 `scale(.97, .94)` 120ms.
- 적용: 버튼, 배지, 칩, 태그, 아바타, 탭(선택된 탭만 스티커), 토스트, 별점, 스텝 번호, 페이지네이션 현재 쪽, KPI 숫자, 캘린더 일정, 드롭다운 선택값, 마스코트 폭닥이.

### 시그니처 B — 마스킹테이프
- 모양: 반투명 띠(`opacity .82`, `mix-blend-mode: multiply` — 다크는 `normal` + `.78`), 높이 28px(와이드 44px), 양 끝 **지그재그 찢김**(`clip-path: polygon(...)` 6px 톱니), 무늬 4종 = 깅엄(딸기) · 모눈(민트) · 도트(라벤더) · 줄무늬(레몬). 모두 `repeating-linear-gradient`/`radial-gradient` 타일(이미지 파일 금지).
- 적용: 메모지·카드·폴라로이드 고정, **섹션 제목 = 테이프 위에 손글씨**(가운데정렬 라벨+제목+부제 대신), 마키(무한 흐르는 테이프), 프로그레스 바(테이프가 늘어남), 드로어 손잡이, 모달 상단, 표 헤더 띠, 타임라인 연결선, 브레드크럼 구분(테이프 조각), 푸터 상단.

> 둘 외의 장식(하트 반짝이 남발, 무지개 그라디언트, radial 얼룩)은 쓰지 않는다. 폭닥이 마스코트는 "스티커의 한 종류"로 취급한다.

### 마스코트 폭닥이
- 구름형 몸통(원 7개를 합친 SVG 경로, 뭉실한 테두리) + 작은 얼굴(점 눈 2, ω 입, 볼터치 딸기) + 짧은 다리 4. 표정 4종: 기본 `^ω^`, 신남(눈 반짝 별), 졸림(다크·로딩 — 눈 `- -`), 시무룩(404·빈 상태 — 눈 `; ;`).
- 인라인 SVG `<symbol>` 1벌을 index·pages가 공유(각 HTML 안에 복사, 색은 `currentColor`/`style="fill:var()"`). 이모지 금지.

## 7. 모션 문법 — "붙이고, 떼고, 눌린다"

| 이름 | 값 | 쓰임 |
|---|---|---|
| `--ease-stick` | `cubic-bezier(.34,1.56,.64,1)` (ui-ux-pro-max bounce) | 스티커 붙이기 착지 |
| `--ease-peel` | `cubic-bezier(.2,.8,.2,1)` | 모서리 떼기, 들림 |
| `--ease-paper` | `cubic-bezier(.22,1,.36,1)` | 메모지·드로어 미끄러짐 |
| `--dur-press` | 120ms | 눌림 |
| `--dur-peel` | 180ms | 호버 떼기 |
| `--dur-stick` | 320ms | 붙이기 (scale 1.12 → 1, rotate 기본각 +6° → 기본각) |
| `--dur-paper` | 260ms | 드로어·모달·아코디언 |
| `--stagger` | 60ms | 스티커 시트 순차 등장 (back.out 1.4 근사) |

- **붙이기(stick)**: 새로 나타나는 스티커형 요소(토스트, 배지 갱신, 칸반 카드 이동 후, 선택된 탭)는 살짝 크게 떠 있다가 툭 붙는다. 붙는 순간 주변에 **작은 별 3개**(레몬, 6px)가 0.3초 튐 — 반짝이 버스트는 이것 하나뿐.
- **모달 = 포스트잇 떨어뜨리기**(위 −24px, rotate −3° → 0, 260ms), **드로어 = 속지 한 장 밀려 나옴**(오른쪽, 그림자 겹침), **아코디언 = 접힌 메모지 펼침**(높이 + 접힘선 사라짐).
- 상시 움직임은 화면당 2개까지(ux 데이터): 마키 테이프(40s/바퀴) + 폭닥이 숨쉬기(scaleY 1→1.03, 3.2s). 나머지는 상호작용 시에만. 도장 칸의 "지금 단계" 흔들림은 세 번 흔들고 멈춘다(상시 움직임에 넣지 않는다).
- `prefers-reduced-motion: reduce` → 기울기는 유지하되 모든 transition 0.01ms, 마키 정지(정적 테이프), 버스트 없음, 캐러셀 자동 넘김 없음.

## 9. index.html 구성안 — "폭닥 2027 다꾸 견본첩"

랜딩 아님. eyebrow·헤드라인·CTA 쌍·통계 줄·가운데정렬 섹션 헤더·둥근 카드 진열 **없음**. 여섯 장을 넘기는 견본첩. 각 장의 구도가 서로 다르다.

0. **상단 띠**: 다이어리 표지 위 고무줄 밴드(세로 cherry 띠 16px) + 워드마크 스티커 "pokdak · 폭닥문방구" + 오른쪽 인덱스 탭 6개(표지·스티커·테이프·메모·트래커·페이지) + 테마 토글(해 ↔ 달 스티커, aria-label "밤 다꾸 모드") + ⌘K.

1. **표지 장 — 펼친 11월 월간 페이지 (첫 화면, 1440×900 안에 완결)**
   - 왼쪽 쪽: 거대한 **"11"** (Mochiy 240px, 딸기 스티커 면으로 채운 숫자, 다이컷) + Dongle "2026년 11월" + 손글씨 "오늘은 20일 금요일 · 1월호 마감까지 D-10". 아래 폭닥이 큰 스티커(높이 280px)가 제본선을 넘어 오른쪽 쪽까지 침범.
   - 오른쪽 쪽: **calendar 컴포넌트 그대로**(11월, 모눈 칸) — 11/11 "다이어리 오픈" 테이프, 11/20 오늘 레몬 동그라미, 11/28 "다꾸 클래스" 스티커, 11/30 "1월호 마감!" cherry 스티커. 아래 테이프로 붙인 작은 메모지: "이 견본첩은 폭닥문방구 디자인팀이 매장·우편함·관리 도구에 쓰는 스티커와 종이 규칙이에요." (홍보 문구 아님, 용도 설명 한 줄)
   - 첫 화면 면적의 50%+가 파스텔 색면(숫자 스티커, 폭닥이, 일정 스티커). 다크: 같은 장면이 밤 속지 + 천장 야광 별.

2. **스티커 시트 장 — 색 · 다이컷 (빽빽한 키스컷 시트)**
   - 펼침면 전체가 하나의 대형 **스티커 시트**(점선 칼선 테두리). 색 토큰 = 크기 다른 원·구름·하트 아닌 **둥근 사각 스티커 16장**이 무작위 배치되어 각자 이름("딸기우유", "민트")과 hex(모노)를 적은 상태. 라이트/다크 쌍은 같은 스티커의 "낮/밤" 두 장을 겹쳐 붙임.
   - 시트 오른쪽 하단에 다이컷 해부도: 확대 스티커 1장 + 손글씨 화살표 주석 "흰 외곽 3px", "그림자는 자두색", "모서리를 떼어 봐요".

3. **테이프 장 — 마스킹테이프 · 타이포 (가로 띠 구성)**
   - 위: 테이프 롤 4개(원형 SVG, 구멍 포함)가 한 줄로 놓이고 각각에서 테이프가 화면 오른쪽 끝까지 풀려 나옴. 풀린 테이프 위에 각 폰트 견본(Dongle "폭닥폭닥 스티커 붙이기", Mochiy "2027", Gaegu "오늘 할 일", M PLUS 1 Code "PD-ST-0412").
   - 아래: 크기 스케일 = 길이가 다른 라벨 테이프 계단(왼쪽 정렬, 위에서 아래로 짧아짐). 여기서 **marquee** 테이프가 화면 전폭을 가로지름(상시 움직임 1번).

4. **메모 콜라주 장 — 버튼 · 폼 · 오버레이 상태 (겹쳐 붙인 메모지 벽)**
   - 3열 비정형 콜라주(폭 5:4:3), 메모지들이 서로 20px씩 겹침. ① 버튼 스티커 시트(primary/secondary/ghost/danger × 기본/호버/눌림/비활성, 손글씨 화살표 주석) ② 주문서 메모지(form 전 요소, 이수아 U-58214 배송지) ③ **열린 상태 정적 견본**: 포스트잇 모달("1월호 신청할까요?"), 메뉴 메모 드롭다운, ⌘K 스티커 검색 시트, 드로어 속지 일부, 팝오버·툴팁 — 각각 옆에 실제로 여는 스티커 버튼.
   - 칸 높이 차는 메모지 크기·겹침으로 흡수(빈 공백 금지, `align-items: start` + 3열 하단에 테이프 붙인 폴라로이드로 채움).

5. **해빗 트래커 장 — 데이터 (가장 빽빽, 기울기 0°)**
   - 왼쪽 쪽: **이번 주 주문 트래커** — 월~일 7칸 × 시간대 원 칸 채우기(진행 원형) + 일별 주문 막대(테이프 길이, 월 98 · 화 121 · 수 167 · 목 139 · 금 146). 그 아래 table 장부(오늘 주문 10행: PDK-261120-0137~0146, 고객·상품·금액·상태 스티커) + pagination.
   - 오른쪽 쪽: timeline 타임테이블(오늘 12:00–20:00 매장 일정), progress(1월호 2,418/3,000 테이프 바), steps(우편함 1월호 제작 단계 도장), accordion(자주 묻는 질문 메모 묶음), tabs(인덱스 탭: 주문 / 구독 / 다꾸 테이블), skeleton·spinner·empty 견본은 하단 "아직 안 붙인 칸" 띠에.

6. **페이지 장 — 9개 페이지로 가는 폴라로이드 줄 + 뒤표지**
   - 빨랫줄(테이프 한 줄)에 폴라로이드 9장이 집게 대신 테이프로 매달림(높이 엇갈림, 기울기 순환). 각 폴라로이드 = 해당 페이지 장면의 축소 CSS 일러스트 + 손글씨 제목 + 실제 링크. carousel(스티커 팩)도 이 장에서 시연.
   - 맨 끝 **뒤표지**: cherry 면 전폭 + 고무줄 밴드 + 공통 푸터 문구.

모바일(390): 장마다 한 쪽 세로. 1장은 "11" 숫자 140px + 폭닥이가 숫자 뒤에서 고개 내밈 → 달력이 바로 아래. 인덱스 탭은 오른쪽 가장자리 고정이 아닌 각 장 시작부 가로 탭 줄(스크롤 페이드 힌트).
