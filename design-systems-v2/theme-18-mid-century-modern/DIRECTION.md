## 1. 클라이언트 · 세계관

### 스타일의 원래 맥락
1950~60년대 미국·유럽의 **제트기 시대(Jet Age) 항공사 광고**(Pan Am, TWA, United의 여행 포스터와 기내 브로셔)와 **가전 광고**(냉장고·라디오·토스터의 「올해의 컬러」 지면)가 출발점이다. 공통 문법은 이렇다.
- 실크스크린·석판 인쇄의 **평면 색면 4~5도**. 그라디언트 없이 색판을 겹치고, 판이 1~3mm씩 어긋난다(misregistration).
- 일러스트는 사진이 아니라 **기하 도형으로 단순화한 비행기·산·태양·구름**이다. 구름은 부메랑이나 키드니 모양이다.
- 광고 카피는 **크고 짧은 헤드라인 + 작은 글씨 본문 3단**이다. 가격은 **톱니 별(스타버스트) 딱지**에 넣는다.
- 항공기 동체를 가로지르는 **치트라인(cheatline)**, 곧 창문 줄을 따라 칠한 2~3색 평행 띠가 항공사 아이덴티티의 핵심 장치다.
- 브로셔는 **3단 접지**, 시간표, 노선도, 탑승권, 좌석 주머니의 **안전 안내 카드**로 구성된다.

한국의 같은 시기에는 1950~60년대 국내 민간항공 광고와 가전 신문광고의 손글씨 도안 문자가 있었다. 2020년대 한국에서는 「뉴트로」라는 이름으로 이 시대 그래픽을 복각하는 브랜드가 실제로 팔린다.

### 클라이언트 (한국, 가상) — 제비항공 JEBI AIR
- 김포공항을 거점으로 **제주·여수·울산·포항경주**를 오가는 국내선 소형 항공사다. ATR 72-600 터보프롭(프로펠러) 4대를 운용한다.
- 세계관 설정: **1959년 김포에서 프로펠러기 두 대로 창업**했다. 2019년 리브랜딩 때 창업 당시의 리버리(크림 동체 + 산호·해바라기·청록 3색 치트라인)와 광고 지면을 복각했고, 기체 4대에는 각 기체의 꼬리 색 이름을 붙였다.
- 이 디자인 시스템이 쓰이는 곳은 세 군데다.
  1. **운항 안내 브로셔 웹판**(index): 계절마다 발행하는 「2026 가을·겨울 운항 안내」.
  2. **승객용 화면**: 운임표(pricing), 굿즈 상세(product), 제비클럽 회원 가입·프로필·설정.
  3. **직원용 화면**: 수익관리 운항 현황판(dashboard), 고객센터 문의함(inbox), 브랜드팀 캠페인 보드(kanban).
- 왜 이 클라이언트인가: 미드센추리 그래픽이 가장 자연스럽게 "정보"가 되는 곳이 항공사이기 때문이다. 항로는 부메랑 곡선, 기체 줄무늬는 치트라인, 운임은 스타버스트 딱지, 시간표는 모노 활자, 안전 안내는 번호 매긴 평면 그림이 된다. 장식할 이유를 따로 지어낼 필요가 없다. 기념품 숄더백(product)으로 가전 광고의 「색상 선택」 문법도 함께 들어온다.

### 감정 톤 (한 문장)
**"토요일 아침 김포 탑승구 유리창 너머, 크림색 프로펠러기에 햇살이 비치고 '제주까지 한 시간 십 분'이 적힌 광고판이 웃고 있는, 들뜨고 낙관적인 출발 직전의 기분."**
첫 화면 1초 안에 "**밝다, 떠나고 싶다, 옛날 광고 같은데 세련됐다**"가 와야 한다. 어두운 갈색, 회색 기술 문서 톤, 서재 감성은 금지한다.

## 6. 레이아웃 문법 — 「브로셔 펼침면」

이 테마만의 규칙. 모든 섹션이 같은 max-width 카드 그리드가 되는 것을 금지한다.

1. **지면은 풀블리드, 판은 4종.** 섹션은 화면 끝까지 차는 지면이고, 아래 판 중 하나를 고른다. 같은 판을 연속 두 번 쓰지 않는다.
   - **A · 색면 광고판**: 청록·밤하늘·산호 중 한 색으로 칠한 면. 카피는 12단 중 **1–6단 좌측 정렬**에 둔다. 평면 일러스트는 **7–12단에 놓고 오른쪽 또는 아래로 15~30% 잘려 나가게(bleed)** 한다. 헤드라인은 -3°까지 기울일 수 있다(이 판에서만).
   - **B · 광고 본문판**: 용지 바탕. 헤드라인이 1–8단을 차지하고, 아래에 **작은 글씨 본문 3단**(각 32자 안팎, 단 사이 세로 헤어라인 1px)을 둔다. **10–12단에 스타버스트·쿠폰 박스를 비스듬히(-8°~-12°)** 놓는다.
   - **C · 3단 접지판**: 4/4/4 단. 단 사이는 간격이 아니라 **점선 접지선**(1px dashed `--ink` 40%)이고, 위·아래 끝에 8px 재단 눈금을 둔다. 각 단 배경색을 한 톤씩 다르게 한다(용지 / 연어 파스텔 / 시폼 파스텔).
   - **D · 안전 안내 카드판**: 3px 잉크 테두리 안에 2×3 칸, 칸마다 큰 원형 번호(①~⑥)와 평면 그림을 둔다. 좌석 주머니의 안전 안내 카드 문법이다.
2. **그리드**: 12단. 바깥 여백 1440에서 64px, 1024에서 40px, 390에서 20px(360에서 16px). 거터 24px / 모바일 16px. 텍스트 측정폭은 본문 최대 62자, 작은 글씨 3단은 단당 28~34자.
3. **정렬**: 언제나 **좌측 정렬, 오른쪽 흘림**. 가운데 정렬 섹션 헤더는 금지한다. 숫자 열은 오른쪽 정렬이다. 가운데 정렬은 스타버스트 내부와 404 숫자에만 허용한다.
4. **섹션 머리**: 「작은 라벨 → 제목 → 부제」 공식을 쓰지 않는다. 대신 **쪽 번호 + 지면 이름**을 모노·라틴으로 지면 모서리에 붙이고(예: 오른쪽 위 `P. 04 — 3단 접지`, 이 표기의 한글은 Plex KR 자간 0), 헤드라인은 카피 자체로 쓴다.
5. **여백 리듬은 판마다 다르다.** A 상하 120px(모바일 72), B 위 96·아래 72(모바일 56/48), C 상하 64(모바일 40), D 상하 88(모바일 56). 표지는 `min-height: 100svh`(최소 720px).
6. **구획은 카드가 아니라 선과 색 바뀜으로 한다.** 지면 경계는 색이 바뀌는 곳이거나 치트라인이다. 카드 안에 카드를 넣지 않는다.
7. **반경**: 지면·표·패널 **0**. 입력·작은 카드 **6px**. 버튼·배지·탭 **알약 999px**(가전 푸시 버튼). 일러스트 창·아바타·캐러셀 슬라이드는 **비행기 창 프레임** `border-radius: 46% / 36%`(세로 타원 사각). 이 세 가지 말고 다른 반경은 없다.
8. **그림자**: 블러가 있는 그림자는 금지한다. 쓸 수 있는 것은 두 가지다. ① **판 어긋남**: 일러스트 색면 뒤에 다른 색판을 `3px -2px` 어긋나게 겹친다(블러 0). ② **푸시 버튼 턱**: 버튼 아래 `inset 0 -3px 0` 한 톤 짙은 띠. 오버레이(모달·드로어)는 그림자 대신 2px 잉크 테두리와 배경 `--ink` 45% 딤 처리로 띄운다.
9. **모바일(≤ 720px)**: A판의 일러스트는 카피 **위로 올라가고**, 오른쪽 30%가 잘린다. B판의 3단은 1단, 스타버스트는 헤드라인 오른쪽 위 **여백**(쪽 번호 아래 모서리)에 겹친다 — 헤드라인 글자 위에 겹치지 않는다. **index의 C판 3단 접지와 D판 안전 안내 6칸은 세로로 쌓지 않고 옆으로 넘긴다**(칸 폭 86%, 다음 칸이 14% 비쳐 보이고 위에 「옆으로 넘겨 …」 한 줄 힌트, scroll-snap). 접지선은 세로 점선 그대로다. 페이지 장면(pricing 운임 3단 등 나란히 비교해야 하는 곳)은 base 규칙대로 가로 점선을 두고 세로로 쌓는다. 같은 꼴을 index의 카드 3장·게시판/운임 규정·직원 화면 견본·간격/반경/턱 견본에도 쓴다. 브로셔를 넘기는 리듬을 지키려는 규칙이며, 390 index 전체 높이 목표는 16,000px 이하다.

## 7. 시그니처 (2개, 끝까지)

### ① 치트라인 (Cheatline) — 기체 동체 3색 띠
- 형태: **산호·해바라기·청록 3줄 평행 띠**. 기본 두께 각 6px, 간격 3px. 끝이 위로 휘어 올라가 **부메랑 곡선**으로 끝난다(SVG path 하나, `stroke: currentColor` 3개 레이어, 색은 `style="stroke:var(--…)"`).
- 크기 단계: `--cheat-xl`(각 10px, 표지·뒤표지 가로지르기), `--cheat-m`(각 6px, 내비 하단·지면 전환), `--cheat-s`(각 3px, 컴포넌트 내부).
- 적용처:
  - **navbar 하단 테두리** = cheat-m 직선 3줄(풀폭).
  - **지면 전환**: 표지→첫 펼침면 사이에 cheat-xl이 왼쪽에서 들어와 오른쪽 끝에서 위로 휘어 올라간다. 한 페이지에 휘는 곡선은 최대 2회.
  - **탭 활성 표시** = 탭 아래 cheat-s 3줄. **사이드바 활성 항목** = 왼쪽 세로 cheat-s 3줄.
  - **progress 채움** = 3색 줄무늬 띠(같은 3색 가로 스트라이프). 진행 끝에 작은 비행기 아이콘.
  - **카드·모달·토스트 상단** = cheat-s 한 줄(카드는 기체 꼬리색이 정해진 경우 그 한 색만).
  - **표 머리 아래**, **탑승권 절취선 위**, **footer 상단**.
- 다크에서도 3색을 유지한다(다크 값 산호 `#F0663F`, 해바라기 `#F5BE3A`, 청록 `#3FB3AE`).

### ② 스타버스트 플래시 (Starburst Flash) — 광고 가격 딱지
- 형태: **24꼭지 톱니 별**. `clip-path: polygon()`으로 바깥 반지름 100%, 안쪽 반지름 82%, 24꼭지를 그린다. 해바라기 면 + 잉크 글자이고 **-10° 회전**한다. 크기 3단: 168px(표지·가격), 96px(배지형 큰 숫자), 44px(카운트 배지).
- 내부 조판: 위에 작은 한글(「편도」), 가운데 League Spartan 가격(`₩39,000`), 아래 「부터」. 가운데 정렬을 허용하는 유일한 곳이다.

## 8. 모션 문법 — 「활주와 이륙」

| 토큰 | 값 | 용도 |
|---|---|---|
| `--dur-press` | 120ms | 버튼 눌림(턱이 0px로 접히고 translateY 2px) |
| `--dur-hover` | 200ms | 색·밑줄·호버 |
| `--dur-overlay` | 320ms | 모달·드로어·팝오버 |
| `--dur-enter` | 420ms | 지면 진입 |
| `--dur-cheat` | 900ms | 치트라인 그리기(1회) |
| `--ease-taxi` | `cubic-bezier(.2,.8,.2,1)` | 기본 |
| `--ease-flash` | `cubic-bezier(.34,1.56,.64,1)` | 스타버스트 회전만 |
| `--ease-linear` | `linear` | 프로펠러·마키 |

- **이륙 진입**: 지면 요소는 `translate(-24px, 10px)` → `0`, opacity 0 → 1로 들어온다. 왼쪽 아래에서 오른쪽 위로, 활주로를 떠나는 방향이다. IntersectionObserver로 한 번만, 스태거 40ms(10행 이상 30ms).
- **치트라인 그리기**: 지면에 들어올 때 `stroke-dashoffset`으로 왼쪽에서 오른쪽으로 900ms, 한 번만.
- **표지 비행기**: 부메랑 항로를 따라 6s 동안 한 번 날아 들어와 멈춘다. 반복하지 않는다.
- **프로펠러 스피너**: 3엽 프로펠러가 900ms에 한 바퀴 linear로 돌고, 허브는 해바라기 원이다.
- **마키(출발 안내)**: 40s linear 무한, hover/focus 시 정지, 정지 버튼 제공.
- **오버레이**: 모달은 브로셔 한 장을 내려놓듯 `translateY(16px) rotate(-1deg)` → `0`(320ms). 드로어는 오른쪽에서 슬라이드, 모바일에서는 아래에서 올라온다.
- **금지**: 블러 전환, 패럴랙스, scroll-scrub, 무한 반복 장식 애니메이션(마키·스피너 제외), 바운스 남발.
- **reduced-motion**: 모든 transform 이동을 끄고 opacity 1ms로 바꾼다. 치트라인은 처음부터 다 그려진 상태로, 프로펠러는 정지 + 「불러오는 중」 텍스트, 마키는 정지 목록, 표지 비행기는 최종 위치로 둔다.
