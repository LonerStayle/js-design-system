## 1. 클라이언트 · 세계관

### 스타일의 원래 맥락
- 이름은 2021년 말 디자이너 미하우 말레비치(Hype4)가 붙였다. 출발점은 Blender·Cinema 4D로 렌더한 **말랑한 점토 3D 아이콘**, 그 뿌리는 지점토·클레이 애니메이션(스톱모션)과 문방구 말랑이 장난감이다.
- 실사용 맥락은 **캐주얼 게임 로비**다: 젤리빈 같은 캐릭터가 무대 가운데 서 있고, 오른쪽 위에 재화 알약, 오른쪽 아래에 커다랗게 튀어나온 "시작" 버튼이 있는 구도. 누르면 꾹 들어가고 떼면 통 튀어 오르는 버튼이 이 장르의 촉감이다.
- 데이터 근거: ui-ux-pro-max Claymorphism 행의 Best For = "children's apps, onboarding, **casual games**, creative tools".

### 클라이언트 (한국) — 주물럭 스튜디오 · 「반죽섬 파티」
- **주물럭 스튜디오**(서울 성수동, 직원 38명) 의 4인 파티 게임 **「반죽섬 파티」**(워드마크 `BANJUK!`, 한글 표기 "반죽섬 파티"). 모바일·PC 크로스플레이, 전체이용가.
- 플레이어는 색 반죽으로 빚은 캐릭터 **반죽이**를 골라, 섬마다 열리는 미니게임(굴리기 레이스·탑쌓기·피구)을 4명이 겨룬다. 시즌마다 축제 테마가 바뀌고 시즌 패스·스킨을 판다.
- 이 디자인 시스템은 반죽섬 파티의 **게임 밖 웹 화면 전체**(로비 웹, 상점, 패스, 우편함, 프로필, 설정)와 **스튜디오 내부 라이브옵스 도구**(관제 대시보드, 업데이트 칸반)를 함께 덮는다. 플레이어 화면과 운영 화면이 같은 장난감 재료로 만들어지지만, 운영 화면은 반죽이 캐릭터를 줄이고 데이터 밀도를 올린다.

## 5. 레이아웃 문법 — "놀이 매트 위의 방(Room) · 무대 · 선반 · 더미 · 트레이"

1. **방(Room) 단위 컬러 바닥.** 페이지는 풀블리드 컬러 바닥 띠의 연속이다. 바닥색은 sky → mint → butter → peach를 돌려 쓰고 **같은 색이 연달아 오지 않는다**. 각 방은 윗모서리 반경 48px(모바일 32px)로 둥글고, 이전 방 위에 48px 겹쳐 올라온다(반죽 판을 쌓은 단면). 방 사이 경계선·구분선 없음.
2. **방마다 구도 4종 중 하나, 이웃한 방은 다른 구도.**
   - **무대(Stage)**: 가운데 원판 위 주인공 오브젝트 1개(화면에서 가장 큼) + 주변 위성 오브젝트 3–5개. 로비 장르 관습이라 이 구도만 중앙 정렬 허용.
   - **선반(Shelf)**: 좌→우 한 줄. 오브젝트 높이가 제각각이지만 **바닥이 한 기준선(선반 판, 12px 두께 흰 반죽)에 정렬**. 모바일은 가로 스크롤 선반(스냅, 끝 페이드 힌트).
   - **더미(Pile)**: 오브젝트가 서로 8–24px 겹치고 −4°/−2°/2°/3° 중 하나로 기울어 쌓임. 장식·견본 전용.
   - **트레이(Tray)**: 데이터가 많은 내용(표·달력·칸반·폼)은 흰 반죽 트레이(기본 `.tray` 반경 32px · 돌출 8px, 큰 트레이 `.tray--lg` 반경 48px) 위 12단 정밀 그리드. **트레이 안은 기울이지 않는다.**
3. **그리드.** 12단, 최대 1320px, 거터 24px. 좌우 여백 40px(데스크톱) / 16px(≤600px). 오브젝트는 컨테이너 밖으로 최대 64px까지 튀어나갈 수 있으나 방에 `overflow-x: clip`(가로 스크롤 0).
4. **여백 단위.** 4 · 8 · 12 · 16 · 24 · 32 · 48 · 72 · 112. 무대 방 상하 112px, 선반·더미 방 72px, 트레이 방 48px — 리듬을 일부러 다르게.
5. **이름표 헤더 — 단, 공식처럼 반복하지 않는다.** 방 제목의 기본형은 방 왼쪽 위 모서리에 **꽂힌 반죽 이름표**(흰 반죽 알약, −2° 기울기, Jua `--fs-h2`, 돌출 6px). 하지만 이름표 줄은 **한 페이지 방의 절반 정도에만** 쓴다(1차 결과물에서 "● 이름표 + 회색 한 줄 설명"이 15번 반복돼 브리프 3절 '반복 섹션 헤더'가 됐다). 나머지 방은 ① 물건에 꽂힌 이름표(`.nametag--stuck`, 벤치·선반 윗모서리), ② 깃발(`.flag`, 지도·섬), ③ 큰 오브젝트가 곧 제목(글자 블록 더미, 리뷰 점수 덩어리, 오늘 판 수 큰 숫자), ④ 선반 판 앞 레일 이름표 중 하나로 단다. 회색 설명 줄은 대부분 지우고, 남길 때는 물건·트레이 안에 넣는다.
6. **접지 그림자.** 떠 있는 오브젝트 아래에는 타원 접지 그림자(`::after`, 폭 80%, 높이 14px, `radial-gradient(closest-side, rgba(29,33,66,.22), transparent)`). 분위기용 흐린 얼룩이 아니라 "바닥에 닿은 물체"를 설명하는 그림자이며, 오브젝트 바로 아래에만.
7. **게임 HUD 셸.** 상단 바(높이 72px, 떠 있는 흰 반죽 알약, 화면 가장자리에서 16px 띄움): 왼쪽 = 플레이어 칩(반죽이 얼굴 + 닉네임 + 레벨 링), 가운데 = 워드마크 `BANJUK!`, 오른쪽 = 재화 알약(젤리·코인) + ⌘K + 테마 토글. 운영 화면은 플레이어 칩 대신 "한소율 · 라이브옵스" 칩. ≤1080px(상단 내비가 숨는 폭)부터 하단 **도크**(높이 76px, 64px 원형 반죽 버튼 5개: 로비·상점·패스·우편·설정, 가운데 로비 버튼만 버터·72px로 솟음)가 메인 내비.
8. **회전 규칙.** 회전 값은 −4° · −2° · 2° · 3° 4개만. 글을 읽어야 하는 블록(문단·표·폼)은 0°.

## 6. 시그니처 (2개, 끝까지)

### 시그니처 ① 반죽 슬랩 — "눈에 보이는 두께"
모든 누를 수 있는 오브젝트는 **윗면 + 돌출 받침 + 안쪽 하이라이트 + 안쪽 그늘 + 바닥 그림자** 5겹이다. 받침은 같은 색의 deep 톤 단색 띠라 측면에서 본 점토 두께처럼 보인다.
```
--slab-h: 6px;   /* sm 4 · md 6 · lg 8 · xl 12 */
box-shadow:
  inset 0 3px 0 rgba(255,255,255,.55),          /* 윗면 하이라이트 (다크 .18) */
  inset 0 -5px 10px rgba(0,0,0,.10),            /* 윗면 아래쪽 말랑 그늘 */
  0 var(--slab-h) 0 var(--slab-color),          /* 돌출 받침 (각 반죽 deep) */
  0 calc(var(--slab-h) + 10px) 22px -8px rgba(29,33,66,.35); /* 바닥 그림자 (다크 rgba(3,5,20,.7)) */
```
- **누름**: `translateY(calc(var(--slab-h) - 2px))` + 받침 2px로 줄어듦 + `scale(1.04, .94)` 스쿼시(옆으로 퍼짐), 90ms `--ease-squish`. **뗌**: 420ms `--ease-boing`로 튀어 오름.
- **호버**: `translateY(-2px)` + 받침 +2px, 260ms.
- **파인 홈(Well)** 은 그 반대: 인풋·슬라이더 트랙·진행바 바닥·체크박스 빈칸은 `inset 0 4px 0 rgba(29,33,66,.10), inset 0 -2px 0 rgba(255,255,255,.7)`, 받침 없음, 배경 `--well`. 채워지는 것(진행바 채움, 슬라이더 손잡이, 체크 표시)은 다시 슬랩.
- **포커스**: 슬랩 그림자 목록 끝에 `0 0 0 3px var(--clay-white), 0 0 0 6px var(--ring)`를 **합성**해 그림자가 링을 덮지 않게(v1 결함 재발 금지). 각 컴포넌트의 `:focus-visible`에서 자기 슬랩 + 링을 함께 선언.
- **반경**: 버튼·칩·인풋 = 알약(999px), 작은 컨트롤 20px, 카드·패널 32px, 트레이·방 48px, 캐릭터·장식 = 비대칭 블롭 반경. 같은 반경이 화면 전체를 덮지 않게 크기별로 갈린다.

### 시그니처 ② 반죽이 — 상황을 연기하는 캐릭터
토마·민트콩·버터·블루베(1절 표)를 CSS로 빚는다: 블롭 반경 몸 + 슬랩 그림자 + 흰자 없는 잉크 눈 2개(지름 몸의 11%) + 딸기색 볼터치 2개. 표정 5종: 기본 · 웃음(눈 ∩) · 놀람(눈 O + 입 o) · 어지러움(눈 ×, 오류) · 잠(눈 —, 빈 상태/로딩).
- 쓰는 자리(그리고 **여기에만**): 로비 무대 · 빈 상태 · 토스트 아이콘 자리(작은 얼굴, 성공=민트콩 웃음, 오류=토마 어지러움, 정보=블루베, 보상=버터) · 스피너(버터가 눌렸다 펴지는 스쿼시 루프) · 404 · 온보딩 안내자 · 아바타 기본값(프로필 사진 없는 사람).
- 운영 화면(dashboard·kanban)에는 아바타·빈 상태에만 등장, 데이터 영역에는 넣지 않는다.
- 눈은 4–7초 간격 깜빡임, 데스크톱에서 포인터 방향으로 최대 3px 시선 이동. reduced-motion이면 둘 다 끔.
- 이모지 금지. 아이콘은 인라인 SVG 24 그리드, stroke 2.5, `stroke-linecap/linejoin: round`, `currentColor`.

## 7. 모션 문법 — "꾹 들어갔다가, 통 튀어나온다"

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--ease-squish` | `cubic-bezier(.3, 0, .6, 1)` · 90ms | 누름 |
| `--ease-boing` | `cubic-bezier(.34, 1.56, .64, 1)` · 420ms | 뗌·토글·탭 인디케이터 (데이터의 바운스 값) |
| `--ease-out` | `cubic-bezier(.2, .8, .2, 1)` · 240ms | 오버레이 페이드·드로어 |
| `--dur-hover` | 260ms | 호버 떠오름 |
| `@keyframes jelly` | 0% scale(1) → 30% (1.08, .92) → 55% (.96, 1.05) → 75% (1.02, .99) → 100% (1) · 600ms | 착지·등장·드롭 |
| `@keyframes bob` | translateY 0 → −8px → 0 · 3.2s ease-in-out infinite | 로비 주인공 1개 + 버터 시작 버튼 (뷰포트당 최대 2개) |
| `@keyframes blink` | scaleY 1 → .1 → 1 · 160ms, 4–7초 간격(JS 랜덤) | 반죽이 눈 |

- **등장**: 방이 뷰에 들어오면 오브젝트가 위에서 −24px 떨어져 `jelly`로 착지, 60ms 간격, 최대 8개.
- **모달**: 트리거 위치에서 `scale(.6)` → `jelly`로 부풀며 등장, 배경 딤 240ms. 닫힘은 `scale(.9)` + 페이드 160ms(튀지 않음).
- **드로어**: 옆에서 밀려 나와 8px 넘었다 돌아옴(`--ease-boing`). **토스트**: 위에서 떨어져 바닥에 한 번 튐.
- **스위치**: 손잡이가 이동 중 가로 130%로 늘었다 붙음(젤리 드래그). **탭·세그먼트**: 버터 인디케이터가 `--ease-boing`로 미끄러짐.
- **칸반 드래그**: 집으면 3° 기울고 `scale(1.05)`, 받침 12px로 들림. 놓으면 `jelly` 착지 + 받은 열이 `wiggle`(−1° → 1° → 0, 300ms).
- **숫자**: 큰 숫자는 등장 시 0에서 카운트업 700ms(대시보드 동접·로비 재화).
- **prefers-reduced-motion**: bob·blink·jelly·카운트업·시선 이동 전부 끔. 누름은 받침 두께·색 변화만(이동·스쿼시 없음), 전환 120ms 이하 opacity만.

## 9. index.html 구성안 — 「반죽섬 파티 로비 · UI 장난감 상자」

매체: **게임 로비 화면 + 장난감 상자 놀이터**. 스크롤하면 로비 무대에서 출발해 방을 하나씩 지나 섬 지도에 도착한다. 각 방은 구도가 다르다.

1. **로비 무대 (Stage · floor-sky)** — 첫 화면.
   - HUD 상단 바: 콩떡대장 칩(민트콩 얼굴, Lv.62 링) · `BANJUK!` · 젤리 2,340 / 코인 18,650 · ⌘K · 테마 토글.
   - 왼쪽 위에 꽂힌 간판: Jua 112px 반죽 글자 **"반죽섬 파티"**, 그 아래 작은 알약 `SEASON 7` + "가을 반죽 축제 · D-39".
   - 가운데: 버터 원판 무대(지름 520px, 받침 12px) 위에 반죽이 4명(토마·민트콩·버터·블루베, 크기 다르게). 민트콩만 bob.
   - 오른쪽 아래: 실제 주 버튼 **"놀이 시작"**(버터, 높이 88px, 반죽 글자). 그 위 파티 슬롯 4칸(3명 + 빈 칸 "초대").
   - 무대 주변에 진짜 컴포넌트가 장난감처럼 놓임: 시즌 패스 진행바(티어 34/80), 스위치 하나, `NEW` 배지 붙은 우편함 아이콘 버튼, 오늘 미니게임 로테이션 마키(무대 아래 띠).
   - 모바일: 간판 → 무대(캐릭터 2명) → 놀이 시작 → 하단 도크. eyebrow + 헤드라인 + CTA 2개 공식 없음.
   - **(2026-10-11 구도 확정)** 12단 위에 간판 1–4단 · 무대 5–9단 · 파티 10–12단. 간판은 두 줄 모두 왼쪽 정렬, HUD와 48px 이상 띄운다. 무대 맨 위에 **축제 줄**(반죽 끈 + 랜턴 4개)이 걸리고, 줄 가운데에 **섬 표지판**(민트섬 · 원활 · 동접 7,960)이 매달려 무대 위 빈 하늘을 채운다. 반죽이 넷은 원판 **한가운데**(발끝 = 원판 높이의 절반)에 서고 발밑에 접지 그림자, 이름은 머리 위 명찰(게임 닉네임 관습). 간판 아래에는 **장난감 선반**(12px 흰 반죽 판) 하나에 패스 티어 카드 · 우편함 버튼 · 진동 스위치가 같은 기준선으로 놓인다. 선반 판 바닥 ≈ 원판 바닥 ≈ 놀이 시작 버튼 아래가 한 땅선. 마퀴는 화면 폭을 채우도록 ceil(폭/한 벌)+1벌 복제.
2. **반죽통 방 (Shelf · floor-mint)** — 색. 이름표 "반죽통". 색 토큰을 **원통형 반죽통**(윗면 타원 + 몸통 슬랩)으로 선반 위에 크기 다르게 진열: 주인공 버터통이 가장 큼. 통 앞 라벨 스티커에 이름·hex·토큰(DM Mono). 선반 끝 "낮 / 밤" 레버 스위치를 당기면 **이 방만** 밤 장면으로 바뀌어 다크 값 비교. 바닥 4색은 선반 아래 매트 견본 4장.
3. **글자 블록 방 (Pile · floor-butter)** — 타이포. **방 제목 자체가 더미**다: Jua 블록 "글 자 / 블 록" 네 개가 −4°/2°/−2°/2°로 기울어 16–20px씩 겹쳐 쌓이고, Fredoka "7!" 블록이 3°로 윗줄 모서리에 걸터앉는다(이름표 없음, h2 = 더미). 오른쪽에 서체 견본 2×2, 아래 전체 폭 트레이에 스케일 표(2단). 폰트 이름은 블록에 붙은 태그.
4. **두께 실험실 (Stage 변형 · floor-peach)** — 시그니처 ①. 이름표는 벤치 윗모서리에 꽂힌다. 커다란 버터 버튼 하나를 **분해도**로: 하이라이트(반투명 판 위 흰 띠) · 윗면 · 받침 · 바닥 그림자 4장이 작업 매트(홈) 위에 비스듬히 펼쳐지고, 각 판 **한가운데 점에서 지시선**이 번호·이름표로 이어진다. "합치기"를 누르면 넷이 가운데로 내려앉아 버튼 하나가 됨. 옆에 받침 높이 4/6/8/12 견본과 반경 견본 — 각 견본이 실제로 눌림. 모션은 같은 크기 카드 4장이 아니라 **한 선반 판 위 반죽 넷 + 판에서 끈으로 매달린 가격표 넷**(곡선 · 이름 · 값 · 버튼).
5. **장난감 상자 방 (Tray 다수 · floor-sky)** — 32개 컴포넌트. 6개 **열린 상자**(크기 서로 다름, 벤토)로 나눔. 상자 머리는 색 띠가 아니라 **손잡이 달린 뚜껑**(몸통보다 살짝 넓게 얹힘)이고, 뚜껑에는 한글 장난감 이름 + 작은 흰 꼬리표(코드 이름 11px)만. 상자 속 견본마다 **한글 스티커**(`버튼 · button`, 코드는 11px 모노):
   - 누르는 장난감: button · badge · tooltip · popover · menu · pagination
   - 끼우는 장난감: form(인풋·셀렉트·체크·라디오·스위치·슬라이더)
   - 쌓는 장난감: card · list · table(시즌 7 상점 아이템 6행) · kanban(미니 3열) · timeline(시즌 일정)
   - 길 찾는 장난감: navbar · sidebar · breadcrumb · tabs · steps
   - 알려주는 장난감: alert · toast · progress · spinner · skeleton · empty
   - 상자 속 상자: modal · drawer · command · accordion · carousel · calendar(10월) · code · marquee · motion
   - 오버레이(modal·drawer·command·menu·popover)는 **열린 상태를 정적으로 렌더한 견본**(딤 처리된 미니 트레이 안, 브라우저 창 목업 아님) + 실제로 여는 버튼을 둘 다.
6. **섬 지도 (floor-mint, 풀블리드)** — 9개 페이지 입구. 방 제목은 이름표가 아니라 지도에 꽂힌 **깃발**. 인라인 SVG 길(굵기 14px 반죽 끈, 곡선 1개)로 이어진 섬 9곳: 첫걸음 섬(onboarding, 처음 온 친구 · 반죽이 만들기 4단계) · 상점 섬(product) · 패스 섬(pricing) · 우편함 섬(inbox) · 내 방(profile) · 설정 공방(settings) · 관제탑(dashboard) · 공작소(kanban) · 미아 놀이터(404). 각 섬 = 반죽 원판 + 이름표 링크. 모바일은 세로 지그재그 길.
7. **푸터** — 흰 반죽 판 1장: 워드마크, 고객센터 시간, 주소, `© 2026 주물럭 스튜디오 · 반죽섬 파티 · 전체이용가`.
