## 1. 클라이언트와 세계관

### 모양학교 MOYANG SCHOOL
- **무엇**: 서울 종로구 창신동 봉제골목 안 4층 건물(가상)을 쓰는 **기초조형 학교**. 12주 「예비과정」(바우하우스 Vorkurs를 한국식으로 옮긴 입문 과정, 기수제·정원 24명), 4주 단과 워크숍(색채·활자·재료), 공방(목공·금속·활판인쇄·암실) 시간제 대여, 교본·교구 상점, 그리고 매 학기말 1층 「구성실」에서 여는 **수료전**을 운영한다. 웹사이트는 수강 신청·과제 제출·공방 예약·전시 관람 예약·교본 상점·교무 관리를 한 곳에서 한다.
- **이름의 근거**: 모양 = 형태(Gestalt). 바우하우스가 "모든 조형은 기본 도형에서 시작한다"고 가르쳤듯, 학교 이름 자체가 "형태를 배우는 곳"이다. 워드마크는 라틴 `MOYANG` + 칸딘스키 대응 세 도형 `△□○`(노랑·빨강·파랑).
- **이 스타일이 진짜 어울리는 이유 (원래 맥락)**: 바우하우스는 1919년 바이마르에서 세워진 **학교**다. 그래픽 언어는 거기서 나온 결과물 — ① 1923년 첫 대전시회 포스터(요스트 슈미트: 원·사각·사선 막대로 짠 구성), ② 교재 시리즈 『바우하우스 총서(Bauhausbücher)』 14권(모홀리-나기의 조판: 굵은 막대, 90° 회전 활자, 큰 숫자), ③ 이텐의 예비과정 연습 과제(색 대비 7종), ④ 1923년 칸딘스키 설문(노랑=삼각형, 빨강=사각형, 파랑=원을 맞히게 한 수업 질문지), ⑤ 바이어의 유니버설 알파벳(기하 산세리프), ⑥ 바우하우스가 채택한 DIN 476 종이 규격(1:√2). 「모양학교」는 이 다섯 매체를 그대로 생활 도구로 쓰는 학교다 — 포스터는 수료전 포스터, 교재는 상점의 교본, 연습 과제는 과제 제출 시스템, 칸딘스키 설문은 입학 온보딩이 된다.
- **감정 톤 (한 문장)**: 수료전 개막 주간, 갓 인쇄된 원색 포스터가 교실 벽에 붙고 학생들이 자기 도판을 들고 뛰어다니는 — **명랑하고 단단한, 손으로 짜 맞춘 기쁨**. (차가운 사양서가 아니다. 첫 화면 1초 안에 "원색 포스터가 붙은 교실"이 느껴져야 한다.)

## 5. 레이아웃 문법 — 「구성판(構成板)」

이 테마의 화면은 **정사각 모듈을 맞물려 짠 구성판**이다. 02 스위스처럼 그리드를 보여주지 않는다 — 그리드는 숨어 있고, 보이는 것은 **맞닿은 색면과 그 사이 2px 먹선**이다.

1. **정사각 모듈 6단.** 데스크톱(≥1200) 6단, 바깥 여백 48px, **거터 0**. 행 높이 = 단 폭(`grid-auto-rows` = 단 폭, `aspect-ratio: 1` 모듈). 1440에서 모듈 ≈ 224px. 태블릿(768–1199) 4단, 여백 32px. 모바일(<768) **2단**, 여백 16px → 390에서 모듈 179px.
2. **블록은 모듈 배수로만**: 1×1, 2×1, 1×2, 2×2, 3×2, 4×2, 2×3, 6×1. 블록끼리 **틈 없이 맞닿고** 경계는 2px `--line` 하나(`gap: 0` + 블록 `outline`/공유 테두리, 이중선 금지). 내용 안쪽 여백 24px(모바일 16px).
3. **판 하나 = 색면 하나.** 한 판(섹션)에 원색 면은 최대 **2개**, 그중 하나는 판 전체 면적의 1/6 이상(작은 색 점 흩뿌리기 금지 — 멤피스·맥시멀과 구분). 나머지는 종이/표면.
4. **비대칭 무게 + 원의 중심축.** 무게(큰 색면·큰 활자)는 한쪽으로 쏠린다. 텍스트는 flush-left. **가운데 정렬이 허용되는 유일한 경우: 원 안의 글자**(원 중심에 맞춤). 섹션 헤더 가운데 정렬 0건.
5. **축은 0° / 90°만.** 회전 활자는 90°(`writing-mode: vertical-rl` — 한글은 세로쓰기, 라틴은 `rotate(-90deg)` 블록). 사선은 index 첫 화면 포스터의 **45° 막대 1개**와 404의 해체 구성에만.
6. **판 높이 리듬을 의도적으로 바꾼다.** 포스터 판(1–1.4 뷰포트, 여백 큼) → 교본 펼침면(2×2 + 4×2, 중간) → 연습 문제 판(모듈 밀집) → 배치도 판(넓은 도면). 같은 판 구성을 연속 두 번 쓰지 않는다.
7. **교본 펼침면 규칙**: 왼쪽 쪽 = 2단(텍스트), 오른쪽 쪽 = 4단(도판). 접지선 = 중앙이 아니라 2단 지점의 4px 먹선. 쪽 번호(모노)는 각 쪽 아래 바깥 모서리.
8. **섹션 제목 위치는 판마다 다르다**: 세로 90° 축(판 왼쪽 1모듈 띠) / 상단 16px 막대 위 오른쪽 끝 / 색면 도형 안(원 안 중앙, 삼각 안 왼쪽 아래) / 판 아래 막대 안. "작은 라벨 → 제목 → 부제" 3단 헤더, "§ 번호 + 제목" 반복 금지.
9. **빈 칸 금지**: 모듈 블록 내용이 모자라면 그 칸은 원색 면 또는 도형 하나로 **채운다**(빈 종이 칸은 판당 1개까지, 의도적일 때만). `align-items: stretch`.
10. 360/390 가로 넘침 0 — 큰 도형은 블록 안에서 `overflow: clip`, body 넘침 금지.

## 6. 시그니처

### 시그니처 1 — 칸딘스키 대응 (△ 노랑 · □ 빨강 · ○ 파랑)
1923년 칸딘스키 설문의 답을 **이 학교의 문법**으로 고정한다. 도형과 색은 항상 짝을 이루고, 짝마다 뜻이 있다.
- **○ 파랑 = 하나의 것·완결**: 아바타, 상태점, 완료, 정보, 단일 아이콘 버튼, 라디오, 토글 손잡이, 스피너, 진행 원, 캐러셀 점, 타임라인 마디.
- **□ 빨강 = 구조·멈춤·경고**: 체크박스, 오류·위험·미제출, 삭제 버튼, 카드/입력 모서리, 페이지네이션 현재 쪽, 알림 카운트.
- **△ 노랑 = 방향·움직임·주의**: 펼침/접힘 화살표(아코디언·메뉴·셀렉트), 다음/이전, 정렬 방향, 툴팁·팝오버 꼬리, 마감 임박, 드로어 손잡이.
- 이 짝은 **어긋나지 않는다**(노랑 사각, 파랑 삼각 금지). 예외: 로고·포스터 구성에서 세 도형이 겹쳐질 때만 색이 섞인다(겹친 부분은 먹으로 처리 — `mix-blend-mode` 금지, 겹침 면은 별도 도형으로 그린다).
- 아이콘: 이모지 0, 외부 아이콘 0. 아이콘은 전부 이 세 도형 + 막대의 조합(SVG `currentColor` 또는 CSS 도형). 예: 검색 = 원 + 45° 막대, 닫기 = 막대 두 개 교차, 메뉴 = 막대 셋, 설정 = 원 + 막대 넷.
- 테마 토글: **원(낮, 노랑 아닌 파랑 원) ↔ 사각(밤, 분필 외곽 사각)** 모핑(`border-radius 50% ↔ 0`, 240ms).

### 시그니처 2 — 막대와 축 (모홀리-나기의 교본 조판)
『바우하우스 총서』 조판의 **굵은 검정 막대**와 **90° 회전 활자**.
- 굵기 체계는 다섯뿐(수정 1에서 실제 쓰는 값으로 정식화): **16px 막대**(판 머리·navbar·모달 머리) / **6px 표시 막대**(활성 탭·사이드바 활성·표 헤더·밑막대) / **4px 접지선**(교본 펼침면·평면도 바깥벽) / **2px 구조선** / **1px 작도선**(보조, `--hairline`). 그 외 굵기 금지.
- 막대 적용: navbar 상단 16px 막대(학교 이름이 막대 위에 얹힘), 활성 탭 = 탭 위 6px 막대, 사이드바 활성 항목 = 왼쪽 6px 막대, 표 헤더 = 위 6px 막대 + 아래 2px선, 진행 바 = 16px 막대 채움, 모달 머리 = 16px 막대, 페이지 헤드 = 판 왼쪽 세로 16px 막대.
- 축 적용: 각 페이지 헤드 왼쪽 1모듈 띠에 세로쓰기 장 제목(한글 `vertical-rl`) 또는 라틴 90° 회전 라벨(`VORKURS 12`). 카드에서는 도판 번호를 오른쪽 모서리에 90° 세로로. 모바일에서 세로 축은 상단 가로 막대 라벨로 접는다.
- 작도선(1px)은 **교본 판에서만**: 원의 중심점·반지름선·치수선을 그려 "이 도형이 어떻게 만들어졌는가"를 보여준다(index 교본 02, product 교구 도면, 404). 컴포넌트 일반에는 쓰지 않는다.

### 하지 않는 것
그림자(소프트·하드 모두), 그라디언트, blur, 중간 radius(4·8·12px), 배경 패턴(점·격자), 투명도로 색 섞기, 회전 각도 장난(15°·-8° 등).

- 화면당 모션 장치 2개 이하(ux 근거): `assemble` 1회 + 상호작용 모션.
- `prefers-reduced-motion: reduce` → 모든 도형 제자리, 막대 채워진 상태, 마퀴 정지(정적 목록), 스피너 정지 + "불러오는 중" 텍스트, 오버레이 즉시 표시.
