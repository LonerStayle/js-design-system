## 1. 클라이언트와 세계관

### 솔개에어 SOLGAE AIR (가상)
- **무엇**: 서울 수도권 도심항공교통(UAM) 운항사. 자체 개발 eVTOL 기체 **SG-4 「솔개」**(조종사 1 + 승객 4) 8대로 김포·여의도·잠실·수서·판교·인천공항 버티포트를 잇는 6개 노선을 매일 운항한다. 2026년 3월 16일(월) 상업 운항 시작.
- **디자인 시스템을 쓰는 곳**: ① SG-4 조종석 디스플레이(PFD·MFD) 소프트웨어의 웹 미러와 **조종사 운용 교범(POH) 온라인판**, ② 김포 운항통제센터(OCC)의 관제 도구, ③ 정비 작업지시 보드, ④ 승객용 탑승권 예매 화면. 모든 화면이 같은 계기 문법을 공유한다(승객 화면도 "조종석에서 본 내 비행"을 보여 준다).
- **이름의 근거**: 솔개는 제자리에서 정지 비행(호버링)하는 맹금이다. 수직 이착륙기의 상징. 워드마크 `SOLGAE`는 Chakra Petch 600, 글자 사이 `·` 대신 비행 경로 마커 기호(원 + 좌우 날개선)를 SVG로 둔다.
- **이 테마가 진짜 어울리는 이유 (스타일의 원래 맥락)**: HUD/FUI의 뿌리는 1950년대 전투기 반사식 조준기 → 1970년대 민항기 HUD → 1980년대 글래스 콕핏(EFIS: Boeing 757/767, Airbus A320 ECAM)이다. 검은 유리 위 벡터 심볼로지, 1px 선, 눈금 테이프, 색 규약(ARINC 661 계열 관행)이 원형이고, 영화 FUI는 그것을 과장한 2차 가공물이다. 실제로 그 화면을 매일 읽는 한국 서비스 = 2025~2028 K-UAM 실증·상용화 단계의 도심 항공 운항사. 조종석·관제·정비·승객이 같은 "계기 언어"를 쓴다는 서사가 성립한다.
- **감정 톤 (한 문장)**: 저녁 7시 42분, 한강 상공 450m — 계기 불빛만 남은 조종석에서 숫자 하나하나가 정확히 제자리에 있다는 **팽팽하지만 통제된 긴장감**.

## 5. 레이아웃 문법 — "베젤 위의 디스플레이 유닛"

화면 전체가 **계기판(패널)** 이고, 내용은 **DU(Display Unit, 디스플레이 유닛)** 에 담긴다. 섹션이 아니라 계기를 배치한다.

1. **베젤 바탕**: 페이지 바탕(`--bg`)은 베젤이다. DU 사이 간격은 **6px**(베젤 틈) 또는 **24px**(계기 군 사이) 둘뿐. 그 외 갭 금지 — 계기는 빽빽하거나 확실히 떨어진다.
2. **그리드**: 1440 기준 바깥 여백 24px, **12단 · 거터 6px**. DU는 실제 콕핏처럼 비대칭 비율로 놓는다: PFD 7단 + ND 5단, 또는 4 + 4 + 4 계기 군. 같은 구도를 연속 두 번 쓰지 않는다.
3. **소프트키 레일**: 주요 DU 좌우(또는 하단)에 44px 폭 소프트키 레일. 레일의 버튼이 DU 안 화면을 바꾼다(탭·캐러셀·페이지 전환이 모두 이 문법). 모바일(<768)에서 레일은 DU 아래 가로 줄(44px 높이, 가로 스크롤 + 오른쪽 페이드 힌트).
4. **DU 내부 정렬**: 좌상단 = 페이지 코드(라틴 모노 11px, `SYS` `ND` `CAS`) + 한글 페이지 이름(17px Gothic A1 700). 우상단 = 기준 시각 또는 상태 램프. 본문은 좌측 정렬, 숫자는 우측 정렬(소수점 정렬). 가운데 정렬은 **원형 계기 안쪽과 레티클 주변에만**.
5. **리듬 변주**: 풀블리드 DU(바깥 여백 0) → 6px 틈 빽빽한 램프 격자 → 베젤 위에 그려진 계통도(DU 없이 선만) → 560px 폭 좁은 체크리스트 칼럼(왼쪽 3단에서 시작, 오른쪽엔 세로 테이프 레일). 섹션마다 폭·밀도·면 유무가 바뀐다.
6. **반경 0.** 둥근 모서리는 원형 계기(게이지·레티클)와 상태 점에만. 리드아웃 창·주 버튼은 `clip-path`로 한쪽 모서리 6px 베벨 컷.
7. **그림자 없음.** 깊이는 면 단계(bg → surface → bezel → pressed)와 선으로만. 다크 글로우는 심볼로지 글자·선에만(면에 금지).
8. **모바일 360–390**: DU 세로 적층, 바깥 여백 16px, DU 사이 6px. 세로 테이프(속도·고도)는 DU 상단 가로 테이프로 회전. 원형 계기는 min(100%, 320px).

## 6. 시그니처

### 시그니처 1 — 눈금 테이프 + 리드아웃 창 (Tick Tape & Readout Window)
PFD의 속도·고도 테이프에서 가져온다. **값을 가진 모든 것은 눈금 위에 놓이고, 현재 값은 한쪽이 뾰족한 리드아웃 창에 들어간다.**
- 눈금: `repeating-linear-gradient`로 소눈금 8px(1px 선, `--line-strong`) / 대눈금 40px(1px, 길이 2배, `--ink-muted`) + 대눈금마다 라틴 모노 11px 숫자.
- 리드아웃 창: 검은(라이트는 흰) 면 + 1.5px `--ink` 테두리 + 한쪽에 8px 삼각 포인터(clip-path). 숫자는 B612 Mono 700, 값이 바뀌면 세로 롤(오도미터).
- 적용: progress(테이프 바 + 창), 슬라이더(눈금 트랙 + 창 손잡이), tooltip(창 모양), badge 숫자형, pagination(눈금 위 현재 페이지 창), timeline(시간 눈금 축), table 행 번호 레일, calendar(날짜별 운항 편수 눈금), skeleton(눈금이 흐르는 정렬 중 상태), DU 가장자리(화면 좌우 가장자리 고정 눈금 — 뷰포트 레벨, `aria-hidden`), 스크롤 위치(우측 세로 테이프에 현재 섹션 창).

### 시그니처 2 — 램프와 색 규약 (Annunciator Lamp & Color Code)
경고 패널의 어넌시에이터 램프에서 가져온다. **상태는 "꺼진 램프(선만)"와 "켜진 램프(면이 채워짐)" 두 가지로 말한다.**
- 꺼짐: 1px `--line-strong` 테두리 + ink-muted 글자. 켜짐: 의미색 면 + `--on-*` 글자 + (다크만) 면 바깥 `0 0 12px` 의미색 25% 글로우.
- 적용: alert·toast(CAS 메시지: 경고=빨강 램프, 주의=앰버, 권고=시안 선, 상태=흰 글자), badge(상태 램프), button pressed·토글(눌린 소프트키 = 램프 점등), tabs 활성(마젠타 램프 테두리 + 하단 2px), navbar FMA(활성 모드 = 초록 박스), kanban 열 머리(열 상태색 램프), 마스터 경고/주의 램프(글레어실드 양 끝).
- **마스터 경고 모드**: 경고급 CAS가 하나라도 미확인이면 `html[data-master="warning"]` — 글레어실드 양 끝 MASTER WARNING 램프가 2Hz로 점멸, 뷰포트 가장자리 눈금이 빨강으로. 램프를 누르면 확인(점멸 정지). index에서 시연 버튼 제공. RM에서는 점멸 없이 점등만.

## 7. 모션 문법 — "셀프테스트, 롤, 점등"

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--dur-instant` | 80ms | 램프 점등·소등 (`steps(2)`) |
| `--dur-fast` | 120ms | 소프트키 눌림, 호버 락온 |
| `--dur-base` | 180ms | 리드아웃 숫자 롤, 탭 전환 |
| `--dur-panel` | 240ms | 드로어·모달·커맨드 열림 |
| `--dur-boot` | 480ms | DU 셀프테스트 점등 |
| `--ease-instrument` | `cubic-bezier(0.2, 0, 0, 1)` | 오버레이·바늘 — 튕김 없음 |
| `--ease-step` | `steps(4, end)` | 셀프테스트 |

1. **셀프테스트 점등(진입)**: 페이지 로드 시 DU가 열 순서대로 60ms 간격 — 0→120ms 검은 화면, 120→240ms 테스트 패턴(모든 램프 점등 + 눈금만), 240→480ms 내용 표시. opacity·clip-path만, y 이동 없음. 화면 밖 DU는 IntersectionObserver로 처음 보일 때 1회.
2. **롤**: 숫자 변경은 세로 롤 180ms. 실시간 값(dashboard 시각·SoC)은 1초 단위 갱신, 롤 사용.
3. **락온 호버**: 카드·행 호버 시 DU 모서리 눈금 4개가 4px 안쪽으로 모이고 테두리가 `--line-strong`→`--select`. 120ms.
4. **선 그리기**: 계통도·비행 경로는 `stroke-dashoffset`로 그려짐(600ms, 1회). 전원이 들어온 계통선만 상시 흐름(1.2s linear) — 화면당 상시 모션 최대 2개(계통 흐름 + ATIS 띠).
5. **점멸**: 마스터 경고 램프 1개만, 2Hz(500ms 주기), 확인 시 정지. 그 외 점멸 금지.
6. **`prefers-reduced-motion: reduce`**: 셀프테스트·롤·흐름·띠·점멸 전부 정지, 최종 상태 즉시 표시. ATIS 띠는 정적 한 줄 + 일시정지 버튼 숨김.
