## 1. 클라이언트 · 세계관

### 스타일의 원래 맥락
멤피스 그룹(Memphis Milano)은 1981년 9월 밀라노 가구 박람회 기간, 에토레 소트사스가 이끈 디자이너들이 **가구·조명·오브제 컬렉션**을 발표하며 시작됐다. 핵심 재료는 고급 원목이 아니라 **커피숍 테이블에 쓰던 싸구려 플라스틱 라미네이트**였고, 소트사스의 「박테리오」(꿈틀거리는 벌레 무늬), 나탈리 뒤 파스키에의 직물·라미네이트 패턴이 가구 표면을 덮었다. 대표작 「칼턴」 책장은 원색 판재를 토템처럼 쌓아 올린 수납장이다. 멤피스는 **"가구 회사"** 였고, 그 세계를 사람들이 만난 매체는 **상품 카탈로그·전시 도록·견본 판**이었다. → 도형은 장식이 아니라 **가구의 부품**이고, 패턴은 배경이 아니라 **팔리는 마감재 견본**이다.

### 클라이언트 (한국, 가상) — 도형상회 DOHYEONG SANGHOE
- 서울 성수동의 포스트모던 가구·라미네이트 브랜드. 파주 공방에서 소량 생산한 책장·사이드 테이블·조명·오브제를 성수 쇼룸과 온라인에서 판다. 라미네이트 패턴 6종을 직접 디자인해 **가구 마감 선택지**이자 **인테리어 업체용 견본(A6 판)** 으로도 판매한다.
- 계절마다 종이 카탈로그를 낸다. 이번 호: **『도형상회 카탈로그 No.07 — 2026 가을·겨울』**.
- 이 디자인 시스템이 쓰이는 곳: ① 카탈로그 웹판(index), ② 상품 상세·트레이드 프로그램(pricing)·디자이너 프로필 등 고객용 화면, ③ 직원용 "작업실" 백오피스(현황판·문의함·공방 제작 보드·설정).
- 왜 이 클라이언트인가: 한국에서 멤피스 리바이벌이 실제로 사는 곳은 성수·연남의 편집숍과 독립 가구 브랜드, 레트로 소품 시장이다. "원색 판재 가구 + 패턴 마감 견본"이라는 상품 자체가 멤피스 어휘이므로, 도형과 패턴이 모든 화면에서 **상품 데이터로 존재할 이유**가 생긴다.

### 감정 톤 (한 문장)
**"주말 오후 성수 쇼룸 문을 열자마자 원색 책장과 꿈틀 무늬 테이블이 와르르 반겨 주는, 시끄럽고 유쾌한 장난감 가게 같은 가구점."**
첫 화면 1초 안에 "웃기고, 시끄럽고, 갖고 싶다"가 와야 한다. 회색 기술 문서 톤 금지.

## 6. 레이아웃 문법 — "카탈로그 펼침면"

1. **펼침면(spread) 단위.** index의 각 섹션은 카탈로그 한 펼침면이다. 섹션마다 **배경 필드 색이 바뀐다**(paper → lemon → salmon → cobalt → paper+LM-02 바둑판 → lilac → ink). 같은 배경이 연속 두 번 나오지 않는다. 섹션 상하 패딩도 펼침면마다 다르게(96/160/64/120px) — 균질 리듬 금지.
2. **폴리오(folio).** 각 펼침면 위 모서리에 카탈로그 쪽번호 `p.04–05`와 섹션 이름(Do Hyeon 14px)만 둔다. 섹션 제목은 가운데정렬 금지 — **바닥선 위 왼쪽에 크게 놓거나**, 펼침면 바깥 모서리에 **세로 책등(writing-mode: vertical-rl)** 으로 세운다. "작은 라벨→제목→부제" 3단 헤더 금지.
3. **바닥선(floor line).** 상품(=컴포넌트)은 공중에 뜨지 않는다. 각 펼침면에 4px 잉크 바닥선이 있고, 상품은 높이가 제각각인 **받침대(plinth)** 위에 서서 같은 바닥선에 정렬된다(`align-items: end`). 높이가 달라도 바닥이 맞아서 벽보형 빈칸이 생기지 않는다.
4. **12단 비대칭 그리드**, 최대 폭 1360px, 거터 24px, 바깥 여백 데스크톱 48px / 모바일 16px. 텍스트 칼럼은 최대 4단(약 420px)으로 좁게, 상품 일러스트는 5~7단으로 크게. 한 펼침면 안에서 **한 요소는 반드시 그리드 밖으로 삐져나간다**(음수 마진 또는 풀블리드).
5. **가로지르는 패턴 띠.** 펼침면마다 LM 패턴 띠 하나가 `clip-path: polygon()`으로 −8°~+6° 기울어 지면을 가로지른다(높이 72~120px). 띠 위에는 글자를 올리지 않는다(패턴 위 텍스트 금지). 모바일에서는 기울기 −4°, 높이 40px.
6. **선반(shelf) 배열.** 컴포넌트 카탈로그 구간은 칼턴 책장처럼 **칸막이 선반**으로 배열: 2px 잉크 선반판 + 칸마다 다른 폭(3/5/4단 등) + 칸마다 다른 판재색 1~2개. 둥근 카드 그리드 금지.
7. **회전은 절제.** 가격표 스티커·품번 태그만 −4°~+5° 회전. 본문 블록·입력 필드·표는 0°. 일러스트 도형은 15°까지.
8. 모바일(360~390): 펼침면 → 단면(한 쪽). 바닥선·폴리오·패턴 띠는 유지, 선반은 2단 엇갈림(짝수 칸 24px 아래로), 가로 스크롤 0.

## 7. 시그니처 (2개, 끝까지)

### S1. 패턴 오프셋 — "라미네이트 단면"
멤피스 가구는 판재 옆면(엣지)에 다른 색·패턴이 보인다. 이를 **블러 없는 오프셋 블록을 단색이 아니라 LM 패턴으로 채우는 것**으로 번역한다(01 네오브루탈의 단색 하드섀도와 구분되는 결정적 장치).
- 구현: 컴포넌트 `::before`에 `inset: 0; transform: translate(var(--offset-x), var(--offset-y)); background: var(--pattern, var(--pat-lm06)); border: 2px solid var(--line); z-index: -1;` (box-shadow 아님 → 패턴 가능). 부모 `isolation: isolate`.
- 크기: 기본 6px/6px, 큰 판(모달·히어로 일러스트) 12px/12px, 작은 것(배지·체크박스) 3px/3px.
- 상태 문법: hover → 오프셋 6→10px(판이 들림), active → 0px(판이 눌려 단면이 사라짐), focus-visible → 오프셋 위 3px 마젠타 아웃라인 + 4px 간격, disabled → 오프셋 제거 + LM-03 깨알 30% 면.
- 컴포넌트별 패턴 배정(시스템 전체에서 고정): 버튼 primary=LM-06 사선, 카드=LM-01 꿈틀, 모달·드로어=LM-02 바둑판, 입력=LM-03 깨알, 토스트·알림=LM-04 번개, 칸반 카드=LM-05 테라조. → 패턴을 보면 무슨 부품인지 안다.
- 패턴 토큰: `--pat-lm01 … --pat-lm06` (repeating-linear/radial-gradient 또는 인라인 SVG data URI. 선색은 semantic `--pattern-ink`로 받아 다크에서 #F4EEDF).

### S2. 도형 모서리 — "부품 조립"
멤피스 가구는 반원·원기둥·삼각 부품을 조립한다. 컴포넌트 radius를 **대칭 라운드로 통일하지 않고, 한 모서리만 크게 깎는다.**
- 기본 판: `border-radius: 0` + **한 모서리만** `--corner-cut: 28px`(카드는 우상단, 버튼은 좌하단, 모달은 좌상단, 토스트는 우하단). 원형 칩은 완전 원(999px) 허용(배지·아바타·스텝 번호). 삼각은 `clip-path`로 툴팁 꼬리·드롭다운 화살표·브레드크럼 구분자에만.
- 8px 균일 라운드 금지(v1 문법).
- 아이콘은 3px 스트로크 기하 SVG(원·삼각·지그재그 어휘), `currentColor`.

## 8. 모션 문법 — "통통 튀어 조립되는 가구"

| 토큰 | 값 | 사용 |
|---|---|---|
| `--ease-pop` | `cubic-bezier(.34, 1.56, .64, 1)` (back.out 1.4 근사) | 등장, 오프셋 확장 |
| `--ease-snap` | `cubic-bezier(.2, .9, .3, 1)` | 눌림, 닫힘 |
| `--dur-press` | 90ms | active 오프셋 0 |
| `--dur-hover` | 160ms | 오프셋 6→10 |
| `--dur-enter` | 420ms | 판 등장(rotate −6°→기본각, scale .92→1) |
| `--stagger` | 60ms (목록 10행 이상은 30ms) | |
| `--dur-band` | 40s linear infinite | 마퀴·패턴 띠 흐름 |

- 등장: 스크롤 진입 시 IntersectionObserver로 상품이 받침대 위로 **"툭" 떨어져** 앉는다(translateY −16px→0, 회전 −6°→0, ease-pop).
- 단 한 번의 큰 장난: 상품 상세의 "장바구니 담기"(primary) 클릭 시 LM 도형 6개(원·삼각·꿈틀·번개)가 버튼에서 튀어 흩어짐(600ms). 다른 버튼에는 없다.
- skeleton = LM-06 사선이 흐르는 애니메이션(그라디언트 샤인 금지).
- `prefers-reduced-motion: reduce` → 모든 등장·띠 흐름·튀김 제거, 최종 상태 즉시 렌더, 호버 오프셋 변화만 유지(transition 0).
