## 1. 클라이언트 · 세계관

### 스타일의 원래 맥락
- **산업 안전색 체계**: ISO 3864 / KS S ISO 3864와 한국 산업안전보건법 「안전보건표지」. 노랑은 경고, 빨강은 금지·정지, 초록은 안내·정상, 파랑은 지시(의무)를 뜻한다. 노랑 바탕 + 검정 45° 줄무늬는 충돌·추락 위험 구역 표시다.
- **군수·물류 스텐실**: 2차대전 이후 군수품 상자·드럼통·컨테이너에 분무 스텐실로 찍은 번호. 글자 획이 브리지(끊김)로 나뉜다.
- **창고 위치 라벨**: 팔레트 랙 빔에 붙이는 「구역-열-단」 위치 코드 라벨. 큰 코드 + 바코드 + 품명이 한 줄에 놓인다. 팔레트 랙은 **주황 빔 + 진회색 업라이트(기둥) + 기둥의 물방울 모양 구멍 줄**로 생겼다.
- **장비 명판과 사양서**: 지게차·발전기에 리벳으로 박은 금속 명판(형식, 정격, 제조번호)과, 카탈로그 뒷면의 2단 사양표.
- **정비 꼬리표**: 모서리를 잘라낸 마닐라·플라스틱 태그에 구멍(아일릿)을 뚫어 철사로 매다는 꼬리표. 「사용 금지」(빨강), 「점검 중」(노랑), 「사용 가능」(초록)으로 나뉜다. LOTO(잠금·표지) 절차의 핵심 도구다.

### 클라이언트 (한국, 가상) — 반월장비창고 BWD
- 경기도 안산 반월국가산업단지 안에서 **산업장비 임대 · 정비 · 부품 보관**을 하는 창고형 업체다. 전동 지게차, 고소작업대, 발전기, 공기압축기, 용접기, 핸드파렛트 등 **214대**를 보유하고, 반월·시화산단의 중소 제조사에 일·주·월 단위로 빌려준다. 정비 보전 계약(월 구독)으로 거래처 장비도 정비한다.
- 1998년 공구상가 한 칸으로 시작해 2014년 지금의 제2창고동(팔레트 랙 1,920칸)으로 옮겼다. 사내에 「BW-STD 19 현장 표준 라벨·사양서 규격」이 있어서 랙 라벨, 장비 명판, 정비 꼬리표, 출고 전표를 모두 같은 규격으로 찍는다. **이 디자인 시스템 = 그 사내 규격집의 웹판이다.**
- 쓰이는 곳:
  1. **현장 표준 규격집 웹판**(index): 「BW-STD 19 제3판」. 신입 직원과 협력사가 라벨·명판·태그 규격을 확인한다.
  2. **사내 화면**: 창고 상황판(dashboard), 거래처 요청함(inbox), 정비 작업 지시판(kanban), 직원 프로필·설정.
  3. **거래처 화면**: 장비 사양서·임대 신청(product), 정비 보전 계약 요금(pricing), 신규 거래처 등록(onboarding).
- 왜 이 클라이언트인가: 산업 유틸리티 미학이 장식이 아니라 **업무 도구**로 쓰이는 곳이기 때문이다. 위치 코드는 실제로 사람을 랙 앞으로 데려가고, 꼬리표 색은 실제로 장비 사용 여부를 정하고, 경고 띠는 실제로 위험 구역을 막는다.

### 감정 톤 (한 문장)
**"새벽 6시 40분, 교대 직전 창고에 형광등이 한 줄씩 켜지고 노란 라벨과 주황 빔이 줄지어 드러나는 — 무뚝뚝하지만 한 치의 착오도 없는, 믿음직한 긴장감."**
첫 화면 1초 안에 "**단단하다, 정확하다, 여기서는 물건이 제자리에 있다**"가 와야 한다. 세련된 SaaS 회색 문서, 차콜 게임 UI, 레트로 소품 진열은 금지한다.

## 6. 레이아웃 문법 — 「팔레트 랙」

창고의 팔레트 랙이 그대로 그리드다. **수직 기둥(업라이트) + 수평 빔(단) + 칸(베이) + 위치 라벨.**

1. **베이 그리드**: 12단, 최대폭 **1392px**, 거터 **24px**(≤768: 16px), 측면 여백 **40px**(≤768: **16px**). 12단은 3단씩 **4베이**로 묶인다. 랙 장면에서는 베이 사이에 **업라이트**(폭 8px, `--ink`, 세로로 12px 간격 물방울 구멍 4×8px이 뚫린 패턴 — `repeating-linear-gradient` + mask)를 세운다. 업라이트는 그리드 거터 안에 들어간다(콘텐츠 폭을 먹지 않음).
2. **빔 = 단 구분**: 랙 장면의 각 단 하단은 **높이 12px 주황 `--orange` 빔 + 위 2px `--ink` 선**. 콘텐츠는 빔 위에 "얹혀" 하단 정렬(`align-items: end`)된다 — 칸 높이가 달라도 바닥선이 맞으니 빈 칸이 위로 남는다(공백이 아니라 적재 여유로 읽힌다). 칸 위 빈 공간이 120px를 넘으면 내용량을 조정한다(7-8).
3. **위치 라벨이 머리말이다**: 가운데정렬 섹션 헤더는 없다. 모든 섹션은 **좌측 정렬 랙 라벨 띠**(9절 참고)로 시작한다. 라벨 띠는 섹션 폭 전체를 쓰고 높이는 72px(모바일 56px).
4. **장면마다 다른 단 높이**: 섹션마다 수직 리듬을 다르게 쓴다 — 표지는 0 여백 풀블리드, 색 섹션은 띠 사이 0 간격, 사양서는 행 높이 44px 촘촘, 랙 섹션은 단 사이 48px, 페그보드는 64px 격자.
   - **섹션 간격은 명시값으로 고정**(남는 공간이 빈 띠로 읽히지 않게): 표지 바닥 아래 32 → 01 도장 위 48 / 아래 64 · 02 강판 안쪽 96(판 자체가 면) · 03 사양서 위아래 64 · 04 랙 위 48 / 아래 64 · 05 타공판 안쪽 64 · 06 열쇠함 위 64, 아래 0(푸터 명판 64가 한 번만). 두 섹션 여백이 겹쳐 120px를 넘으면 버그로 본다.
5. **정렬**: 텍스트·코드는 좌측 정렬, 숫자는 우측 정렬(표·사양). 가운데 정렬은 404 경고 표지 하나만 허용.
6. **각도**: 모든 모서리 직각(radius 0). 둥근 것은 **펀치 구멍, 표시등(LED), 토글 노브** 셋뿐. 대각선은 **45°만**(모따기, 경고 띠).
7. **간격 스케일**(px): 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 · 128. 패널 내부 패딩 20/24, 표 셀 12×16.
8. **선 두께**: 구조선 2px(`--ink`/`--line-strong`), 강조 경계 4px, 표 내부 1px(`--line-mid`). 그림자는 블러 0의 하드 오프셋만: 매달린 태그 `4px 4px 0 var(--ink)`(다크 `#000`), 눌림 `0 0`.

## 7. 시그니처 (2개, 끝까지)

### 시그니처 ① 「정비 꼬리표」 — 45° 모따기 + 펀치 구멍
모든 "물건에 붙는 정보 단위"(카드, 배지, 토스트, 팝오버, 칸반 카드, 모달, 드로어 머리, 가격 플랜, 페이지 링크)는 꼬리표 형상이다.
- 형상: **왼쪽 위·왼쪽 아래 모서리를 45° 모따기**(`--chamfer` 큰 태그 16px / 중간 12px / 배지 6px), 모따기 쪽 세로 중앙(큰 패널은 위에서 28px)에 **펀치 구멍**(지름 10px, 배지 6px; 바탕색 `--bg`로 뚫린 원 + 2px 링 `--ink`).
- 테두리 구현: 바깥 요소 `background: var(--ink)` + `clip-path: polygon(16px 0,100% 0,100% 100%,16px 100%,0 calc(100% - 16px),0 16px)`, 안쪽 `::before`가 같은 다각형을 2px 안쪽으로(inset 2px) `--surface`로 덮는다 → 대각선 변에도 2px 테두리가 이어진다. 그림자는 clip-path에 잘리므로 **부모 래퍼의 `filter: drop-shadow(4px 4px 0 var(--ink))`** 로 준다.
- 상태색 = 꼬리표 색: `사용 금지` 빨강 면 + 흰 글자, `점검 중` 노랑 면 + 검정, `사용 가능` 초록 면 + 흰 글자, `정보` 흰 라벨 + 검정. 색만이 아니라 **아이콘 + 한글 라벨**을 함께 쓴다.
- 매달림: index 표지·페이지 링크 열쇠함·product 점검 꼬리표처럼 "걸린" 태그는 구멍에서 **철사(SVG 1.5px `currentColor` 곡선)** 가 위로 이어지고 `rotate(-3°…4°)`로 기운다. 일반 UI의 카드는 기울이지 않는다(기울기는 장면 전용).

### 시그니처 ② 「랙 위치 라벨」 — 스텐실 코드 + 바코드 띠
창고 빔에 붙는 위치 라벨이 모든 머리말·식별자의 형식이다.
- 구조(가로 한 줄, 높이 72px): `[스텐실 위치 코드 ─ Saira Stencil 56px, 노랑 면 + 검정]` `[한글 품명 ─ Black Han Sans 28px, 라벨지 면]` `[바코드 ─ 1·2·3px 검정 막대 repeating-linear-gradient, 폭 160px, 아래 Plex Mono 12px 숫자]` `[수량/개정 ─ Barlow Condensed 13px 대문자 + 값]`. 전체 2px `--ink` 테두리, 칸 사이 2px 세로선.
- 하위 판 예: dashboard `D-00-1·1 장비 꼬리표 현황판` · `D-00-1·2 구역별 적재율` · `D-00-1·3 오늘 출고`(D-01처럼 부모와 끊긴 코드 금지 — D-01은 D구역 1열 위치와 헷갈린다). 모달 코드 칸에는 대상 장비의 위치 코드(`B-05-2`, `B-07-3`)만 쓰고 `LOTO`는 제목 옆 빨강 꼬리표로 둔다.
- 모바일: 코드 + 품명 한 줄, 바코드·수량은 아래 줄로 접고 바코드 폭 120px. 첫 행은 `minmax(56px, auto)`로 내용만큼 자라고 코드·품명에 위아래 8px 여백(스텐실 글자가 테두리에 붙지 않게), 수량 칸은 왼쪽 정렬.
- **코드 파생 규칙**: 머리말 코드는 반드시 `구역-열`(판 머리) 또는 `구역-열-단` 형식이거나 부모 위치에서 파생한다. 하위 절은 `부모·번호`(product `B-07-3·1 제원표` · `B-07-3·2 현재 상태` · `B-07-3·3 점검 이력부`), 같은 구역의 형제 판은 단 번호를 잇는다(index `L-05` → `L-05-2 동작 시험대`, `A-04` → `A-04-0 바닥 구역`, pricing `P-00-1` → `P-00-2 사양 비교표`), 페이지 밖 공용 판은 `구역-00-n`(product `B-00-2 대체 장비`). `FB25` `IT` `4×8` 같은 라틴 약어는 코드 칸에 쓰지 않고 메타 칸(수량·개정 자리)으로 보낸다.
- 적용: index 각 섹션 머리말, 페이지 제목(예: dashboard `D-00-1 창고 상황판`), 사이드바 현재 위치, 표의 위치 열, 모달 제목 줄, 브레드크럼(코드 체인), 404(`Z-00-0 미등록 위치`).
- 다크에서 라벨 지면은 `--label-stock` #ECEBE6 + 글자 #111214 유지(반사 라벨).

### 경고 띠의 규칙 (시그니처가 아니라 "의미 장치")
45° 노랑/검정 줄무늬(`repeating-linear-gradient(-45deg, var(--yellow) 0 14px, #141518 14px 28px)`)는 **위험·차단·잠금이 있을 때만** 쓴다: 삭제·해지 영역 테두리, 사용 금지 장비 행 왼쪽 8px 띠, 잠긴(비활성) 기능 오버레이, 드래그 놓기 금지 칸, 정비 중 배너, 404. **구분선·장식으로 쓰면 버그로 본다.**

## 8. 모션 문법 — 「기계는 미끄러지지 않고 걸린다」

- 지속: `--t-snap: 80ms`, `--t-move: 160ms`, `--t-travel: 240ms`. 300ms를 넘는 UI 모션 금지.
- 이징: `--ease-snap: cubic-bezier(.2, 0, 0, 1)` (빠르게 출발해 딱 멈춤), `--ease-swing: cubic-bezier(.3, 1.6, .5, 1)` (꼬리표 흔들림 전용 오버슈트), 진행률은 `steps()`.
- **누름**: 버튼 `:active` → `translate(2px, 2px)` + 하드 그림자 0, 80ms. 래칫 감각.
- **꼬리표 흔들림**: 매달린 태그 hover/focus 시 `rotate` 현재각 → +2° → 현재각, 240ms `--ease-swing`. 일반 카드는 흔들지 않는다.
- **라벨 출력**(토스트·새 알림): 라벨 프린터에서 라벨이 나오듯 위에서 아래로 `clip-path: inset(0 0 100% 0) → inset(0)` 240ms `steps(6)`, 출력 끝에 2px 아래로 툭 떨어짐.
- **셔틀**(드로어·모바일 사이드바): 랙 셔틀처럼 `translateX` 240ms `--ease-snap`, 정지 순간 1px 반동.
- **진행률**: 채움이 연속이 아니라 10칸 단위로 `steps(10)` 덜컥 증가. 막대 끝에 2px 검정 눈금.
- **스피너 = 경광등**: 12px 원 안에 노랑 반원이 회전(800ms linear), 바깥 2px 링. 줄무늬가 흐르는 「작업 중」 띠(경고 띠를 `background-position`으로 1.2s 이동)는 **정비 중 상태 배너에만**.
- **스켈레톤**: 반짝이는 shimmer 대신 **점선 테두리 「적재 예정 칸」** + 내부 1px 사선 해칭 고정. 깜빡임 없음.
- **LIVE 표시등**: 지름 8px 원, 1s `steps(2)` 점멸(켜짐/꺼짐, 페이드 없음).
- 페이지 진입 연출, 스크롤 리빌, 패럴랙스 없음.
- `prefers-reduced-motion: reduce` → 모든 애니메이션·트랜지션 0.01ms, 매달린 태그는 기울기만 유지, 점멸 표시등은 켜짐 고정.
