cat /usr/share/doc/sw07/pinout.txt

+--------------------------------------+
| (o)  SW-07 rev C                (o)  |
|                                 1 o--+--- TX
|==+    +--------+   +-----+      2 o--+--- RX
|  |USB |        |   | LVL |      3 o--+--- GND
|  | C  | RP2040 |   +-----+      4 o--+--- VREF
|==+    |        |                5 o--+--- SWDIO
|       +--------+                6 o--+--- SWCLK
|  PWR *  ACT *    [1V8|3V3|5V0]       |
| (o)                             (o)  |
+--------------------------------------+

핀  이름    방향    연결
1   TX      출력    대상의 RX
2   RX      입력    대상의 TX (5V 허용)
3   GND     -       공통 접지, 가장 먼저
4   VREF    입력    대상 전압 감지
5   SWDIO   양방향  SWD 데이터
6   SWCLK   출력    SWD 클럭

6핀 헤더: 1 TX 출력, 2 RX 입력(5V 허용), 3 GND 공통 접지, 4 VREF 대상 전압 감지, 5 SWDIO 양방향, 6 SWCLK 출력. 전압 점퍼는 3V3에 꽂혀 출고.

점퍼를 옮기기 전에 USB를 뽑으세요.
